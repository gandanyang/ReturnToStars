### 后续内容设计过滤器（所有新功能/新区域/新NPC 立项前先问）

1. 它是否强化"岛曾经存在过"？（例：废弃码头 → 这里以前有人来）
2. 它是否强化"玩家正在改变它"？（例：修复老屋 → 我的行动留下痕迹）
3. 它是否留下未来期待？（例：灯塔 → 那里以后是不是会发生故事？）

> **三个都不能满足：不要做。**（2026-08-13 制作人升级：本规则是所有 Agent 任务的第一层过滤器——AI 擅长"可实现"，但必须先判断"值不值得存在"。）
