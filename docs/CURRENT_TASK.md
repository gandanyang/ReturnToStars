## 当前阶段目标（2026-08-12 制作人拍板：解除 Alpha Freeze，进入第一章「复苏」）

> **第0章 Demo 已冻结。第一章不追求地图扩大 / 系统数量增加，重点建立「玩家行为 → 世界变化 → 情感反馈」循环。**
> 最高指导：`docs/第一章开发总纲.md`。

**第一章目标**：玩家第一次明确感受到"我的行动正在改变这里"，并因此想留下——"这个小镇，可以因为我的到来而慢慢变好。"

**开发优先级**：
- **P0 世界反馈**：任何玩家行为都应产生可见反馈（种植→小镇资源/居民生活/区域变化；修复→场景/NPC/氛围变化）
- **P1 NPC 生命感**：已有 NPC 拥有日常行为 / 小事件 / 情绪变化 / 对小镇变化的反馈
- **P2 轻量玩法**：收集 / 采集 / 钓鱼 / 小型互动——必须服务生活感，不引入复杂数值系统

**禁止**：无限扩张（大地图/新大陆/大量 NPC/复杂剧情线）；偏离核心玩法（战斗/装备/抽卡/复杂制造链）；为"看起来丰富"增加内容；第0章内容回归/变动（D-021/D-023/D-025 红线仍有效）。

**判断标准**：不是"这个功能很酷"，而是"**玩家是否因此更喜欢这个小镇**"。

### 后续内容设计过滤器（所有新功能/新区域/新NPC 立项前先问）

1. 它是否强化"岛曾经存在过"？（例：废弃码头 → 这里以前有人来）
2. 它是否强化"玩家正在改变它"？（例：修复老屋 → 我的行动留下痕迹）
3. 它是否留下未来期待？（例：灯塔 → 那里以后是不是会发生故事？）

> **三个都不能满足：不要做。**

### 核心概念（2026-08-10 制作人统一）

- **"转" = 认知转变，不是剧情反转**：不做《原神》式真相揭露、不做《终末地》式世界危机。认知转变 = 玩家开始「我要帮爷爷留下的岛」→ 中间「等等，爷爷不是想让我守住这里」→ 最后「我自己想留下」。没有爆炸，但情绪完成。
- **转①红线（升级）**：没有灾难，只是时间过去了——以前渔船很多/灯塔每天亮/港口有人聊天；后来年轻人出去工作/老人减少/船越来越少/灯塔维护不了；最后岛不是死了，只是安静了。
- **测试后三情况决策**：A 有情绪投入→只补转②+少量转①；B 喜欢种田但不关心岛→是复兴反馈不足（环境/NPC/小镇变化），不走转①/转②；C 不知道为何留下→回到第一章前 10 分钟，不加转折。
