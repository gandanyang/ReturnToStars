## 🔵 任务分类（2026-08-13 制作人拍板：所有 Agent 新任务先分类）

> 三层过滤器：**A 类直接执行 / B 类先出方案 / C 类必须制作人判断**。开工前先判断任务属于哪类，B/C 类禁止直接施工。

| 类 | 定义 | 示例 |
|---|---|---|
| **A 直接执行** | 明确、可验证、不涉及体验判断 | 探针 / 存档 / UI / 状态机 / 资源接入 / 已定稿文本落地 |
| **B 先出方案** | 新玩法/新NPC/新区域/新系统——先交方案文档，制作人确认后才施工 | 新系统设计、新区域生产方案 |
| **C 制作人判断** | 节奏/情绪/是否空洞/是否"有意思"/是否需要删——AI 可提建议，拍板权在人 | 文本去留、演出节奏、数值调感 |

### 后续内容设计过滤器（所有新功能/新区域/新NPC 立项前先问）

1. 它是否强化"岛曾经存在过"？（例：废弃码头 → 这里以前有人来）
2. 它是否强化"玩家正在改变它"？（例：修复老屋 → 我的行动留下痕迹）
3. 它是否留下未来期待？（例：灯塔 → 那里以后是不是会发生故事？）

> **三个都不能满足：不要做。**（2026-08-13 制作人升级：本规则是所有 Agent 任务的第一层过滤器——AI 擅长"可实现"，但必须先判断"值不值得存在"。）
