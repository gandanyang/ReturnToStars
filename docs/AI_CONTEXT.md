## 一、项目定位

《归星物语》是像素风农场生活 RPG（类星露谷、二次元剧情表现），Phaser 3 + TypeScript + Capacitor 打包安卓 APK，**移动端优先**。
当前阶段：**Alpha 稳定阶段**——做一次 15~30 分钟完整体验 Demo（"逃离现实 → 回到故乡 → 重新照顾生活 → 看见回应 → 主动发现岛的过去 → 想留下来看看"）。

核心原则：**稳定 > 新功能，体验 > 系统数量，完成一个闭环 > 添加十个半成品。**

## 二、平台与设备约束

### ⚠️ 移动端方向：只支持横屏

**《归星物语》移动端只支持横屏模式。禁止默认按竖屏移动游戏设计。**

| 项 | 值 |
|---|---|
| 目标设备 | Android 横屏手机 / 横屏浏览器 / Capacitor APK |
| 画布基准 | 横屏 16:9 或接近比例（800×600，等比 FIT 缩放） |
| 强制手段（已存在） | `AndroidManifest.xml` `screenOrientation="landscape"`；`index.html` 竖屏旋转提示层 `#rotate-hint` |

所有移动端 **UI、触控、镜头、安全区域设计**，必须以横屏为基准。

### 手机端测试规范（AI 模拟测试时）

**禁止：**
- ❌ 使用默认竖屏手机模拟器作为验收依据
- ❌ 根据竖屏截图判断 UI 是否合理
- ❌ 调整布局适配竖屏

**正确做法：**
- ✅ 模拟器/浏览器先设为**横屏**再测试
- ✅ 用真实游戏方向验收
- ✅ 检查：横屏视口填充 / 操作按钮位置 / HUD 遮挡 / 虚拟摇杆区域 / 触控目标大小

**任何"移动端优化"任务开始前，先确认测试环境为横屏。**
