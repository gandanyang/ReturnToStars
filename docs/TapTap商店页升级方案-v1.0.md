# 《归星物语》TapTap 商店页升级方案 v1.0

> 版本：v1.0（2026-08-08 制作人立项：P0 专项——TapTap 上架宣传物料全面升级）
> 定位：项目已从"把游戏做出来"进入"**让玩家愿意点击下载**"。核心风险不在游戏内，而在**第一眼转化率**。

## 一、核心卖点（一切物料围绕它）

> **一个现代职业人在 AI 时代回到故乡，让一座荒废小岛重新恢复生命。**

- 不是"又一个 Stardew 类"——差异化 = **"AI 时代程序员回乡 + 重新寻找生活意义"**
- 情绪锚点：观星夜（Demo 记忆节点）已就绪
- 一句话：**当工作无法回答"我是谁"，你会不会回到一个熟悉的地方，重新开始生活？**
- 三句话：林澈是一名生活在城市中的程序员。在 AI 改变工作方式的时代，他回到了爷爷留下的归星岛。种下一片田，修复一座岛，也重新寻找自己想留下的理由。

## 二、商店定位（P0-1 产出）

| 项 | 内容 |
|---|---|
| 类型标签 | 像素 / 治愈 / 种田 / 模拟经营 / 剧情 / 独立游戏 / 慢节奏 / 中文 |
| 一句话卖点 | 当工作无法回答"我是谁"，你会不会回到一个熟悉的地方，重新开始生活？ |
| 核心差异 | AI 时代程序员回乡 × 修复荒废小岛 × 观星夜情感闭环 |
| 语气基调 | 克制、温暖、不煽情；拒绝"手游化"文案（不写"海量玩法/无限合成/福利"） |

## 三、首图 Banner（P0-2，最高优先级）

- 主视觉：**林澈 + 夏雅**，场景=观星夜 / 黄昏海边
- 文字：主标题《归星物语》+ 英文副题 `Return to the Star Island` + 一行副标题
- 情绪："重新找到生活"，不是"种田赚钱"
- ❌ 不做：单纯风景 / 单独角色 / Logo 占满 / 立绘堆砌

## 五、宣传视频脚本（P0-4，30~60 秒，拒绝传统宣传片）

```
0-5s    城市·电脑·夜晚·林澈        字幕：「如果有一天，你最擅长的事情不再被需要……」

15-30s  玩法：种田/修复/探索/NPC    节奏加快，实机混剪
30-45s  观星夜·夏雅·小镇灯光        静下来，情绪顶点
结束    黑场：《归星物语》等你回来    Logo + 下载引导
```

## 九、执行顺序与风险

1. **P0-1 定位定稿 → P0-2 首图 → P0-3 截图 → P0-4 视频 → P1-1 统一**（定位先行，避免返工）
2. 风险：promo 源文件丢失（需先决定找回还是重做）；AI 图风格不一致（用同一 prompt 基座 + 统一调色板）
3. 视频为最大工作量（逐镜生成），建议在图片物料确认后启动
4. 所有物料输出 `marketing/`，实机截图用横屏视口（1024×768，项目红线）
