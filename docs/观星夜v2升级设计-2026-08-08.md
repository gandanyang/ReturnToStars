# 观星夜 v2 升级设计（设计稿 v0.1）

> 版本：v0.1（2026-08-08 制作人指令：**先出设计稿，确认后施工**）
> 定位：Demo 最后情绪锚点——"做到让玩家愿意截图"
> 红线：**不新增系统/存档字段/剧情结构；对白 v0.3 定稿不改**；只强化演出层（镜头/星空/环境/节奏/结束）
> 关联：probe-stargaze 14/14（回归基准）、`docs/老屋环境设计原则-2026-08-08.md`（环境叙事原则同源）

## 一、现状基线（v0.3 已达成，已验证）

```
主线完成 + 夜晚（或白天靠近"坐等天黑"）
 ↓
靠近观星点 → startStargaze()
 ↓
星空显隐（渐变底 + 120 静态星 + 银河带 + 30 闪烁星，depth 15-16）
 ↓
相机 stopFollow + useBounds=false + pan 2s 至观星点（#29 补丁：钉住镜头）
 ↓
showMemoryMoment("这片星空，和爷爷记忆里的一样。")
 ↓
DEMO_ENDING_DIALOGUE（18 行 + 三选项）
 ↓
分支独白（try_stay / unknown / tonight）
 ↓
DEMO_ENDING_FINALE（次日清晨）
 ↓
晨曦过渡 2s（相机背景色深蓝→暖橙 tween）
 ↓
隐藏星空 → 相机拉回玩家 → 恢复 follow/useBounds → save → EndingPanel（归星记录）
```

**已验证**：probe-stargaze 14/14（对白/选项/分支/结算/终态/存档全绿）。
**已修历史坑**：#29（观星画面偏右看不到玩家）、BUG-050（结束后相机跟随失效）——相机是高风险区，v2 动相机必须回归。

## 二、v2 目标

1. 星空从"静态背景"升级为"会呼吸的天空"（流星/更亮银河/分层星）
2. 镜头从"钉住"升级为"有感情的调度"（缓推→微横移→独白拉近）
3. 结束从"切面板"升级为"留白呼吸"（更慢晨曦 + 记录前黑场）
4. **对白一字不改**（红线），只做演出

## 三、分节设计

### 1. 玩家到达前（铺垫）
- 现状：观星点呼吸闪烁 + 白天"坐等天黑"，夜晚环境音已由 AmbienceSystem 承担
- v2：**不加新对白**（到达前保持安静，靠视觉铺垫）
- 小增强（可选）：夜晚靠近观星点时，星空先"渐显"再触发对话（现为对话开始才 show 星空 → 改为靠近即渐显，1s 淡入）

### 2. 镜头（高风险，改动最小化 + 必须回归）
- 现状：pan 2s 钉住观星点，全程静止
- v2 三段调度：
  - ① pan 阶段（2s）：起点从玩家肩位 → 终点观星点，**末段上抬 20px**（模拟"抬头看天"）
  - ② 对话阶段：**一次极慢横移 30px / 8s**（打破静止，不切机位）
  - ③ 分支独白阶段：**zoom 2.0→2.15 拉近（1.5s）**聚焦角色
- 风险控制：所有 tween 挂在同一 chain，结束后必须恢复 follow/useBounds（#29/BUG-050 回归点）

### 3. 环境
- 现状：对白文字里有"星光落在旧墙""远处虫鸣"，视觉/听觉 MVP
- v2 增强（零资源）：
  - **星光粒子**：观星点上空 20 颗淡蓝白粒子慢漂（复用 forestFireflies 粒子模式，tint 0xddeeff，blendMode ADD）
  - **旧墙月光**：观星点旁旧墙/石头加淡月光 tint（复用现有 tint 配置）
  - **微风音效**（可选）：AudioSystem 新 case `wind`（一次性、低音量、程序合成风声——noise 低通 + 低频），仅观星夜播一次

### 4. 夏雅对白
- **严格不改**（v0.3 已定稿："你爷爷以前每天都会坐在这里"…"总有一天会有人回来继续看"）
- 演出层：夏雅说话时立绘/头像已存在，不动

### 5. 林澈独白
- **台词不改**（3 分支已定稿）
- 演出层：分支独白播放时镜头拉近（见 ②③）+ 星空闪烁频率略增（情绪放大，闪烁 tween 速度 ×1.3，播完恢复）

### 6. 星空表现（核心升级，全部零资源）
| 项 | 现状 | v2 |
|---|---|---|
| 底色 | 深蓝渐变 | 保留（色相微调：暗部略提亮 0x0a1628→0x0d1a30） |
| 静态星 | 120 颗单层 | **分两层**：近层 80 颗（亮 0.6-0.9）+ 远层 60 颗（暗 0.2-0.4），共 140 |
| 闪烁星 | 30 颗 sine | 增至 50 颗，**8 颗大星带十字光芒**（4 条短 line，旋转慢闪） |
| 银河带 | 0.06 白带状 | **叠加 0.04 淡蓝带** + 宽度微增（更"银河"感） |
| **流星**（新增） | 无 | 演出期间随机 **2-3 颗**（直线 + 尾迹渐变，tween 1.2s 划过，一次性） |
| memoryMoment 时刻 | 无 | "这片星空，和爷爷记忆里的一样"出现时，**星空整体亮度脉冲一次**（0.5s 提亮再回落） |

性能约束：全部 Graphics/particles，**总量 < 60 活动对象**（静态星是单 Graphics 绘制不计数）。

### 7. 结束方式
- 现状：晨曦 2s → 相机拉回 → EndingPanel 直接打开
- v2：
  - 晨曦 **2s → 3.5s**，加"第一缕阳光"光带（地平线斜向一条淡金线 tween 扫过，1.5s）
  - EndingPanel 打开前：**1s 黑场呼吸**（相机/遮罩 fade 至 0.85 再回 0）——强化"记录时刻"的庄重
  - 结算面板内容**不变**（五段归星记录已验证）

## 四、技术约束清单

- 零新系统 / 零存档字段 / 零剧情结构改动
- 新增资源：无（全部 Graphics/particles/tweens；AudioSystem 最多 +1 case `wind`）
- 相机改动集中在 `startStargaze`/`playStargazeAfter` 两个方法内
- 回归：**probe-stargaze 14/14 必须全绿**（相机/星空/晨曦改动点）
- 手机性能：粒子 + 闪烁星 < 60 对象，流星一次性销毁
