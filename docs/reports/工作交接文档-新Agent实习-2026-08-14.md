## 九、红线速查（违反 = 返工）

1. **移动端只支持横屏**：禁止竖屏设计 / 竖屏模拟器验收。
2. **Git 写权限**：禁止 `git add -A` / `git commit` / `git reset` 等，提交统一由 opencode / 制作人执行。
3. **不新增系统**：动手前查 `src/systems/`、`src/data/`、`docs/`；已有 `Inventory.ts` 就不建 `NewInventory.ts`。
4. **状态只进 SaveSystem**：禁止 localStorage / scene 散落；一次性事件一律 `EventManager.triggerOnce`。
5. **地图 gid 语义 / 碰撞编号禁止改动**（与存档关联）。
6. **剧情权限**：主角成长 / 角色身份 / 世界观真相 / 关键节点 / 玩家选择——不得自行扩写。
7. **文本护栏**：新增/修改游戏内文本前过《归星岛文本风格与反AI味标准》四层过滤（角色→生活→信息→情绪）。
8. **语音交付流程**：先本地试听 → 制作人确认 → 更新文档 → 打包 → 装机；禁止直接打包。
9. **docs 是项目资产**：禁止删除；归档用 `archive/` 复制。
10. **测试分级**：纯文档 Level 0 / 单系统小改 Level 1 / 核心逻辑 Level 2 / 大版本 Level 3；禁止默认跑全部测试。
