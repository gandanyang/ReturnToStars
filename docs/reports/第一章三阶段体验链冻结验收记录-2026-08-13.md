## 一、目标（复述）

第一章副标题「重新认识青禾镇」，将主线与支线统一为一条**小型体验链**：

```
发现自然（捉虫引导） → 参与小镇生活（集市「重新开张」布置） → 理解自然（昆虫观察）
```

叙事推进：*「我发现这个地方还有生命」→「我发现这里还有人生活」→「我发现这个世界值得被记录」*。
判断标准：不是"功能很酷"，而是"玩家是否因此更喜欢这个小镇"。

## 四、关键决策记录

1. **集市从「一次资源交付」升级为「多阶段需求匹配布置」**（D-029）：原资源交付保留为"清理场地"阶段，新增布置/开张阶段，强化"听居民需求"而非"试错惩罚"（放错→温和纠正、不消耗、可重试）。
2. **捕虫收敛为固定品种叙事体验**：移除稀有度随机（银翼蝶 12% 稀有），固定青禾凤蝶，首次奖励为世界观文本而非金币。
3. **一次性状态用 `triggerOnce` 持久化**：`ch1_market_cleared` / `ch1_market_stall_1/2/3` / `ch1_qinghe_butterfly_guide` 等不新增存档字段，旧档兼容（存档回归通过）。
4. **老屋节奏改造**：B-1 分时淡入 + B-3 焦点优先 + B-2 专属反馈音效，解决"装修清单感"。
