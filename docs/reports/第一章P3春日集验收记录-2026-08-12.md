## 一、P3 目标（复述）

**不是大型节庆**，是"青禾镇重新有了一天热闹的晚上"。玩家修好集市后，第一次亲眼看到镇上重新聚起人——第一章以"生活重新开始"的画面收尾，而非"任务完成结算"。

验收（任务书硬性）：
1. 演出触发条件：`chapter >= 1` + `marketSquare` 修复完成
2. 玩家在人群（或老屋窗前）看到镇上重新聚集
3. 埋第 2 章钩子但更克制（远处码头/灯塔方向一点动静，不展开）

限制：**规模 ≤ 观星夜 40%**（克制版：灯火 + 人声 + 一句独白）、不扩写剧情。

### triggerOnce 时序纪律（遵 docs/dev/EventSystem.md）

`startSpringFair` 内演出主体包在 `triggerOnce('ch1_spring_fair', fn)` 中（fn 内 play('crowd') / buildSpringFairFX / showMemoryMoment / storyDialogue.play），**triggerOnce 返回后**再 `save()`——先 fn 后标记，fn 内不 save，避免"fn 内 save 漏存当前 key / 全部完成判断漏判"两类坑。

## 四、施工过程中的决策与问题记录

1. **克制优先**：按任务书"规模 ≤ 观星夜 40%"，明确砍掉镜头链 / 星空 / 选项分支，只保留灯火 + 人声 + 一句独白。台词仅 3 条（人群旁白 / 镇长一句 / 灯塔钩子旁白），不扩写剧情。
2. **灯塔钩子克制**：第 2 章钩子只用旁白"海面上好像亮了一下，很快又暗下去"，不解释来源、不接对白，留白给第 2 章。
3. **零新素材**：灯火与人影剪影全部 Graphics 程序绘制（复用观星夜/集市恢复范式）；人群声为程序合成低噪声（`noise()` 自带 2000Hz 低通，正好符合"人群嗡嗡"质感），无新音频资产。
4. **triggerOnce 时序**：save 放在 triggerOnce 返回后（EventSystem.md 纪律），探针 S3 实测存档字段正确。
5. **探针种子档**：`worldRestore.marketSquare=true` + `ch1TownIntroDone=true` + `hour:21`（夜晚），跳过首进镇剧情干扰（延续 Sprint3 探针 M3 教训：首次进镇剧情是延迟 auto 事件，可能与 E 输入抢交互）。
