## 二、三个验收问题的回答

### Q1：第一次玩家是否知道自己该做什么？→ ✅ 知道，且比 v0.9 好很多

| 节点 | 指引方式 | 判断 |
|---|---|---|
| 车站 | 移动提示 DOM「向右走出车站」（含摇杆/移动，无 WASD 键名） | ✅ 明确 |
| 大门 | 夏雅对话给钥匙 → 背包使用 → 开门（坏档自愈兜底） | ✅ 有引导 |
| 锄地 | 对白 + hint「对着农田区域按 [E] 锄地，清理 3 块土地」 | ✅ 明确 |
| 播种 | hint「按 [R] 切换到萝卜种子，对着锄过的土地按 [E] 播种 ×3」 | ✅ 明确 |
| 浇水 | hint「对已播种的土地按 [E] 浇水，为所有作物浇水」 | ✅ 明确 |
| 收获 | 萝卜 1 天成熟，day2 清晨成熟即可收（首次收获有夏雅见证） | ⚠️ 成熟时机无主动提示（见 §五·P2-3） |
| 交付后 | QuestPanel 追踪 + 观星点白天「坐等天黑」选项 | ✅ 明确 |

**结论：不存在"到农场后不知道下一步"。** 教程四步每一都绑定了 hint 与目标数。

### Q2：玩家有没有理由继续玩到观星？→ ✅ 有，节奏基本成立

- 萝卜 1 天成熟：day1 播种浇水 → 睡觉 → **day2 清晨即有第一次收获**，第一次收获即回应对白（"它真的长出来了"），情绪闭环早于观星成立。
- f7 将主线委托推迟到 day2：玩家先在农场完成"安顿→收获→清晨回应"，再去小镇接任务 → 后山 → 交付 → 夜晚观星。**节奏曲线：慢→快→收束**，符合"先相信这里值得留下，再看过去"。
- 等待点（交付后到 20:00）：有 WaitPanel「等到入夜」+ 观星点「坐等天黑」双通道主动快进，**不干等**。

⚠️ 轻微风险（P2）：day1 无主线目标，只有种田+睡觉，活跃玩家可能觉得"今天就这样了"——但这是设计意图（安顿日），不建议改。

### Q3：结束时有没有记住一个画面？→ ✅ 有（但观星演出当前**没有探针能证明其稳定可到达**）

观星夜（v0.10.4 已升级）提供：
- 三段镜头（人在岛上 → 我做过的事留在世界 → 星空展开）
- 星空 + 银河 + 流星 + 远景小镇灯光
- 爷爷的信 + 三选项（留下来 / 弄清爷爷经历 / 没想好怎么回城市）
- 归星记录手账（五段叙事，非结算页）——**正是"结束想留下的画面"**

**但 §四·A 暴露观星夜在探针 debug 路径下不可稳定复现**——P2 观星升级前必须先解决验证空白，否则"观星最后一句话"无法被证明。

## 四、发现的问题

### A. ⚠️ 观星夜演出串台（探针复现；真实玩家路径低风险，但需修防御）

**现象**：`probe-stargaze.mjs` 8 项失败——按 E 触发观星后，`step` 直达 `observatory_complete`，但读到的对白是「清晨。阳光从老屋的窗户透进来……」（FIRST_MORNING_RESPONSE），而非观星夜 DEMO_ENDING。

**根因**（已定位代码）：
- `startStargaze()`（MapScene.ts:4924）标记 `inStargazeCutscene=true`，但 DEMO_ENDING 要等**三段镜头（2s+3s+3s=8s）完成后才 `play()`**。
- `tryFirstMorningSequence()`（MapScene.ts:1850）的**入口**有 `inStargazeCutscene` 守卫，但其内部 `time.delayedCall(2600, () => play(FIRST_MORNING))`（MapScene.ts:1872）**没有二次守卫**。
- 探针 debug 快进路径：day2 首次进 farm 时 first_morning 尚未触发（真实玩家 day2 清晨已触发过、夜间不受影响）→ 清晨对白在 2600ms 插入，覆盖了还在镜头期的观星对白。

**真实玩家影响**：低（first_morning 在 day2 清晨 `triggerOnce` 持久化，夜间观星不会重复）。但这是**防御缺口**——任何"day2 从未进过 farm 直到夜晚"的边界路径都会复现。

**建议**：delayedCall 回调里补 `if (this.inStargazeCutscene) return;`（一行防御），同时修探针（先在观星前正常触发 first_morning 或注入 `hasTriggered('first_morning_response')`）。

### B. ⚠️ 探针陈旧（非游戏缺陷）

- `probe-first-playtest-audit.mjs`：Q2/Q3 失败——它直接走近碎片 (328,184) 按 E，但 v0.10.2 起碎片上方先有观景台一次性对白（FOREST_LOOKOUT），导致碎片对话未触发 → questState 停在 accepted。**是探针未适配后山两段式，游戏本身正确**（ch1-walkthrough 用观景台→碎片两段式走通了）。
- 观星节点同样读到清晨文本（与 A 同根因）。

**建议**：下批与 A 一起修探针，或归档这两条，保留 ch1-walkthrough + mobile-text 作为回归基线。

## 六、总体结论

**v0.10 情感重构批次（P0-1/2/3）验收通过（除观星夜待验证项）。**

- 主链路 0 运行时错误，情绪曲线七个节点全部达标，三问回答两问强通过、一问有条件通过。
- 玩家 30 分钟内走通「车站→安顿→收获→小镇→后山→交付→观星」具备现实可行性。
- 下一个真正的"导演"工作是：**把观星夜这一句话在真机上稳定地讲出来**（P1 守卫 → 探针基线 → P2 观星升级 → 配音）。

> 一句话总结：**现在缺的不是内容，是把最后一句话稳定地讲完。**
