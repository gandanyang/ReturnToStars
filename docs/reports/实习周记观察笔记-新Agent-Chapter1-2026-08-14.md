## 二、Task 2 理解：为什么中央广场是视觉中心

依据《青禾镇场景分析 v0.1（v0.2 评审）》+ 《青禾镇舞台块定义 v1.0》+ 瓦片/坐标还原。

### 2.1 现状问题（分析给出的判断）

- **几何中心 ≠ 视觉中心**：交叉口（x24-25, y17-18）在 HEAD 版本是「十字路穿草地」，不是「广场」。
- **视觉重点与生活重点错位**：全图最重的视觉质量在北石板（x10-39, y0-7），但它是空的；生活发生（7 NPC / 商店 / 售货机 / 需求板）全部扎堆在中央的草地+路上——人站在马路中间。
- **四民居严格对称** → 注意力被平均分配，无主次锚点。
- **最有故事的两点（S4 宅基地 / 老街区 B 街屋）不在动线交汇处** → 当不了中心。

### 2.2 中央广场是「视觉中心」的成立逻辑

1. **它是全镇唯一的规则几何中心**：交叉口 + 石板广场 + 十字路（竖路 col24-25 穿心、横路 y17-18 东西贯通），玩家进镇可一眼识别「这里是镇心」——补足「三镜叙事」的第三镜（中央广场=现在的人）。
2. **它是生活发生点的集合**：7 个 NPC + 商店 + 售货机 + 需求板全部落在 x20-29, y15-20 矩形内。石板化后，NPC 从「站在路上」变为「站在广场上」。
3. **它是未来内容的物理容器（制作人原话）**：为春日集 / 小吃摊 / NPC 活动 / 夜晚灯光预留「有人聚在一起」的舞台——否则后续加小游戏只是往空地上塞东西。
4. **记忆点优先于瓦片**：一棵大树 > 10 个小装饰；中央广场是地图最缺的「我为什么记住这里」。

### 2.3 我的独立验算（坐标级，读代码 + 解码瓦片）

- 7 个 town NPC 站位（tile）：elder(23,18)、shopkeeper(26,18)、mystery(25,16)、miner(24,20)、gardener(28,18)、adventurer(22,20)、carpenter(20,17)——全部落在 x20-29, y15-20 之内。✅ 佐证「NPC 扎堆」。
