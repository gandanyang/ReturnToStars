## 二、六类问题清单（按审查维度）

### 1. 角色 OOC

- **镇长「为什么种田」**：守望者语言被写成"主题播报员"——7 连解释不属于镇长会说的话，遮名可辨失败风险最高的一条。
- **夏雅「你在这里，就足够了」**（观星夜）：夏雅是行动派（拿工具/修东西），突然说抽象抒情，靠近 OOC。
- **林澈教学独白密度**（F1 已知未全落地）：gate/sow/water 三处"程序员 vs 土地"对比仍密集，woodcut/mine 两句最有记忆点；建议 gate/sow/water 三留一。

### 2. AI 味过重

- 集中点：`ELDER_WHY_FARM_DIALOGUE`（演讲 + 内部重复 + 解释型）。
- 次要点：观星夜 tonight 连续漂亮句；阿风 welcome 末句。
- 其余实装对白（钓鱼交换、邮箱、老姜、老周 A1 版）达标。

### 3. 主题偏移

- **无重大主题偏移**。第一章守住"生活驱动"（复兴=生活重新发生，非设施堆砌）；第三章禁词（开发/旅游/商业/网红/游客/打卡）已核对实装台词 **零命中** ✅。
- 唯一偏移风险：镇长「为什么种田」把"生活主题"讲成"道理"——从"让生活发生"滑向"解释生活意义"，建议弱化。

### 4. 剧情逻辑

- **`ch1ElderChoice` 死旗**（P1-②）：玩家选择无消费，属剧情逻辑断点。
- 星碎片交付 → 立刻接 7 句种田演讲：把交付情绪冲淡，衔接略跳（P1-①）。
- 神秘少女「你也捡到过？」信息权限：她知道林澈捡了碎片（森林深处偶遇），勉强可解释，建议加一句她也在找的行为证据。

### 5. 重复信息

- 镇长「看星星」三版对话（QUEST / RETURN / BUSY）开头重复自我介绍——A4 RETURN 已去重 day1 见过路径；**day1 未见过路径仍逐句重复**，跨天重演感 H1 仅部分解决。
- 「星星亮」3 处近句（P1-⑤）。
- 老周口头禅 2 处近句（P1-④）。
- 已确认删除：阿风后山×2（E1）、浇水三行同主题（B1）、观星夜"会有人回来"×3（C1）、碎片规则×2（D1）——✅ 均落地。

### 6. Flag / Quest 状态问题

- **`ch1ElderChoice`**：`'help' | 'unsure'` 入档但零消费（P1-②）。
- **`questState` vs `storyStep` 双轨**（P2-⑦）：当前恢复逻辑 OK，需长期防漂移。
- ✅ 健康项：`elder_starter_gift` triggerOnce 防重复；`fishReleaseDay` / `fishXiyaExchangeDay` 走 mapFlags；邮件世界信 `ready()` 用 isRestored/hasTriggered 条件插队；灯塔 `lighthouse_lit_seen` 一次性 + 与入口 locked 的体验断裂已补旁白修复（2026-08-15）。
