## 一、项目定位

**归星物语**（Return To The Star Island）是一个 Phaser 3 + TypeScript 横屏移动端独立游戏。

核心体验：一个疲惫的人回到故乡，通过修复环境、帮助居民、恢复生活气息，重新找到自己的节奏。

**当前阶段**：第0章 Demo 已冻结，第一章「复苏」开发中。
**核心判断**：项目已从「缺功能」阶段进入「Vertical Slice 已成型，需要证明好不好玩」阶段。

## 三、技术架构要点

### 3.1 技术栈
- **引擎**：Phaser 3 + TypeScript
- **构建**：Vite
- **平台**：移动端（Capacitor 打包 APK），**只支持横屏**
- **存档**：localStorage，SaveSystem v0.5

### 3.2 核心系统模块

| 模块 | 文件 | 说明 |
|---|---|---|
| ChapterSystem | `src/systems/ChapterSystem.ts` | 章节状态（CHAPTER_0/1/2），`getChapter()` / `setChapter()` / `isChapterAtLeast()` |
| EventManager | `src/systems/EventManager.ts` | 一次性事件，`triggerOnce(id, fn)` / `hasTriggered(id)` / `markTriggered(id)`（只标记不执行 fn） |
| SaveSystem | `src/systems/SaveSystem.ts` | `save()` / `load()` / `apply(data)` / `hasSave()` |
| FarmRestore | `src/data/FarmRestore.ts` | 世界恢复点，`markRestored(key)` / `isRestored(key)` |
| HouseTidy | `src/data/HouseTidy.ts` | 老屋整理等级，`getHouseTidyLevel()` 返回 0-4（从 EventManager 派生，零新增存档字段） |
| StorySystem | `src/systems/StorySystem.ts` | 剧情步骤 `StoryStep`，`getStoryStep()` / `setStoryStep()` / `advanceStory()` |
| TimeSystem | `src/data/TimeSystem.ts` | `setTime(hour, min)` / `setTimeFull(day, hour, min)` / `nextDay()` |
| Economy | `src/data/Economy.ts` | `getCoins()` / `setCoins(n)` / `addCoins(n)` |
| DevTestHub | `src/dev/DevTestHub.ts` | 开发者测试种子档（仅 DEV 构建） |

### 3.5 存档结构（SaveData）

```ts
interface SaveData {
  version: string;       // '0.5'
  player: { x, y, scene, facing, inventory, lockedItems };
  world: { day, hour, minute, coins, level, xp, stamina, minedOres, questState };
  farm: { tiles, crops, trees, automation };
  worldRestore?: Record<string, boolean>;  // 恢复点
  story: { storyStep, ch1TownIntroDone? };
  mapFlags?: MapSceneFlags;
  album?: string[];
  gameState?: { triggeredEvents: Record<string, boolean> };  // 一次性事件
  chapter?: number;
}
```

### 3.6 测试体系

- **探针**：`tests/probes/probe-*.mjs`（Puppeteer 自动化浏览器测试）
- 运行方式：`node tests/probes/probe-*.mjs`（需先启动 `npm run dev`）
- **测试纪律**：按修改影响范围分级（Level 0-3），禁止默认跑全部测试（详见 `docs/dev/TestSystem.md`）

### 3.7 调试 API

`window.debug` 挂载了所有核心系统的调试接口（`getChapter` / `setChapter` / `events.hasTriggered` / `getHouseTidyLevel` 等），可在浏览器控制台直接调用。
