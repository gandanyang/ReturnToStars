## 一、章题与主题（一句）

第一章 **《归园新序》**（开发副题「复苏」）：**一个疲惫的人回到故乡，通过整理老屋、修复集市，让原本存在的生活重新发生，第一次相信「我的行动正在让这个小镇慢慢变好」，从而决定留下。**

> 系列定位：第0章《归星》＝「回来了／试着留下」；**第1章＝「住下了，开始生活」**；第2章候选＝「融入了」；第3章候选＝「守护了」。

## 二、剧情目标（玩家要体验到什么）

- **一句话验证情感**：玩家从「我为什么回来」走向「**为什么我要留下**」。
- 复兴不是建设更多东西，而是**让更多生活重新发生**（人回来 / 灯亮 / 集市开 / 孩子跑）。
- 承制人原则：**安顿是叙事不是装修（零数值）、余波靠生活不靠播报、复兴是邀请不是任务板**。
- Fun Hypothesis：一个人先把自己安顿下来，然后他周围的人开始重新相信——这个地方可以活回来。
- 章节时长规划 60~120 分钟；红线＝观星夜是唯一章节切换点（D-025）、零新系统、章末演出 ≤ 观星夜 40%。

## 四、关键人物第一章戏份

- **林澈**：从「回来的人」变「开始生活的人」——整理老屋、回应村长邀请、交付集市、布置摊位；第一章即「重新选择归处」。
- **夏雅**：核心引导/情感角色。day2 邀约复兴、集市花摊、·一心语（主旨=「让她被第一次理解」，不展开恋爱/释怀）；埋秋日晒场伏笔（口径 2026-08-29 统一）。
- **镇长（村长）**：复兴的「邀请者」而非任务板；整理完毕夜晚来访「要不要一起试试」；春日集反馈台词。
- **阿风（冒险家）**：第一章为「种子级」——集市热闹台词＋欢迎闲聊＋埋「追风」伏笔；完整《追风的人》冻结至 Beta。
- **花匠小梅**：集市小吃摊居中（参与生活链一环）；自然引导/昆虫观察中的科普者。
- **矿工老张**：集市工具摊靠路边；「这个秋天」收成链代表「过去·旧手艺」。
- **神秘少女**：第一章几乎无正面戏份（仅观星夜前后旁白 hook）；星轨守护者身份层主线不参与生活化内容。
- **木匠老周**：集市热闹台词分支；第0章回归角（建设反馈）；第一章非核心。
- **商店老板**：集市/春日集行动型反馈台词（「油锅一起，这味儿就对了」）。

## 五、章末收束

已实现＝**春日集**（克制版最低档）：一次性 `ch1_spring_fair`，无镜头链/无选项，末尾灯塔钩子埋第二章。
设计指向＝`章节终点-集市重开之夜-赶大集质感`（红蓝布棚/油锅/叫卖/熟人碰面/散集余温），其中 3 项仍待制作人确认；已实装为克制最低档。
可扩展收束＝**《秋日晒场》**（章末「全镇第一次回应玩家」，立意「不是庆祝丰收，而是证明这里还有人在生活」）——设计定稿+任务卡已出，约 8 人日，**尚未施工**，以「玉米收成＋春日集后」触发。

## 六、与相邻章节的衔接

- **与第0章《归星》**：观星夜为唯一切换点；情绪「为什么回来→为什么留下」；day2 清晨兑现第0章爷爷笔记「岛屿会记住照顾它的人」的埋钩。夏雅线顺序铁律＝**世界恢复→居民关系恢复→个人故事展开**。
- **与第二章《故人远来》（未施工）**：衔接句＝「把自己安顿下来→镇子重新发光→光被远处的人看见→有人愿为它回来」。钩子＝章末灯塔/旧信线索；第二章以「集市重开后镇民传说外面有人问起这里」＋一封旧信承接。
