> 版本：2026-08-12（第一章 Sprint 1-3 + P3 春日集已全部施工完毕）
> 适用：制作人/手动测试。想自己上手玩第一章，不看长篇第 0 章流程。

> ⚠️ 项目红线：**移动端只支持横屏**。桌面浏览器测试请把窗口拉成横屏比例（探针用 1024×768）。

## 一、第一章剧情链总览（6 个节点，按触发顺序）

```
观星夜完成 → chapter=1（D-025 唯一合法切换点）
   ↓
① day2 清晨「岛屿的第一声回应」   farm 场景   夏雅出现在老屋门口，自动对白，注入复兴任务
   ↓
② 首次进 town（TOWN_INTRO）      town 场景   第一章小镇开场对白
   ↓
③ 老屋整理（4 交互点）            house 场景  床→灯→书桌→收音机 → ch1_house_tidy_done
   ↓
④ 村长来访（复兴计划邀请）        house 场景  整理完成 + 下一晚进老屋 → 敲门 → 5 句对白 + 选项
   ↓
⑤ 集市广场恢复                    town 场景  村长来访后解锁 → 交付 木材25+石头15+金币80 → 三反馈
   ↓
⑥ 春日集（第一章结束演出）        town 场景  夜晚 + 集市已恢复 → 灯火+人影+人群声+独白+灯塔钩子
```

每个节点的触发条件明细：

| 节点 | 触发条件（全部满足） | 关键存档字段 |
|---|---|---|
| ① 第一声回应 | `chapter>=1` + `day>=2` + 教程完成 + 进 farm + 未触发 `first_morning_response` | `chapter:1`、`story.storyStep:'done'` |
| ② TOWN_INTRO | 第一章首次进 town + 未 `ch1TownIntroDone` | `story.ch1TownIntroDone` |
| ③ 老屋整理 | `chapter>=1` + house 场景 | 逐点 `ch1_bed/lamp/desk/radio_done` → 聚合 `ch1_house_tidy_done` |
| ④ 村长来访 | ③完成 + 夜晚（hour>=20 且 day 已推进）+ 进 house + 未触发 `ch1_elder_visit` | `ch1_house_tidy_done`、`mapFlags.ch1ElderVisitDay`、`ch1_elder_visit` |
| ⑤ 集市修复 | `chapter>=1` + `ch1_elder_visit` 已触发 + town 场景（集市区） | `ch1_elder_visit`、交付后 `worldRestore.marketSquare=true` |
| ⑥ 春日集 | ⑤完成（集市恢复）+ 夜晚（hour>=20 或 <6）+ 进 town + 未触发 `ch1_spring_fair` | `worldRestore.marketSquare:true`、`ch1_spring_fair` |

## 二、最快路径：F12 控制台种子档（推荐，约 30 秒）

> 原理：直接向 `localStorage` 写入存档（key=`return_star_save`），刷新后游戏按存档恢复直达指定节点。种子档结构与探针验证过的一致，**不会破坏旧存档**（写前自动备份到 `old_save_backup`）。

**操作步骤**：
1. 打开 http://localhost:5173/ ，按 `F12` 打开开发者工具 → Console
2. **先把这段备份脚本粘贴执行一次**（防止误覆盖现有存档）：
   ```js
   const _s = localStorage.getItem('return_star_save');
   if (_s) localStorage.setItem('old_save_backup', _s);
   console.log('原存档已备份到 old_save_backup');
   ```
3. 按下面"种子档"任选一段粘贴执行 → 页面自动刷新 → 直达目标节点
4. 测试完想恢复原档：`localStorage.setItem('return_star_save', localStorage.getItem('old_save_backup')); location.reload();`

> 💡 想回到新游戏：`localStorage.removeItem('return_star_save'); location.reload();`

### 种子 ①：第一章入口（day2 清晨，farm）—— 看「岛屿的第一声回应」

```js
localStorage.setItem('return_star_save', JSON.stringify({
  version: '0.5',
  player: { x: 400, y: 300, scene: 'farm', facing: 'down', inventory: { wood: 40, stone: 30 } },
  world: { day: 2, hour: 7, minute: 0, coins: 300, level: 1, xp: 0, stamina: 100, minedOres: [], questState: 'not_started' },
  farm: { tiles: [], crops: [], trees: [] },
  story: { storyStep: 'done' },
  chapter: 1
}));
location.reload();
```

**看什么**：进 farm 约 1-2 秒后自动触发——窗外阳光旁白（鸟叫/风吹树叶）→ 夏雅出现在老屋门口看农田 → 自动播对白 → 结束后注入复兴任务（收获/种植/清理），HUD 出现「让农场重新运转起来」目标。

## 三、从新游戏正常玩到第一章（完整路径，供参考）

不想改存档时，正常通关第 0 章即可自动进入第一章（观星夜完成 → `setChapter(1)` → 存档）：

1. 新游戏 → 车站教程（对话可按 E/点击跳过）
2. 进镇 → 见镇长 → 森林采集星之碎片 → 交付 → 观星夜（三选项）
3. 观星夜结束后弹结算 → 存档 chapter=1 → 第一章开始

> ⚠️ 注意：第 0 章 Demo 已冻结，观星夜是**唯一**合法章节切换点（D-025）。不要用 `debug.setChapter(1)` 修改正在运行的章节（只改内存不改存档，刷新即回 0）；要跳章节请用上面的种子档。

## 四、Debug API 速查（控制台可用，测试辅助）

| API | 作用 |
|---|---|
| `window.debug.setTime(h, m)` | 设置当前时间（如 `setTime(21, 0)` 切夜晚） |
| `window.debug.nextDay()` | 结束今日，推进到次日 06:00 |
| `window.debug.giveItem('wood', 40)` | 给物品（wood/stone/gold 等） |
| `window.debug.getChapter()` | 查看当前章节 |
| `window.debug.getHouseTidyLevel()` | 老屋整理进度（0-4） |
| `window.debug.isHouseTidyComplete()` | 老屋整理是否完成 |
| `window.debug.events.hasTriggered('ch1_elder_visit')` | 查询一次性事件是否触发 |
| `window.debug.events.markTriggered('ch1_elder_visit')` | 强制标记事件已触发（跳过前置） |
| `window.debug.getStoryStep()` | 查看剧情步骤 |
| `window.debug.sfx('crowd')` | 试播音效（如人群声） |

> ⚠️ `setTime/nextDay/giveItem` 只改运行时内存，**改完需触发一次存档才写入**（如睡觉/交付/演出结束自动存档）。纯查看没问题，用来推进剧情请用种子档或正常交互。

## 五、测试注意事项

1. **横屏**：窗口保持横屏比例（如 1024×768），禁止竖屏验收。
2. **存档 key**：`return_star_save`。种子档覆盖前已自动备份到 `old_save_backup`，随时可恢复。
3. **一次性事件**：①/④/⑥ 均为一次性（`triggerOnce`），重复测试需刷新种子档（刷新即重新写入全新触发态）。
4. **触发延迟**：各演出均有 1-2 秒延迟（`time.delayedCall`），进场景后稍等再看，别急着按 E。
5. **首次进镇干扰**：种子 ③④⑤ 已带 `ch1TownIntroDone:true` 跳过 TOWN_INTRO；若去掉了它，进 town 会先播首次进镇对白。
6. **遇到问题**：把浏览器 console 报错和当前节点发给我（如「种子④资源不足提示没弹出」）。

## 附：种子档结构说明（想自己拼档用）

```js
{
  version: '0.5',
  player:   { x, y, scene: 'farm'|'house'|'town', facing, inventory: { wood, stone, ... } },
  world:    { day, hour, minute, coins, level, xp, stamina, minedOres: [], questState: 'not_started' },
  farm:     { tiles: [], crops: [], trees: [] },   // 必须存在！SaveSystem.load 结构校验要求（SaveSystem.ts:233）
  story:    { storyStep: 'done', ch1TownIntroDone?: true },
  chapter:  1,                                   // 缺省=0（旧档兼容）
  worldRestore: { marketSquare?: true },          // 集市恢复态
  mapFlags: { ch1ElderVisitDay?, ch1ElderChoice? },
  gameState: { triggeredEvents: { 'ch1_elder_visit'?: true, 'ch1_house_tidy_done'?: true, ... } }
}
```

> ⚠️ `farm` 字段不能省：存档读取时有结构完整性校验（[SaveSystem.ts:233](file:///g:/ReturnToStars/src/systems/SaveSystem.ts#L233-L236)），缺 `player/world/farm/story` 任一字段都会被当作无存档，重新走新游戏流程（种子档全部已验证）。
