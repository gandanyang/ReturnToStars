## 一、Bug 清单

### 🔴 Bug 1：`probe-nature-p0.mjs` 6 失败 — Vite 动态 import 双实例（确定）
- 现象：`getCurrentState`/`getTimePhase`/`getWeatherToday` 在 `setTimeFull` 后仍返回初始值（day12/25/40 全 germination、13/19/21 时全 dawn）。
- 根因：探针用两条独立动态 import（`/src/data/TimeSystem.ts` 与 `/src/systems/NatureSystem.ts`），Vite dev 下 NatureSystem 内部 `import '../data/TimeSystem'` 解析成**第二个实例**。决定性验证：`ts.getTime().day=25` 但 `ns.getWeatherToday()`=clear（应为 rain）。
- 影响：**产品代码不受影响**（NatureSystem 当前未被运行时引用；生产构建合并单实例），但**探针必须修**，否则失去回归保障。
- 修复方向：探针不自行 import TimeSystem，走 NatureSystem 测试入口或统一相对路径。

### 🔴 Bug 2：Dev 经济工具 / debug 污染玩家位置存档（真实，低概率）
- 位置：`DevTestHub.ts` 经济按钮、`main.ts` debug.markRestored 均用 `save({x:0,y:0,scene:''})`。
- 后果：刷新重进时 `MapScene.create`（L1188）检测 `scene !== 'farm'` → `scene.start('')` → 空场景/黑屏。
- 触发：点工具后**立即刷新**（继续玩会因下次睡觉重写正确位置）。测试后门可接受，但 `scene:''` 是隐患。

### 🟡 Bug 3：`probe-fishing-phase4.mjs` 不稳定（2~3 失败，两次运行 23/2 与 22/3 不一致）
- X1 真实路径"选项换"/"键盘选换"返回 `triggered:false`、X6 小场景一次性偶发失败。
- 属**探针时序不稳定**（选项交互 + triggerOnce 契约竞态），非稳定产品 bug。
