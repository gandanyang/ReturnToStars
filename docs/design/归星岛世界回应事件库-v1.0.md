# 《归星岛世界回应事件库》v1.0

> **状态：** 📋 P2.5 设计交付（2026-08-10 制作人排期新增）｜设计冻结，不改代码
> **定位：** **中间层**——玩家行为与区域变化之间的"岛如何回应玩家"。**不是写任务，是写反应类型。**
> **目的：** 防止未来滑回传统开放世界（"修完 A → 获得 B → 开 C"），让灯塔/码头/老街/温泉任何区域都不会跑偏
> **依据：** `docs/design/归星岛核心叙事原则-v1.0.md`（新区域 = 玩家行为带来的世界回应）、`docs/design/岛屿未来扩展路线-v1.0.md`（P2）
> **红线：** 不写任务 / 不新增 NPC 作为"奖励" / 不做"任务完成即解锁"的机械响应 / 复用现有机制（triggerOnce / 台词池 / NPC 行为 / 环境叙事）

---

## 一、为什么需要这个中间层

当前有：
- **玩家行为**（修码头、恢复道路、修灯塔……）
- **区域变化**（灯塔亮起、航线恢复、人回来……）

中间缺的是：**岛如何一步步回应玩家**。

如果跳过这一层，未来区域设计容易变成"地图部门需求"：

> 修完 A → 获得 B → 开 C。

而《归星物语》的世界回应应该是**渐进、分次、可感知的**。

---

## 二、核心原则

1. **不是任务，是反应类型**——先定义"岛会以什么方式回应"，再谈具体触发点
2. **分次递进**——同一个事件分 3 次出现（第一次：细节变化 → 第二次：有人注意 → 第三次：状态改变），不做"一次完成"
3. **不让 NPC 成为奖励**——NPC 出现不是"任务奖励"，是"玩家让这里值得回来"的自然结果
4. **已有 NPC 生活半径扩大**——不是增加 NPC，而是让已有 NPC 开始做以前不做的事
5. **复用现有机制**——triggerOnce / 台词池 / NPC 行为 / 环境叙事，零新增系统

---

## 三、反应类型库（类型模板，非具体任务）

### 类型一：人回来（分次递进）

**触发前提**：玩家修复了某个"人曾经离开的地方"（码头 / 道路 / 港口）。

**回应节奏**（3 次，不一次到位）：

| 次 | 玩家看到 | 玩家感受 |
|---|---|---|
| 第一次 | 环境细节变化（如海边多了一盏旧船灯） | "这里好像有人在意了" |
| 第二次 | 有人问起（如"码头还能不能用？"） | "有人在等它恢复" |
| 第三次 | 状态改变（如一艘旧船停靠） | "离开的人真的回来了" |

> ❌ 错误：修码头 → 新 NPC 解锁（任务奖励感）
> ✅ 正确：修码头 → 海边多一盏旧船灯 → 有人问码头还能不能用 → 一艘旧船停靠

### 类型二：旧物重新产生意义（分次递进）

**触发前提**：玩家修复了某个"已经失去意义的东西"（灯塔 / 老屋 / 旧设施）。

**回应节奏**（3 次）：

| 次 | 玩家看到 | 玩家感受 |
|---|---|---|
| 以前 | 老人说"那东西坏了很多年" | 失落（基线） |
| 第一次 | 细节变化（如镇长发现有人擦过灯塔玻璃） | "有人在重新对待它" |
| 第二次 | 有人行动（如夜里第一次出现远处船灯） | "它重新有了用途" |

> ❌ 错误：修灯塔 → 灯塔功能开启（机械解锁）
> ✅ 正确：修灯塔 → 有人擦过灯塔玻璃 → 夜里第一次出现远处船灯

### 类型三：居民行为变化（生活半径扩大）

**触发前提**：玩家持续帮助某个 NPC / 区域。

**回应节奏**（对比式）：

| 状态 | 老周行为 |
|---|---|
| 没有玩家时 | 修自己的东西 |
| 玩家帮助之后 | 开始帮别人修 |

**重点**：不是增加 NPC，而是**已有 NPC 的生活半径扩大**——玩家能直接看到"我的帮助让他开始关心别人"。

---

## 四、如何使用（设计时自检）

设计任何区域 / 事件时，先回答：

1. **这个区域 / 事件的回应是分次的吗？**（至少 3 次渐进，不做"一次完成"）
2. **回应里有没有"人"？**（不是只有状态变化，要有人注意到、有人行动、有人回来）
3. **NPC 是"奖励"还是"结果"？**（如果是"修完解锁新 NPC"，重写为"岛值得回来 → 人自然出现"）
4. **有没有复用现有机制？**（triggerOnce / 台词池 / NPC 行为 / 环境叙事）

若第 1 或第 2 条答否，回到"反应类型库"重写。

## 五、与既有路线的衔接

| 既有路线 | 本事件库提供的回应 |
|---|---|
| P2 灯塔链路（修复→亮起→航线→人回来） | 类型一 + 类型二（分次递进：灯玻璃→船灯→航线） |
| P2 码头链路（恢复供应→旧船靠岸→人回来） | 类型一（旧船灯→有人问→船停靠） |
| P2 老街（老店铺重开） | 类型三（已有居民开始帮别人） |
| P1 碎片（收集→解锁→揭示） | 每次解锁 = 一次"类型一/二/三"的完整回应循环 |

## 六、红线

- ❌ 不写具体任务（本库只定义反应类型，触发点交给具体区域方案）
- ❌ 不让 NPC 成为"任务奖励"
- ❌ 不做"修完 A → 获得 B → 开 C"的机械响应
- ✅ 所有回应必须是分次、可感知、复用现有机制

> 完成一个闭环 > 添加十个半成品。
