## 〇、制作人拍板项（2026-08-14）

1. **名字：老姜**（「江叔」作废；「老周」为木匠，不混用）
2. **外观：草帽大叔**（靛蓝旧衫 + 深色描边 + 亮草帽 + 竹竿 + 小板凳 + 脚边茶杯 + 脚底投影；当前为程序绘制零素材，正式 32×32 精灵后置走美术管线）
   - 2026-08-14 配色修正：原灰衫/土色系与草地木台融为一体，改为深描边 + 靛蓝衫（与背景绿/棕拉开色相），保证剪影第一眼可读
3. **教学：简单易懂，不故弄玄虚**——不弹窗、不说教、不"坐得住"式玄虚开场；直接讲怎么收竿
4. **小事件：《老姜的钓鱼修行》**——三鱼入门（青禾鲫/河虾/黄昏鱼都给老姜看过）→ 送出旧鱼竿纪念物
5. **剧情调味：老姜喜欢钓鱼，老婆嫌弃他不务正业——轻微吐槽，不尖锐矛盾**

---

## 一、角色定位（不变）

- 青禾镇最后一个还坚持每天去河边坐一下午的人——**氛围锚点，不是任务机器**。
- 无感叹号、无任务图标、无强制触发；错过老姜不影响钓鱼/交换。
- 语言指纹：话少、慢、带河/水/时间意象；老婆吐槽是"生活气"，不是家庭矛盾。

---

## 二、作息与在场

- 每天 **13:00-17:00** 在 S6 河堤（世界 84,232，钓点南侧岸线）坐着钓鱼；其余时段"收竿回家"（视觉隐藏 + 不可交互）。
- 交互：靠近按 E（范围 30px，优先级高于钓鱼提示——人在旁边先说话，站到水边才钓鱼）。

## 三、对白结构（已实现，按优先级）

### ① 教学（一次性 `fisher_teach_done`）

简单直白版（制作人方向：不要故弄玄虚）：

> 老姜：钓鱼啊，不难。
> 老姜：抛竿下去，盯着浮漂。
> 老姜：浮漂一沉，就收竿。
> 老姜：收早了鱼会跑，等它咬实了再拉。多试几次，手就有数了。

### ② 鱼种评价（一次性每种：`laojiang_see_qinghe / laojiang_see_shrimp / laojiang_see_dusk`）

- 青禾鲫：「小鲫鱼，小时候我天天吃。」
- 河虾：「河虾啊……以前河边一捞就是一碗。」
- 黄昏鱼：「黄昏鱼？这个点来钓，会钓鱼。」

钓到什么 = 被老姜记住（不消耗鱼，纯评价）。

### ③ 《老姜的钓鱼修行》完成（一次性 `laojiang_practice_done`）

三鱼都给老姜看过 → 入门完成 → **送出旧鱼竿**（新物品 `old_fishing_rod`「老姜的旧鱼竿」，forbidden 不可售）：

> 老姜：青禾鲫、河虾、黄昏鱼——三种都见过了。算你入了门。
> 老姜：这根竿子跟了我大半辈子，送你。以后河边修行，就咱俩了。
> 林澈：……老姜，你老伴儿不念叨你吗？
> 老姜：念叨。说我整天跟鱼过不去，不务正业。
> 老姜：……鱼也没说什么。

### ④ 复兴台词变体（一次性 `laojiang_revival_line`）

集市恢复后：

> 老姜：集市又开起来了……河边也热闹了。
> 老姜：年轻时候嫌吵。老了才知道，没人吵才是真的安静。……不过，热闹点也好。

### ⑤ 日常台词（按天轮换，含老婆轻吐槽）

偶日：

> 老姜：我那口子说我这是不务正业。……她说她的，我钓我的。

奇日：

> 老姜：坐得住，才钓得到。

## 四、技术实现（零新系统）

| 能力 | 实现 |
|---|---|
| 视觉 | `setupRiverbankLife` ⑬：程序绘制草帽大叔（零素材 Graphics，depth 4）+ 名字标牌 |
| 在场/作息 | `checkLaoJiangInteract`（update 每小时切换显隐；13-17 在场） |
| 交互 | `tryLaoJiangInteract`（tryInteract 内、钓鱼之前）；DOM 提示「按 [E] 和老姜聊聊」 |
| 对白 | `buildLaoJiangDialogue`（build 模式，一次性事件副作用 + 存档） |
| 一次性 | EventManager.triggerOnce（教学/评价×3/修行/复兴台词） |
| 物品 | `old_fishing_rod`（Inventory ItemType + ITEM_DEFS，forbidden 不可售） |
| 存档 | 零新顶层字段（全部 triggerOnce + Inventory 自动序列化） |

> 与 v0.1 差异：老姜采用**场景锚定交互**（Graphics 视觉 + MapScene 内处理），未走 NPCSystem 条件注册——因为当前视觉为程序绘制锚点，无独立 sprite，NPCSystem 的精灵日程不适用。后续替换正式 32×32 精灵时可再迁入 NPCSystem。
