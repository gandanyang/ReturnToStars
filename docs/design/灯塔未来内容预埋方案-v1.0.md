# 灯塔未来内容预埋方案 v1.0

> 状态：设计定稿 + 现状已落地（2026-08-10 制作人方向对齐）；**2026-08-11 调整：农场西侧缺口已石墙堵回（灯塔远景撤除）**
> 一句话：**现在先让玩家相信"未来有灯塔"，城市复兴后让玩家第一次看见"灯亮了"，再往后才开放灯塔。**
>
> **调整说明（2026-08-11 制作人反馈"灯塔影子效果不好"）**：08-10 落地时在农场西侧海湾画了灯塔远景剪影（纯 Graphics 塔影 + 呼吸 alpha），实机观感不佳。制作人拍板：**撤掉灯塔影子，西侧缺口用石墙堵回**，玩家当前看不到灯塔；未来开放时再打通缺口 + 重建海湾视觉 + 点亮灯室。锁定的入口（exits.ts locked）与 lighthouse 场景均保留，开放机制不变。

## 一、制作人定调（2026-08-10）

> "对，这次我完全明白你的意思了。你不是要做'执灯人系统'，甚至现在连执灯人 NPC 都不要做。你现在真正要做的是一个非常克制的'未来内容预埋'。"

**原则（与项目既有原则一致）：**
> 不是现在把未来做出来，而是现在让玩家相信未来存在。

**钩子已经存在**：远处的灯塔。
现在只需要给它一个非常明确的未来变化：
- 现在它是黑的。
- 有一天，它会亮。

玩家自然就会想知道："什么时候亮？"

---

## 二、三层叙事结构

### 第一层：现在（当前阶段，已落地 ✅，2026-08-11 调整为"石墙堵住"）

- **灯塔存在但不可见**（2026-08-11 调整）：农场**西侧**石墙缺口已补回（farm.json Walls 层 rows 10-13/col0 恢复 gid 3），海面/沙滩/灯塔远景剪影全部撤除（`setupFarmWestCoast` 删除）——玩家在农场看不到海也看不到灯塔，西侧就是一堵完整的石墙
- **去不了**（出口 locked：farm 西侧 → lighthouse 不可进入，locked 出口保留作未来开放占位）
- 不放执灯人 / 不点灯 / 不做任务 / 不做交互
- **当前玩法上玩家感知不到灯塔存在**——牵挂感改为由剧情台词承载（镇长码头句 / 阿风灯塔句，已有）
- 玩家自然产生："西边墙外是什么？" —— 未来开放时揭晓

### 第二层：城市复兴之后（未来实施）
- 某个城市复兴节点完成，**不需要玩家额外接任务**
- 某天玩家经过农场西侧海湾：远处原本黑着的灯塔——**亮了**
- 就这么一个变化
- 然后非常克制地给一句 NPC 台词：
  > "西边的灯塔……好像又亮起来了。"
- 到这里就结束。执灯人出现，但先不讲他的故事。玩家只知道：**原来有人回来了。**

### 第三层：更后面（未来实施）
- 再完成一组任务，灯塔正式开放
- 玩家第一次走进去，这时候才见到执灯人
- 这时候他的存在才有意义：
  > 不是"这个人一直住在那里"，而是"这个岛重新开始运转之后，有人重新回来接过了这盏灯"。

---

## 三、未来链路（设计记录）

```
城市复兴 → 执灯人归来 → 灯塔重新点灯 → 后续开放灯塔
```

## 四、状态预留（设计约定）

### `lighthouseUnlocked`（默认 false）

- 语义：灯塔是否已解锁（第二层亮灯事件是否已发生）
- 当前阶段**不加代码字段**（制作人："甚至如果你现在连这个状态都不想加，暂时都可以不加，先把设计记录下来"）
- **未来落点**：`SaveData.worldRestore`（与 `FarmRestore` 同档，可选字段，缺失=未解锁），新增 `lighthouseUnlocked: boolean`
  - 序列化：`worldRestore.lighthouseUnlocked = true`（第二层触发时写入）
  - 读取：缺失视为 false → 灯塔保持锁定 + 灯熄灭

### 解锁触发点（第二层）
- 某个城市复兴节点完成时（具体节点待制作人定：oldHouse / forestRoad 全完成？或单独节点？）
- 触发内容：
  1. `worldRestore.lighthouseUnlocked = true` 入档
  2. **重建海湾 + 点亮远景灯塔**（farm.json Walls 层 rows 10-13/col0 打通为缺口 + 恢复海面/沙滩视觉 + 灯塔灯室夜晚点亮 + 呼吸 + 光束）——`setupFarmWestCoast` 已于 08-11 删除，开放时按 MapScene.ts 中预留注释恢复
  3. 灯塔地图内部恢复暖光（`setupLighthouseVisuals` 恢复光晕/光束/地面光斑）
  4. NPC 台词一次（EventManager 管理，一次性）

### 开放触发点（第三层）
- 再完成一组任务后：
  1. `exits.ts` 中 farm 西侧出口移除 `locked: true` → 玩家可走进灯塔
  2. 出口指示箭头恢复
  3. 执灯人 NPC 在灯塔内首次出现（叙事内容待后续设计）
