## 0. 为什么需要这份衔接设计

- 现状：春深有信·一 已在游戏内落地（教学完成后下午/傍晚 farm 花田触发），但**它是"孤立支线"**——与主线进度、观星夜节点、小镇恢复没有显式衔接说明；·二《花期未至》正文已定稿但**未定义如何从主线/·一 顺承进入**。
- 本设计回答三个问题：
  1. 心语任务在主线时间线上的**解锁位置**（不早不晚）
  2. 完成后**世界/主线如何记住它**（不是一次性消耗品）
  3. ·一 到 ·二 的**承接钩子**（"下周岛上有个小活动"如何兑现）

> **制作人 2026-08-13 审阅结论（8.5/10）**：方向正确——把夏雅线从"恋爱支线"拉回"世界恢复线"；核心金句「·一让玩家认识守护者，观星夜让玩家选择留下，·二让玩家看见"留下的人一起把生活重新点亮"」确立为夏雅线设计核心。本版落实其 5 点反馈（见 §2.2 / §3.2 / §4）。

## 1. 主线时间线（第一章语境，衔接锚点）

> 依据：顶层设计 §章节（序章→第一章居民/星之碎片）+ D-021（第0章=归星 Demo）+ D-016（第1章候选「春深有信」主题=留下）

| 阶段 | 主线节点 | 锚点（游戏内） | 与夏雅心语的关系 |
|---|---|---|---|
| 0 教学 | 播种/浇水/第一次收获 | `isTutorialDone()` | **前置**：教学完成才解锁 ·一 |
| 1 初见 | 与夏雅第一次见面（教学引导对白） | `xiya_01` 等 | 建立"认识但不亲密" |
| 2 日常 | 修复庄园/种田循环/认识居民 | 星之碎片收集中 | ·一 可触发窗口（下午/傍晚 farm） |
| 3 观星夜 | 第0章收束（归属感） | `stargazeCompleted` | **·一 的"第一个反馈点"**（见 §2.2-B，非截止点） |
| 4 第一章开启 | 第1章「留下」主题展开 | `chapter1_arrival`（已实现 triggerOnce） | ·一 完成态成为"留下的理由"之一 |
| 5 小镇恢复期 | 广场/环境恢复（第一阶段主线） | `marketSquareRestore` | **·二 前置**：广场恢复后才触发（见 §3.1） |
| 6 春祭期 | ·二《花期未至》承接期 | 「下周岛上有个小活动」兑现 | ·二 从这里顺承 |

> **衔接结论 1（v1.1 修订）**：·一 在 `isTutorialDone()` 后即开放、**玩家自由选择何时做**；观星夜不是截止点，而是**第一个反馈点**——完成则观星夜夏雅特殊对白，未完成则普通对白，**两者都不阻塞主线**（长线体验，星露谷/原神式）。情绪上"认识夏雅的另一面"后进入观星夜的"留下"抉择仍是最顺路径，但不由系统强制。

## 3. ·二《花期未至》承接设计（正文已定稿，此处定义进入方式）

### 3.1 进入条件（v1.1：增加广场恢复前置）

| 条件 | 依据 |
|---|---|
| `xiyaLetterDone === true`（·一 完成） | S1 开场"还记得我上回说的那个'小活动'吗？"直接承接 ·一 D 段伏笔 |
| 主线进入第一章（`chapter1_arrival` 已触发） | ·二 属第一章"留下/建设"主题，不应在第0章内出现 |
| **`marketSquareRestore.restored === true`（广场恢复）** | **制作人 2026-08-13 拍板新增**：《花期未至》核心是"沉寂的小镇重新有人生活"——广场若还是废墟就办春祭会突兀。顺序=修复广场 → 居民开始聚集 → 夏雅提出春祭 |
| 时段：白天（S1 是午后） | 正文演出"午后阳光" |
| 场景：青禾镇旧广场 | S1/S6/S7/S8 都在旧广场 |

### 3.2 承接钩子（·一 伏笔 → ·二 兑现）

- ·一 D 段已埋："**下周岛上有个小活动**"（`letter_final_11` 台词"下周岛上有个小活动。"）
- ·二 S1 开场："还记得我上回说的那个'小活动'吗？"——**钩子直接闭合**
- **建议**：·二 触发时若间隔 ≥N 天（如 2 天），夏雅 S1 开场可加一句"说好下周的，这都过去好几天了"（衔接自然）；若同一天完成 ·一 就触发 ·二，则原句即可（**文案待制作人定稿**）

### 3.3 情绪递进（与主线"留下"主题咬合）

```
·一（教学后→观星前）: 熟悉感→好奇→遗憾      —— 认识夏雅的"守护"
观星夜（第0章收束）: 归属感（"我可以留下"）
·二（第一章，春祭期）: 期待→误解→重新理解    —— "她等的是岛重新有人生活"
```

> **衔接结论 3**：·二 不在第0章（Demo）实现，Alpha 范围保持 ·一 即可；·二 进入条件锚定"·一完成 + 第一章已开"，钩子由"下周小活动"自然兑现，正文 S1-S8 已全部就绪待实现排期。

## 4. 世界反馈链 + 第一章恢复绑定链（v1.1 新增）

### 4.1 双向反馈链

| 方向 | 内容 | 落点 |
|---|---|---|
| 主线→支线 | 教学完成解锁 ·一；第一章开启 + 广场恢复解锁 ·二 | 触发条件 |
| 支线→主线 | ·一 完成 → 花田痕迹（A，已实现）+ 观星夜呼应（B，待文案）；·二 完成 → 春祭恢复 = "岛重新有人生活"的**第一个可见集体事件**（烟花） | 世界痕迹 + 文案呼应 |
| 支线→支线 | ·一 伏笔 → ·二 兑现 | S1 开场承接 |

### 4.2 第一章整体恢复节奏与夏雅线绑定（制作人补强的关键链）

> 制作人反馈：欠缺"第一章整体恢复节奏和夏雅线的绑定强度"。补上 `小镇恢复阶段 → 夏雅活动 → 春祭` 这条链后，第一章从"NPC 故事合集"提升为"一个小镇逐渐重新活过来的章节"，与「归星岛复兴」主循环完全一致。

```
第0章：我为什么回来？
  ↓
观星夜：这里值得留下吗？          ← ·一 第一个反馈点（特殊/普通对白）
  ↓
第一章「留下」：
  阶段一 世界恢复（主线）：
    修复农场 → 修复广场（marketSquareRestore）→ 环境恢复
    └─ 玩家行为 → 世界变化（花苗 A 即此链首个实例）
  阶段二 居民关系恢复：
    居民开始聚集 / 日常回归
    ↓
  阶段三 夏雅心语：
    ·一 完成态继承 → 春祭准备 → ·二《花期未至》
    └─ 夏雅提出春祭（广场恢复后，"为什么现在办活动"成立）
  阶段四 大型反馈：
    春祭烟花 → NPC 状态变化 → 玩家确认留下
```

> **衔接结论 4（v1.1 修订）**：心语任务不是"做完就消失的支线"，而是主线"留下"主题的**情感证据链**——·一 让玩家认识守护者，观星夜让玩家选择留下，·二 让玩家看见"留下的人一起把生活重新点亮"。**顺序铁律：世界恢复 → 居民关系恢复 → 个人故事展开**（绝不反过来）。
