# 《星光艺术展》垂直切片设计稿 v0.2（拍板基线）

> 状态：✅ **制作人拍板基线（2026-08-15 逐项拍板）**——后续进入代码任务卡阶段
> 系统：小镇计划（首个事件实例）｜关联：`星光艺术展-垂直切片设计稿-v0.1.md`（已被本版替代）、`庆典筹备系统设计-v0.2-拍板方向.md`
> 开发原则：**现有系统组合，不造新系统**——第一版本质是验证循环：生活事件 → 玩家参与 → 世界变化 → 永久留下痕迹

---

## 〇、一句话

> **"把青禾镇曾经拥有的光，重新展示给世界。"**

定位（制作人拍板）：

> 青禾镇第一次主动准备迎接外界目光的**生活事件**——不是活动、不是任务、不是限时挑战。

---

## 一、EventPlan 方向（拍板）

✅ 活动模板 = EventPlan 方向。一次"筹备"= 镇子的一个生活阶段（目标 / 筹备 / 当天 / 回响 / 唯一性），每一项是**世界状态**而非数量条；每个活动一次性，完成后进入永久态。

---

## 二、C 旅人艺术家（拍板，定位调整）

✅ 季节性原型，**当天实体出现**，但**不是"活动 NPC"**。

存在意义：**第一个被青禾镇吸引回来的人。** 与第二章 A/B 区分：

| 原型 | 定位 |
|---|---|
| A 老木匠 | 曾经属于这里的人 → 回来确认记忆 |
| B 记录者 | 被这里的价值吸引 → 建立新联系 |
| **C 旅人艺术家** | 被"小镇重新发出的信号"吸引 → **成为未来连接点** |

功能（克制）：

- 开幕
- 留下一件展品
- 提供一句评价

结束。不做大量剧情；以后活动可以回来。

---

## 三、时间机制（拍板：软期限）

❌ 不做倒计时。

《归星物语》的压力来源不是"你有没有赶上活动"，而是"你有没有参与这个地方变好的过程"。

错误（经营游戏）：

```
距离艺术展还有12天
赶快收集100朵花
```

正确（生活）：

```
星光艺术展准备中

环境：
展台已完成
灯光待准备

人际：
夏雅正在设计展区

资源：
还缺少一些自然素材
```

---

## 四、资源（拍板：贝壳后置）

✅ 贝壳后置，不为填表硬加资源。

本切片使用：

- 野花（小野花/蒲公英）→ 艺术展（**采集循环首个世界变化出口**）
- 木材 → 建设（展台）
- 矿石 → 装饰（星空装置底座）
- 鱼 → 河岸生活（当晚晚餐食材）

贝壳留给灯塔观海夜（与海边绑定）。

---

## 五、菜单（拍板）

主入口：**「小镇计划」**

下面：**「星光艺术展 · 筹备中」**

"小镇计划"有未来扩展空间——丰收节 / 村超 / 灯塔夜 / 摄影展都能挂进去。

---

## 六、艺术角位置（拍板：广场东侧）

理由：北街更像商业/居民区域；东侧可连接河岸、光线、夜晚倒影，且未来灯塔方向/海边方向更容易形成视觉轴。

```
      北

  镇街

西   广场   东
        ⭐艺术角
        ↓
       河岸

      南
```

---

## 七、星空装置（拍板：复用观星夜资产，不复制）

- 观星夜 = "仰望天空"
- 艺术展 = "把星光留下"

做法：小型星光灯 / 玻璃瓶灯 / 投影装置；**不做新的大特效**。

---

## 八、验收标准（拍板：两条）

1. **永久变化**：完成后中央广场永久增加艺术角（展台 / 展示牌 / 长椅 / 夜晚灯光），NPC 会在那里停留。
2. **第二次路过广场要感觉"不一样"**：
   - 完成前：空广场、NPC 少
   - 完成后（白天）：有人坐艺术角、有展示牌
   - 完成后（夜晚）：灯亮、河面反光

> 第二条比"数据完成"更重要。
