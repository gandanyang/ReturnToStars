## 五、施工顺序（确认后执行）

```

Phase 5 内容放置：集市恢复点/NPC/出口衔接（Phase 4 后确认无碰撞）
Phase 6 探针验收：probe-ch1-town-visual-verify 密度 + 碰撞核查 + 截图
```

每 Phase 独立验证（tsc + 探针），不一次全上。

## 六、关键风险与待确认

1. **tilesets 引用**：town.json 现引用 placeholder，MapScene 硬编码 town_tileset——**Phase 1 必须修正**（这是之前地图异常的根因之一）
2. **地图宽度**：50×35=800×560 视野外右侧可能有黑色（相机视野 > 地图宽度）——**是否需要扩到 60-80 列**由制作人定
3. **宅基地叙事**：只铺残垣，不解释（制作人 Phase 2 建议）
4. **老街破损度**：破损屋数量/破洞位置——按"先破旧后修复"调性

**请制作人确认：①分区布局 ②是否扩宽 ③老街破损度，确认后按 §五 顺序施工。**
