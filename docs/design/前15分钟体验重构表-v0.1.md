# 《归星物语》Alpha Demo 前 15 分钟体验重构表 v0.1

> 状态：✅ **制作人已批准进入 v0.10 收口施工**（2026-08-08，四项修正已并入）｜性质：**设计文档，非实现任务卡**
> 定位：不是"加内容"，而是**为已有系统补一条"情感翻译层"**——让第一次来的玩家走进设计意图的桥。
> 核心判断（P0 审查结论）：《归星物语》不是缺内容，是**玩家还没产生"这是我的岛"的感觉，游戏就开始讲"这里有秘密"**。
> 红线：纯文案/表现/既有资产组织，零新系统、零存档改动、不扩主线剧情走向、不新增角色。

---

## 〇、一句话目标

> 前 15 分钟内，让玩家从"我在玩种田游戏"变成"我在让一个快消失的地方重新开始生活"。

## 〇·一、三段落总览

| 段落 | 时间 | 主线流程 | 情绪目标 |
|---|---|---|---|
| P1 序章·车站 | 0–3 分钟 | 车站开场 → 解锁移动 | 共鸣 / 好奇（"他累了、不知下一步、这岛给他重新开始"） |
| P2 教程·庄园 | 3–8 分钟 | 大门 → 锄/播/浇 → 傍晚对话 → 睡觉 | 上手成就感 + 治愈（"我在给爷爷的地方续命"） |
| P3 探索·岛 | 8–15 分钟 | 小镇 → 后山 → 星之碎片 | 发现乐趣 + 期待（"岛回应我的第一个事件"） |

> **2026-08-08 补充（制作人体验收口方案 v0.10）：完整 30 分钟心理旅程分五段**——P4 主动探索（15-25 分钟，后山"1 强+1 弱"路线）、P5 观星收束（25-30 分钟，归星记录=手账式，不做统计结算页）。核心：让玩家在半小时内完成"逃离现实 → 回到故乡 → 重新照顾生活 → 看见回应 → 主动发现岛的过去 → 想留下来看看"。

## 一、P1 序章·车站（0–3 分钟）

### 重构表

| 玩家看到什么 | 玩家做什么 | 应感受到什么 | 当前缺什么 |
|---|---|---|---|
| 黑屏 + 列车声 + "建议打开声音"弹窗 | 点击确认声音 | 好奇：旅程开始 | —（已达标） |
| 手机通知两页（HR 辞退/岗位调整） | 连续点击两页 | 共鸣：他刚失去方向 | 信息全是被动接收，无一次主动选择 |
| 内心独白 9 句（五年了/换个环境/爷爷说回来） | 逐句点击 | 共鸣：他累了、逃回来 | 独白偏"解释为什么回来"，缺"展示他逃回来"；公司背景解释过多，情绪浓度被稀释 |
| 站台细节（售货机/旧报纸/电话/时钟/行李箱） | 可交互查看（可选） | 好奇：时间在这里慢一些 | —（已有的好设计） |
| 移动教学 + "向右走出车站" | 向右移动 | 好奇：去庄园 | "去哪/为什么去"锚点弱：庄园只是远处一个点，缺"那里有等你的人/爷爷留下的地方"的指向 |

### 重构动作（P0-3）

1. **独白压缩至 4–5 句**，前三句直接传达"他累了 / 不知道下一步去哪 / 这个岛给他一个重新开始的机会"；公司背景说明后置（可放手机通知第二页，非强制阅读）。
2. **手机通知两页合并为可选一页**（或第一页可"稍后再看"），减少连续纯信息接收。
3. **移动解锁前给玩家一次主动选择**（把"被动接收"变"主动投入"）。选项文字做人话（制作人修正），不功能化：
   > "现在就走吗？" / "再看看这里。"
   选择只影响是否先逛站台，不动主线。（落地为 StoryDialogue 选项行，复用 `DialogueLine.options`，零新系统。）
4. **"前往星黎庄园"补一句目的地锚**："爷爷把这里留给了你。"（让"走过去"成为"接近某个地方"，而非"完成移动教学"。）

## 二、P2 教程·庄园（3–8 分钟）

### 重构表

| 玩家看到什么 | 玩家做什么 | 应感受到什么 | 当前缺什么 |
|---|---|---|---|
| 庄园大门 + 初遇夏雅 | 与夏雅对话 | 好奇：这座岛有人认识我 | —（已达标，XIYA_DIALOGUE） |
| 获得钥匙 | 开背包→用钥匙开门 | 成就感 | 行为提示依赖对话；跳过后可能卡"怎么开门"（有坏档自愈兜底，但首遍无主动提示） |
| 开门后荒废农田 + 旧锄头 | 锄 3 块地 | 成就感 | 只有"做"，没有"为什么"——玩家以为在刷星露谷操作 |
| 播种 3 块 / 浇水 | 播 3 次 / 浇 3 次 | 成就感 | 同上：教程步骤没有翻译成"给爷爷的地方一个开始" |
| 收获作物 | 第一次收获 | 回应感（"真的长出来了"） | 当前只有"获得萝卜"式系统提示，缺"照顾有回应"的情绪句 |
| 傍晚对话（晚霞/手机新闻对比） | 点完对话 → 睡觉存档 | 治愈 | —（已达标；P0-1 收束句并入现有 evening_talk，不新增节点） |

### 重构动作（P0-1，本轮最高优先）

给教程每步补一句"为什么"，把"习得"翻成"治愈"。纯文案。

> **说话人分配（制作人 2026-08-08 拍板）**：**根据叙事位置分配角色**，不强制统一夏雅。
> 锄地=夏雅（岛上生活经验）；播种/浇水/收获=林澈 inner（玩家自己重新建立生活的过程）。
> 措辞=制作人定稿（下表 2026-08-08）。
> 情感方向（制作人 2026-08-08 修正）：不强调"爷爷/祖辈继承"，强调"**照顾 → 成长 → 回应**"——玩家感觉"我在这里重新建立生活"，而非"我回来是因为爷爷"。
> 四步语义：锄地=土地 / 播种=未来 / 浇水=照顾 / 收获=回应。

| 教程步骤 | 当前反馈 | 补一句"为什么"（制作人定稿措辞 2026-08-08） |
|---|---|---|
| 锄地（clear_land） | "地要翻过，种子才肯住下"（已有） | "地要先翻过，才愿意接住新的种子。"（保留） |
| 播种（sow_seeds） | 播种提示 | "种下去的时候，看不到结果也没关系。很多事情，都是先有人开始，后来才慢慢有变化。" |
| 浇水（water_crops） | 浇水提示 | "有些东西不会马上改变，但每天照顾一点，就会慢慢回来。"（保留，四句里最重要——连接林澈现实焦虑/岛屿恢复/夏雅价值观） |
| 收获（harvest） | 获得作物提示 | "看吧。它真的长出来了。有时候，土地比我们想象得更愿意回应。"（降总结感：第一次收获应是惊喜，不是发表主题） |

**约束**：每步**只加 1 句**，不加第二段，避免"塞更多信息"反而拖慢（P0 审查红线：不要为改善体验而增密）。

## 三、P3 探索·岛（8–15 分钟）

### 重构表

| 玩家看到什么 | 玩家做什么 | 应感受到什么 | 当前缺什么 |
|---|---|---|---|
| 小镇 + 6 NPC | 进入小镇 / 与 NPC 对话 | 世界感 | —（NPC 已有生活台词） |
| 接主线"星之碎片" | 接受任务 | 期待？ | 碎片像"任务物品"，不像"岛回应林澈的第一个事件"；玩家还没建立归属感前提，任务就先抛出世界观悬念 |
| 后山 / 森林 | 走进森林 | 发现 | 缺少"第一次主动走进岛"的 3–5 分钟——从接任务到采集碎片之间没有"走过被遗忘的地方"的环节 |
| 老树（已有交互） | 靠近老树 E 查看 | 安心 / 好奇 | —（已有分碎片状态台词，教程期"很老的树/刻痕/安心"已经很好） |
| 星之碎片发光点 | 首次对话 → 自动采集 | 期待 | 采集对话已好，但承接它的前置探索感不足 |
| 交付碎片 → 观星夜收尾 | 交付 → 夜晚观星点 | 温暖 / 期待 | 收尾仪式感可能与"每日睡前存档"触发器重叠（情绪断点，见 P0 审查二 B 段） |

### 重构动作（P0-2，纯既有资产组织）

> 原则：**不新建任务、不加新资源**，只把已有素材（老树交互、森林氛围、NPC 台词、夏雅引导）重新组织成"第一次主动走进岛"的 3–5 分钟探索段。
> **制作人 2026-08-08 修正：互动点控制为「1 强 + 1 弱」，不做探索任务化**——玩家是来"发现"，不是来"检查地图"。

1. **接任务前，夏雅先给一句"为什么去后山"**（方向，待定稿）：
   > 夏雅："后山以前是岛上看星星的地方。只是后来，没人去了。"
   > （把"去拿碎片"翻译成"我第一次走到这个岛被遗忘的地方"。）
2. **强互动（唯一）**：森林老树（已有交互，教程期台词"很老的树/刻痕/安心"即符合"被遗忘/安心"，保留不动）。
3. **弱氛围点（一个即可，不互动）**：林间旧路牌 / 林缘空地——玩家**经过看到即可**，不触发对话、不弹提示，只作视觉氛围（已有森林氛围：萤火虫/落叶/野花，作为"这座岛还在呼吸"的视觉基础）。
4. **碎片出现时，用台词把"捡到"翻成"玩家主动发现"**：在碎片首次对话中补一句（方向，待定稿）：
   > "它不知道在这里沉睡了多久。但今天，终于有人来到这里。"
   > （重点不是"岛等你/命运召唤"，而是"**你重新走到了这里**"——选择，而非命运。）
5. **交付碎片后**：复用 v0.6 既有思路——交付后 farm tint 转暖（表现层，已规划），让"我交出去了"变成"岛开始回暖"。

### 约束

- P0-2 全程零新资源、零新任务、零存档字段；只加台词 + 复用既有交互点。
- 3–5 分钟"探索"是**松散的经过感**，不是任务链：不弹任务面板、不计数。

## 五·二、第一章体验红线（制作人补充锁定 2026-08-08）

> **玩家应该感觉自己正在发现归星岛，而不是被游戏介绍归星岛。**

- 现有优秀设定（林远山 / 夏雅 / 星之碎片 / 星轨守护者）易诱发"赶紧告诉玩家"的错误倾向。

## 五·三、森林路径与"弱痕迹"候选位置分析（只读 MapScene/exits，已核坐标）

> 目标：确认玩家实际路径，选定"弱氛围点"位置——**一个玩家必经路上的一句话，胜过没人看到的十句剧情**。

### 森林地图结构与坐标

| 项 | 值 | 说明 |
|---|---|---|
| 地图尺寸 | 30×20 瓦片（480×320 像素） | `MapScene.ts:720` |
| 玩家入口 | 森林底部 (15,17) 出生，出口区 x∈[14,16]T、y∈[18,20]T | `exits.ts:45`（从 farm 顶部进入） |
| 强互动·老树 | 瓦片 (8,8) → 像素 (136,136) | `MapScene.ts:2111` |
| 碎片采集点 | 瓦片 (20,10) → 像素 (328,168) | `MapScene.ts:2043` |
| 矿洞出口 | 瓦片 (28,9)（右侧） | `exits.ts:46` |

### 玩家自然路径（实测必经线）

```
入口 (15,17)  ↑ 左行  →  老树 (8,8)  →  右行  →  碎片 (20,10)
```

- 从入口向上偏左移动，**老树位于必经路径上方偏左**（先见强互动）。
- 老树 → 碎片为向右横向移动，**碎片在右半区、视野内可见**（发光点自然吸引）。
- 结论：**入口 → 老树 → 碎片 是一条自然 Z 字形路径，两处现有交互点都在必经线上**，无需额外强互动。

### 弱痕迹点候选（制作人锁"1 强 + 1 弱"，候选=旧路牌）

- **第一候选：旧路牌**——沿入口 (15,17) → 老树 (8,8) 上行途中，置于左侧林缘（约瓦片 x 9~11、y 12~14 一带，玩家上行的必经视线内）。
- 理由：天然表达"以前有人来过"，不需要解释；不拉出神秘少女/爷爷线。
- **明确排除**：旧房子 / 信件 / 照片（会把神秘少女、爷爷线拉出来）。
- 弱痕迹 = **只经过看到，不触发对话、不弹提示**，纯视觉氛围（可加 1 句暗示台词挂在环境描述层，也可完全无声——待定）。

### 森林氛围基础（已有，作视觉底）

萤火虫 / 落叶 / 野花装饰（`MapScene.ts:2964` 试玩-11，零资源）已作为"这座岛还在呼吸"的视觉基础。

## 七、Alpha 收口补充（制作人体验收口方案 v0.10，2026-08-08）

### 7.1 观星收束：归星记录 = 手账（不做统计结算页）

观星夜后不放大结算面板，改为**一本手账**，内容是叙事而非数据：

```
归星岛记录

第一天。
林澈回来了。
庄园有了第一片新土地。
有人开始重新整理这里。
```

然后接星空。让"归星"落在"记录自己正在让这里活过来"，而不是完成任务结算。

### 7.2 后山碎片台词（呼应 §五·三 "1 强+1 弱"）

碎片不说命运/等待/召唤，改为"主动发现"：

> "它不知道在这里多久了。但今天，有人来到这里。"

重点：林澈**选择**，不是被选择。

### 7.3 明确不做（Alpha 收口红线）

❌ 大量新任务 / 新地图 / 全程语音 / 拍立得结算页 / 新系统 / 新货币循环 / 复杂恢复系统

### 7.4 当前真正应施工的优先级（收益/成本）
