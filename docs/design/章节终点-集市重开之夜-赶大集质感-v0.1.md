## 一、为什么"赶大集"是对的

原 §九 的"集市重开之夜"如果做成通用夜市（西式 fair / 霓虹夜市），玩家看到的是**功能开张**——热闹但无记忆。

中国乡村赶大集（北方叫"赶集"、南方叫"趁圩/赶场"）是**几代人的集体记忆**，它的核心不是买卖，而是：

> **平时冷清的街口，某个日子突然挤满了人。**
> 熟人碰面、讨价还价、小孩骑在大人脖子上、油锅滋啦作响。
> 散集后街口恢复冷清——但你知道，下个集日它还会再热闹起来。

这正是第一章主题"复苏"的画面化：**生活不是被"建成"的，是"重新发生"的。**

记忆点清单（观众共鸣的来源）：
| 记忆点 | 画面 |
|---|---|
| 逢集日 | 平时空荡的广场，特定日子突然摆满摊 |
| 布棚 | 红蓝条纹塑料布 + 竹竿撑的摊位棚 |
| 油锅 | 炸油条/炸糕，热气腾腾，滋啦声 |
| 叫卖 | "新到的——"长调吆喝，人声嘈杂 |
| 熟人碰面 | 街口站住聊半天，孩子跑闹 |
| 散集余温 | 收摊、灯光一盏盏熄，心里却热乎 |

## 二、演出设计（克制版 ≤ 观星夜 40%）

### 2.1 触发与时机

- **前置**：`isRestored('marketSquare')`（集市已修复）+ `ch1ElderChoice` 已记录（任意态度都可进入，help/unsure 台词微差）
- **时机**：修复集市后**下一个集日**（用 day 记录，避免当天立刻爆发——"过几天才热闹"更真实）
- **时间**：傍晚（18:00-19:00 进入演出窗口）——不是深夜，是"天擦黑、灯光亮起"的集日傍晚，最有人气

### 2.2 演出分层（从轻到重的递进，不一次性堆满）

```
① 傍晚入场（环境层，1 次）
   平时：广场空荡，只有修复后的摊位骨架
   集日：摊主陆续出现 → 布棚逐个撑起 → 灯光亮起
   表现：NPC 走到摊位后（复用 NPCSystem 精灵），摊位灯渐次亮（tween 序列）

② 生活层（声音 + 粒子，贯穿）
   油锅滋啦（程序合成短循环）、叫卖长调（低频人声感音效）
   热气粒子（摊位上方白雾）、灯光暖色（新增集日灯效）

③ 人群层（NPC 行为，集日专属）
   村民三三两两走到集市区 → 摊位前停留（patrol + 驻足）
   碰面对话：复用 getDailyNpcLine 的 MARKET_RESTORED_LINES + 集日专属一句

④ 高潮层（克制，不搞大镜头）
   玩家走近集市 → 自动触发 1 段对白（镇长 1-2 句 + 夏雅 1 句）
   不是演出，是"你走在人群里听到的"——旁白式
```

### 2.3 对白（克制，台词过文风审查）

- 镇长（集日开场）："今天赶集，好些日子没这么热闹了。"（不总结、不宣言）
- 商店老板："油锅一起，这味儿就对了。"（行动型：气味唤起记忆）
- 夏雅（若在场）："以前逢集，爷爷总带我来这头买糖。"（记忆线钩子，不展开）
- 旁白（高潮）："青禾镇的集市，又开了。"（唯一一句总结性台词，其余全靠画面）

## 三、实现映射（复用现有轮子，零新系统）

| 层 | 复用 | 新增（程序化） |
|---|---|---|
| 布棚/摊位 | 已有 `buildMarketSquareRestored` 摊位 | 布棚顶（红蓝条纹 Graphics）逐个出现 tween |
| 灯光 | 已有摊位灯 | 集日灯效（摊位上暖黄呼吸光晕） |
| 油锅热气 | 已有粒子系统（townSmoke 模式） | 摊位上方白雾粒子（低频） |
| 叫卖/油锅声 | AudioSystem 程序合成 | `market_calls` / `market_oil`（短循环，低音量） |
| 人群 | NPCSystem patrol + 驻足 | 集日路径（town 集市区附近 patrol 点） |
| 存档 | FarmRestore / EventManager | `ch1_market_fair_done`（一次性演出） |

**关键约束**：
- 不新增 NPC、不新增地图区域、不新增系统——只加程序化视觉/声音/行为
- 演出不冻结玩家操作（参照 showMemoryMoment 不冻结；对白可走开）
- 观星夜 40% 上限：无长镜头、无 pan、无银河级特效，总时长 ≤ 40s 递进
