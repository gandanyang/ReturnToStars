# 青禾镇舞台块定义 v1.0（叙事空间单元）

> 状态：设计稿（2026-08-13，制作人：方向 8.5/10，**补完本文件才进施工**）
> 定位：把 50×35 拆成 **8 个叙事空间单元**——每块回答"为什么做这个地方"
> 原则：**"设计文档很漂亮" 不是目标，"游戏里不是一堆瓦片" 才是**
> 前驱：`青禾镇玩家动线设计图-v1.0.md`（南北轴已按制作人调整：**南=行动区**，非"未来"）

---

## 南北轴调整（制作人拍板）

```
北：记忆区（爷爷、星空、旧时代）
中：生活区（人与人的连接）
南：行动区（玩家改变世界的地方）—— 农田不是"未来"，是"现在开始行动"
真正的"未来" = 玩家修复之后看到的东西（成长反馈）
```

**玩家第一天情绪线**：陌生 → 发现遗迹 → 认识居民 → 产生责任感 → 看到希望

## S1 镇门遗址（第二层发现 · 公共记忆）

- **位置**：南横路/竖路交叉西侧（x22-27, y26-29，玩家从 S4 北上后第二视野）
- **玩家第一次看到**：褪色的"青禾镇"牌匾（歪斜）、倒下的木栏、坏掉的路灯
- **玩家为什么经过这里**：离开 S4 北上前往广场的必经之路——**"这个地方曾经是什么"** 的公共记忆
- **初始状态**：
  - 褪色"青禾镇"木牌（gid10 墙 + gid11 门改造的匾额底座）
  - 倒下的木栏（gid14 栅栏横置）
  - 坏路灯（gid13 井造型 + 无光晕）
- **修复状态**：
  - 牌匾扶正、漆色恢复（代码改色）
  - 路灯点亮（暖黄光晕 tween）
  - 路边花坛（gid8 作物）
- **对应任务**：无任务，纯"钩子"——**第一章村长来访后自动修复**（"有人在修了"）
- **情绪目标**：**"这里不是没人住，是被遗忘了"**（比多放十棵树有效）

---

## S2 老街·记忆街（过去的生活）

- **位置**：x30-39, y2-7（北区东侧）
- **玩家第一次看到**：成排破旧老街屋（屋顶缺角/墙面裂/空窗）、杂草丛生、空招牌
- **玩家为什么经过这里**：竖路北上探索、集市广场绕行
- **初始状态**：
  - 老街屋 ×2-3（gid9 屋顶缺角 + gid10 墙裂 + gid12 空窗）
  - 路边杂草（gid8 稀疏）
  - 空招牌（gid15 装饰）
- **修复状态**：
  - 屋顶补齐、窗亮灯（光晕）
  - 路侧花坛 + NPC 聊天点（石凳/树荫）
  - 招牌挂回（代码改色）
- **对应任务**：集市恢复后触发"老街修复"（小任务链，可后置）
- **情绪目标**：**"以前这里很热闹"→ 现在安静但有影子**

---

## S3 中央广场（现在的生活 · 连接）

- **位置**：x20-29, y8-27（现有镇中心，**几乎不动**）
- **玩家第一次看到**：四民居 + 竖路 + 横路 + 商店 + 需求板（P0-0 平移后原样）
- **玩家为什么经过这里**：NPC 互动/商店/任务中枢——**玩家的生活中心**
- **初始状态**：现有内容（石板开裂感可通过地砖零星 gid2 表达，但不改主体）
- **修复状态**：道路修补（gid7 完整）、商店门面（已实现 shopRevival）
- **对应任务**：主线任务中枢（镇长/商店/需求板）
- **情绪目标**：**"这里是镇子的心，有人在等我"**

---

## S4 爷爷旧宅遗址（爷爷留下的第一处痕迹）

- **位置**：x22-27, y29-33（南侧中）
- **玩家第一次看到**：残垣断壁（三面破墙）+ 荒草 + 废井——**"爷爷留在镇上的第一处痕迹"**
- **玩家为什么经过这里**：竖路南下必经（从广场去农田/行动区）；出生点附近东南向
- **初始状态**：
  - 三面残垣（gid10）+ 门位缺口（x24-25 通竖路）
  - 院内荒草（gid8）+ 废井（gid13）
  - 地面 gid6 石板（破旧地基）
- **修复状态（四阶段成长反馈，制作人拍板）**：
  - ① 破旧房子（地基清理）
  - ② 整理庭院（院内杂草清除 + 石板完整）
  - ③ 种花（gid8 花丛 + 花坛）
  - ④ 夜晚灯亮（暖黄光晕——**"这里开始有人记得了"**）
- **对应任务**：夏雅记忆线（未来）/ 章节终点演出
- **情绪目标**：**爷爷留下的第一处痕迹**——不是"我的家"，而是"爷爷的过去散落在这个镇里"；林澈不是回来继承一栋房子，而是渐渐发现"爷爷留下的不只是房子，还有整个青禾镇"。farm house（现在的家）与 S4（记忆的痕迹）不冲突，是两个"家"概念的厘清。

---

## S5 农田·行动区（改变世界的起点）

- **位置**：x40-49, y12-31（东区）
- **玩家第一次看到**：荒地（gid2）+ 零散作物 + 田埂——**"可以动手的地方"**
- **玩家为什么经过这里**：种田/收集/资源（行动区）
- **初始状态**：荒地 gid2 + 少量作物 gid8 + 木埂 gid6
- **修复状态**：作物生长（随农场系统）、田埂完整、田头工具架
- **对应任务**：农场系统联动（非独立任务）
- **情绪目标**：**"我的行动真的让这里长东西"**（不是"未来"，是现在动手）

---

## S6 老河堤（治愈 · 停下来）

- **位置**：x0-4, y6-28（西侧河岸）
- **玩家第一次看到**：水（gid4）+ 荒草岸线 + 无灯
- **玩家为什么经过这里**：横路西端/主动探索——**"什么都不做也舒服"的位置**
- **初始状态**：水 + 岸线草地 + 稀疏树
- **修复状态**：
  - 长椅（gid6 木条凳）
  - 岸线花（gid8）
  - 夜晚灯光（暖黄）
- **对应任务**：夏雅任务 / 环境恢复（P2）
- **情绪目标**：**玩家停留 20 秒+ 的治愈点**（原神尘歌壶/星露谷逻辑）

---

## S7 集市广场（复兴的证明 · 赶集舞台）

- **位置**：x18-33, y2-7（北区中）
- **玩家第一次看到**：荒地（gid2）+ 摊贩残骸（集市恢复点现状）
- **玩家为什么经过这里**：集市恢复任务/竖路北上/赶集演出
- **初始状态**：荒地 + 摊位残骸 + 交互标记（已实现 buildMarketSquareRuined）
- **修复状态**：摊位×3 + 灯光 + **空角（老树+石凳+木牌）**（已实现）→ 赶大集（人群/油锅/叫卖）
- **对应任务**：集市恢复（已实现）/ 章节终点赶集（设计稿 v0.1）
- **情绪目标**：**"人重新聚起来"**（复兴的证明）

---

## S8 果林·东林（自然与资源）

- **位置**：x40-49, y2-11（东北）
- **玩家第一次看到**：草地 + 树阵（gid16）+ 稀疏果木
- **玩家为什么经过这里**：果林入口/资源收集（P2 轻量玩法）
- **初始状态**：草地 + 树阵
- **修复状态**：果木挂果（gid8 点缀）、林间小路
- **对应任务**：P2 收集玩法（后置）
- **情绪目标**：**"自然还在"**（资源轴）

## 施工顺序（制作人拍板：先基础后内容）

```
Phase 0：tileset 引用统一（town.json → town_tileset，16 tile）

Phase 1：骨架（路/水/草地/区域边界）——不放花/树/房/装饰
         先看玩家走起来像不像
Phase 2：叙事物件（废弃牌子/老屋残骸/路灯/公告栏）
Phase 3：美术（树/花/细节装饰）
```

## 验收标准（每块）

每块施工完成后检查：
1. 玩家第一次看到什么 → 与定义一致
2. 玩家为什么经过 → 动线成立（不绕路/不堵路）
3. 初始/修复两态 → 有对比
4. 情绪目标 → 截图目测可达
