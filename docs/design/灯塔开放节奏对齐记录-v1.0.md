# 灯塔开放节奏对齐记录 v1.0

> **状态：** 🟡 长期规划 / 非当前施工——设计方向对齐记录（2026-08-15 制作人拍板方向确认），灯塔当前为预埋状态，本记录**不改代码、不施工**。
> **定位：** 回答"**灯塔启动后什么时候开放游玩/探索**"——不设计成"完成某个任务立刻解锁新地图"，而是**中后期的大事件节点**。
> **依据：** `docs/design/灯塔区域生产方案-v1.0.md`（P3-01）、`docs/design/灯塔未来内容预埋方案-v1.0.md`（三层叙事：黑→亮→开放）、`docs/design/岛屿未来扩展路线-v1.0.md`（P2）、`docs/design/归星岛世界回应事件库-v1.0.md`（P2.5 类型二/三）。

---

## 一、核心判断（本次确认）

**灯塔不要过早开放。**

| 结构 | 承担情绪 | 定位 |
|---|---|---|
| 观星夜 | 第一章情绪高潮 | 星之碎片 → 观星夜（已承担） |
| **灯塔启动** | 章节奖励 / 第二章开端 | 世界"真正重新亮起来"的象征 |

> 节奏要点：现在"星之碎片 → 观星夜"已经承担第一章情绪高潮。如果马上又灯塔启动，会抢戏。灯塔应作为**章节末收束 / 章节奖励**出现。

---

## 二、建议开放节奏

```
第0章：回归青禾镇 → 找到星之碎片 → 第一次观星
第一章：修复生活 → 恢复集市 → 帮助居民
第二章：寻找星辉 → 启动灯塔 → 照亮青禾镇
```

### 灯塔第一次启动（第一章末 / 第二章开始）

```
星之碎片发现
   ↓
修复旧天文设备
   ↓
收集星辉材料
   ↓
灯塔重新亮起
   ↓
开启灯塔区域
```

### 启动当天（情感奖励）

- 灯光扫过青禾镇
- 海面出现星光倒影
- NPC 来观看
- 解锁新的生活空间

## 三、灯塔开放后内容（未来排期参考）

### ① 灯塔观景（每日，非刷资源）

- 看日落 / 看星空 / 触发 NPC 偶遇 / 听环境音乐
- 定位：类似温泉/沙滩的"想去待一会"的地方（星露谷参考）

### ② 灯塔维护玩法（与资源系统连接）

- 木材 → 修木梯、平台
- 矿石 → 修灯具
- 玻璃材料 → 修灯罩

> 第一次：能亮；后续：更漂亮。

### ③ 星辉采集（挖矿系统终点价值）

- 灯塔启动后夜晚附近出现：星辉碎片 / 特殊植物 / 夜光昆虫
- 把采集、挖矿、探索全部串起来

### ④ 灯塔事件（NPC 反应，反 AI 味）

> 夏雅："小时候我一直觉得，这盏灯会重新亮起来。"
> 老镇民："以前海上的船都靠它回家。"
