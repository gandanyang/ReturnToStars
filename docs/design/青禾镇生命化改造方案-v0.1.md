---

## 〇、一句话

> 现在的镇子像一张地图；改造后，玩家会觉得"这里有人生活过、正在生活、还会继续生活"。

---

## 一、核心判断

1. **功能密度已够，差最后 20% 的气质**——不是缺元素，是缺"人生活过的痕迹"。
2. 反例：一块草地 = 绿色 tile × N → 玩家大脑补全不了生活；正例：草 + 碎花 + 踩踏区域 + 小石子 + 落叶 + 边缘变化 → 玩家自动脑补"这里有人走过"。
3. 判断标准（每处改动自问）：**这块地，能看出有人住过吗？**

---

## 二、范围：三段样板（先于全图）

施工顺序（制作人拍板）：**河岸 → 中央广场 → 北街**。每段做完独立验收，再进下一段。

### 段 1：河岸（情绪核心，第一优先）

- 现状：S6 水 + 岸线 + 长椅 + 新钓点视觉 + 阿风火堆
- 改造方向：
  - **痕迹物件**：岸边旧木桩 / 拴船绳 / 晒的渔网一角 / 石子滩 / 一只旧木桶
  - **岸线层次**：草 / 碎花 / 踩踏路径 / 边缘过渡（不再是"水和草的直线分界"）
  - **黄昏氛围**：光照实验推广到河岸段（压暗 + 水面反光 + 长椅暖光）
  - **前景遮挡**：岸下缘草叶/树枝，玩家走近被轻微遮挡
- 宣传图潜力：**黄昏 + 浮漂 + 长椅 + 火堆**——《归星物语》情绪核心一幕

### 段 2：中央广场（城镇复兴，第二优先）

- 现状：24 格石板 + NPC 聚集 + 商店 + 需求板 + 集市
- 改造方向：
  - **石板质感**：裂缝 / 补丁 / 砖缝变化（不再"干净得像新铺的"）
  - **生活痕迹**：摊位旁木箱 / 菜篓 / 散落的菜叶 / 车辙印
  - **人气感**：NPC 聚集区的光斑 / 一点动态（摊位布偶尔被风吹动）
  - **收边**：树 / 花坛把广场框出来（吸收场景分析 P0 边界的建议）
- 验证：玩家站上广场，感觉"这里是镇子的心，有人在等我"

### 段 3：北街（生活感，第三优先）

- 现状：老街屋 + 集市区
- 改造方向：
  - **老街破损质感**：屋顶缺角阴影 / 墙面剥落层次（不是"贴了个破 tile"）
  - **生活痕迹**：晾晒的衣物 / 门口杂物 / 旧招牌（Phase3 招牌） / 窗台小物件
  - **氛围**：窗灯 + 路灯暖光池（光照语言与河岸统一）
- 验证："以前热闹过"的生活感

---

## 三、优先级（S / A / B）

| 级 | 项 | 说明 |
|---|---|---|
| **S** | Tile 质感刷新 | 16 gid 不变，走 gpt-tileset 管线重绘品质（草/石板/路面纹理、边缘、使用痕迹）——"空间和材质"是第一印象 |
| **S** | 前景遮挡 | 屏幕下缘草叶/树冠，空间层次感，成本极低收益极高 |
| **S** | 光照氛围 | 夜晚压暗 + 光源各自投射暖光池（路灯/窗灯/火堆/长椅），统一视觉语言 |
| **A** | 粒子 | 萤火虫 / 落叶 / 炊烟（复用火堆粒子做法） |
| **A** | 动态植物 | 草/花轻微摆动（低成本 tween） |
| **A** | 水面 | 波纹层次 / 反光 |
| **B** | 镜头微动 | 克制化（不是处处都动，只在地标/停留点） |

## 四、技术约束

- **16 gid 不扩**、地图 gid / 碰撞 / 存档结构零改动（D-030 + Phase3 路线 C）。
- 痕迹与修复态一律 **GameObject / Graphics**（路线 C，零 tile 修改）。
- 零新系统、零新顶层存档字段。
- Tileset 品质刷新走现有 `gpt_tileset_normalizer.py` 管线（同一 16 gid 重绘品质，不换 tileset 结构）。
- 表现层复用火堆实验组件（overlay / Add 光 / 粒子 / 前景 / 镜头），抽成可复用写法后按场景推广。
