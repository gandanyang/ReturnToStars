# 青禾镇玩家动线设计图 v1.0（叙事空间 · 非城市规划）

> 状态：设计稿（2026-08-13，制作人方向：**地图是舞台，不是城市**）
> 核心原则：**先决定"这个地方是什么"，再决定"它由什么组成"**
> 定位：《归星物语》是 15-30 分钟体验的舞台剧，不是开放世界——地图服务剧情节奏，不服务"看起来大"
> 本文档替代 `青禾镇大地图分区设计-v1.0.md` 的功能分区思路（那是"城市规划"，本文是"舞台设计"）

---

## 一、叙事总纲：衰败 → 修复 → 有人生活

青禾镇不是普通 RPG 城镇。它的核心是：

> 一个衰败的小镇，被林澈一点点重新连接起来。

所以地图不是"河/街/广场/农田"的排列，而是**三层视觉叙事**：

| 层 | 玩家看到 | 素材表达 |
|---|---|---|
| **第一层：初到**（衰败） | "这里以前很好，但现在荒了" | 裂开的石板路、杂草、倒掉的木栏、空房子、熄灭的灯 |
| **第二层：修复后**（变化） | "我在让它活过来" | 花坛、亮灯、NPC 聊天点、商店扩建——**同一个空间产生变化** |
| **第三层：情绪中心**（地标） | "这里和爷爷/星空/土地相连" | 观星台 / 老屋 / 星之碎片所在地 |

**核心设计手法**：**每个分块是"同一个空间的两种状态"**——衰败态（玩家初到）与修复态（玩家行为后）。这正是"归星岛复兴"的视觉化：不是新建东西，是让旧的东西活过来。

## 二、南北叙事轴（空间 = 时间线）

```
            北
         观星台 / 老街（过去：爷爷、星空、记忆）
              │
    老林 ─── 中央广场（现在：居民交流）─── 河岸
              │
         老屋宅基地（未来：复兴起点）
              │
         农田入口（未来：农业、生长）
            南
```

| 方向 | 主题 | 情绪 | 设计语言 |
|---|---|---|---|
| **北** | 过去 | 怀旧、记忆 | 观星台、老街破损屋、爷爷痕迹 |
| **中** | 现在 | 连接、生活 | 中央广场、NPC、集市恢复 |
| **南** | 未来 | 希望、生长 | 老屋宅基地（待复兴）、农田 |
| **东西** | 自然与资源 | 呼吸、探索 | 河岸（治愈）、果林/农田（资源） |

玩家**每天走路都有故事**——不是随机贴图，是沿时间线走动。

## 三、舞台剧四幕（动线服务节奏）

《归星物语》不是开放世界，是**四幕舞台剧**。地图动线必须服务这个节奏：

```
第一幕：车站 → 镇入口 → 老屋     （引入：你是谁，你回到了哪里）
第二幕：中央广场 → NPC            （连接：这里的人，这里的关系）
第三幕：森林 → 星之碎片           （行动：为爷爷完成一件事）
第四幕：观星夜                    （高潮：理解"回来"的意义）
```

### 对应到地图动线：

| 幕 | 玩家位置 | 动线设计 |
|---|---|---|
| **第一幕** | farm → house → town 南口 | 从农场老屋出发 → 走过农田 → 进镇南口 → **第一眼看到爷爷旧宅遗址（个人记忆）** → 北上见镇门遗址（公共记忆） → 中央广场 |
| **第二幕** | 中央广场 | 玩家站上广场那一刻，NPC 在周围、商店、需求板——**"这就是镇子的心"** |
| **第三幕** | 森林（town 北→矿洞→森林） | 竖路向北 → 出镇去森林，老街/观星台方向 |
| **第四幕** | farm 观星点 | 回到农场，情绪收束 |

## 四、玩家动线问答（制作人 5 问）

### Q1：玩家第一天进入城镇，从哪里来？
从 **farm（农场老屋）** 出发，走 farm 东侧出口 → town 南口（x10, y17 附近出生，现 spawn (13T,18T)）。

### Q2：第一眼看到什么？

**三镜叙事（制作人 2026-08-13 拍板定稿）**——玩家不是游客，是归乡者，先看"家"再看"镇"：

```
出生
 ↓
第一镜：爷爷旧宅遗址（个人记忆）→ "我为什么回来"
第二镜：镇门遗址（公共记忆）    → "这个地方曾经是什么"
第三镜：中央广场（现在的人）    → "这里还有人"
```

- **第一镜 · 个人记忆**：S4 爷爷旧宅遗址（三面残墙 + 废井 + 荒草）——"爷爷留在镇上的痕迹"
- **第二镜 · 公共记忆**：S1 镇门遗址（褪色镇牌 + 倒木栏 + 坏路灯）——"青禾镇曾经有门"
- **第三镜 · 现在**：中央广场（NPC、商店、需求板）——"这里还在生活"

> 注：S1/S4 均在南区，地理上相距近，玩家出生后视野天然形成"前景 S4、背景 S1"的视线层次；两镜顺序由玩家步行路线自然完成。

**目标**：5 秒内玩家理解"这里曾有人生活，现在正在慢慢回来"（已验证成立）。

### Q3：15 分钟体验路线是什么？
```
进镇（南口）→ 沿竖路北上 → 中央广场（见 NPC/接任务）
→ 集市广场（村长老来访前置）→ 老街（感受衰败）
→ 出镇北上 → 森林采集（星之碎片）→ 回镇交付
→ 回 farm → 观星夜
```
（注：第一章主线"老屋整理→集市恢复"在同一空间循环，动线在 farm/town 间往返）

### Q4：哪些地方随章节变化？

| 分块 | 第0章（初到） | 第一章中（修复） | 章节终点（有人生活） |
|---|---|---|---|
| **老街 A/B** | 破损屋、杂草、断路 | 屋顶修补、路边花坛 | 亮灯、NPC 聊天点 |
| **集市广场** | 荒地、摊位残骸 | 摊位出现、灯光亮 | 赶大集（人群、油锅、叫卖） |
| **老屋宅基地** | 残垣、杂草 | 地基清理（待叙事） | 夏雅记忆线启用 |
| **中央广场** | 石板开裂 | 道路修补 | NPC 常驻、商店扩建 |
| **河岸** | 荒草 | 岸线整理 | 河边座椅（"什么都不做也舒服"） |

### Q5：哪些区域未来可扩展？

| 区域 | 预留位置 | 未来用途 |
|---|---|---|
| 东侧果林/农田 | x40-49 | 农场资源扩展、新作物 |
| 北侧老街延伸 | y0-3 | 观星台、爷爷记忆点（第三章） |

## 五、与旧分区设计的差异（为什么这个对）

| 维度 | 旧版（城市规划） | 新版（舞台设计） |
|---|---|---|
| 出发点 | 功能分区（河/街/广场/农田） | 叙事动线（过去/现在/未来） |
| 空间逻辑 | 区域互不相关 | 南北时间轴 + 东西资源轴 |
| 视觉节奏 | 均匀填充 | 衰败→修复→有人生活的对比 |
| 分块定义 | "这块是什么" | "这块是什么 + 它如何变化" |
| 玩家感受 | "一个镇子" | "一个正在被重新连接起来的镇子" |
