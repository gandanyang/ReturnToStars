# 岛屿边界扩展方案 v1.0

> **状态：** Alpha 阶段已实施 P0（2026-08-09，制作人拍板）
> **类型：** 世界空间感增强 / 展示版本体验优化
> **目标：** 不扩大实际开发规模，通过视觉、地标、远景、叙事暗示提升岛屿完整感。
> **归档原因（制作人 2026-08-09）：** 本设计理念将反复使用，作为未来并行开发的"护栏"，防止"这里加个区域吧"导致项目膨胀。

---

# 一、问题定义

当前地图结构：

```
车站
 |
小镇
 |
农场
 |
森林
 |
矿山
```

功能路径明确，但玩家可能产生：

> "这是几个游戏区域连接起来的地图。"

而不是：

> "这是一个曾经繁荣，现在等待恢复的小岛。"

当前缺少的不是可玩内容，而是：

* 远方目标
* 未完成空间
* 历史痕迹
* 未来期待

---

# 二、设计目标

## 不做：

❌ 大规模扩地图
❌ 新增大量可探索区域
❌ 新增复杂系统
❌ 消耗大量剧情资源

## 做：

✅ 增加视觉范围
✅ 增加未来探索预期
✅ 增加岛屿历史感
✅ 增加玩家想象空间

---

# 三、核心原则

## 1. 看得见 > 现在能进去

玩家不需要马上进入。

玩家需要知道：

"那里以后会发生故事。"

## 2. 地标 > 面积

一个灯塔的价值：

> 让玩家相信岛外还有故事。

比增加十片草地有效。

## 3. 暗示 > 填满

保持未开放区域。

让玩家产生：

"以后我要回来看看。"

---

# 四、岛屿空间规划 v1

目标：从二维功能路线升级为有层次的空间：

```
                      灯塔（农场西侧海湾外，2026-08-10 起）
                       |
  海岸 ---- 废弃码头 -----
   |
  车站 ---- 小镇 ---- 老街
   |
  农场 <---- 海湾（西侧，灯塔岛）
   |
  森林 ---- 温泉
   |
  矿山 ---- 封锁山路
```

# 五、推荐新增视觉地标

## 1. 灯塔（高优先级）✅ 已实施（P0 远景，2026-08-10 调整为西侧海湾）

位置：~~海岸方向远景~~（2026-08-10 调整：原 farm 东北角海角远景效果不合格返工，**灯塔内容统一移至农场西侧海湾 + lighthouse 场景**，farm 西侧石墙打通为海湾缺口，玩家西望可见灯塔岛）。当前版本不可进入（出口 locked）。

表现：
* 夜晚灯光**熄灭**（⚠️ 2026-08-10 制作人方向对齐：灯塔=未来内容预埋，当前恒黑——"现在它是黑的，有一天它会亮"；原"夜晚灯光闪烁"移入未来链路，见 `灯塔未来内容预埋方案-v1.0.md`）
* 白天可见轮廓（西侧海湾灯塔剪影）
* NPC 偶尔提起

叙事价值：代表"岛曾经连接外界"。

未来剧情：老航线 / 爷爷故事 / 海边事件 / **灯塔亮起（城市复兴后）→ 执灯人归来 → 灯塔开放**。

## 2. 废弃码头（高优先级）✅ 已实施（P0 远景）

位置：车站/海岸附近。

表现：破旧木板 / 生锈吊机 / 停泊的小船。

叙事暗示：过去这里曾经很热闹，现在没人来了。与主题高度契合。

## 3. 老街（中优先级，未实施）

位置：小镇边缘。

表现：关闭商店 / 空招牌 / 老居民楼。

作用：强化"这里不是小村庄，而是衰落的小镇"。

## 4. 温泉（中优先级，未实施）

位置：森林深处。当前不可进入。

作用：未来休闲玩法 / NPC 故事空间 / 季节活动可能性。

## 5. 封锁山路（低优先级，未实施）

位置：矿山附近。

表现：坍塌道路 / 警示牌 / 隧道入口。

作用：暗示"岛还有过去"。

# 七、技术实现建议

不新增地图系统。优先使用：
* Tile Layer / Decoration Sprite / Background Object / Collision Block

不新增任务。只新增：
* 地图对象 / 环境音 / 少量对白

---

# 八、验收标准

完成后玩家第一次进入岛屿，应该产生：

**现在：** "这里有农场和几个地方。"

**目标：** "这里以前一定发生过很多事情，我想看看以后能恢复什么。"

---

# 九、与《归星物语》核心主题关系

地图扩展不是为了"大"，而是为了表达：

> 一个正在消失的小岛，等待一个人重新连接它。

真正的目标不是让玩家觉得"地图很大"，而是：

"这个地方值得被救回来。"

# 十一、P0 实施记录（2026-08-09）

## 空间扩展原则（护栏，制作人拍板）

> **《归星物语》空间扩展原则：不是"做更多地图"，而是"制造未来"。**

当出现"这里加个区域吧"的提议时，先回答：能不能用**视觉层 + 台词池 + 一句对白**完成同样的心理效果？

**陷阱警示（制作人 2026-08-09）：** 若扩展一步变成"新 tilemap / 新区域 / 新碰撞 / 新任务 / 新存档"，就滑入了大型内容坑。正确做法是"海角视觉层 + 碰撞墙"——给玩家的脑子扩地图，而不是扩工程。

验收心得：实施后地图空间感从 6.5/10 → 8/10，变化不在面积，而在"农场是一块功能地图" → "农场是一个岛屿的一部分"。

## 独立核验记录（2026-08-10 WorkBuddy）

对 P0 落地做了独立代码 + 像素级核验（不依赖并行会话结论），全部通过：

1. **代码核验**：`MapScene.setupFarmHorizon()`（L2832-2909：海面/码头/灯塔/夜灯呼吸 + 透明岸线碰撞墙，零资源纯 Graphics）；`NPCSystem` 镇长码头句 + 阿风灯塔句；`AmbienceSystem` waves 海浪层（farm 白天 3 层：birds/wind/waves）。
2. **视觉像素核验**（真实视野 getWorldPoint 映射，1024×768 页面）：白天海角海面蓝 65.5%（water 锚点同族）、码头核心区棕 9.8%+蓝 41.1%、灯塔塔身棕 47.9%（pillar 锚点同族）；夜晚海面整体转暗 78.6% 暗像素、灯室暖色 21.3%（白天 ≈0）→ **昼夜渲染正确，灯室"夜亮昼灭"成立**。
3. **美术规范对照**：码头 0x8a6a4a ≈ 调色板 crate 锚点(138,106,66)；灯塔 0x3a4a5a ≈ pillar 锚点(74,74,84)；海面 0x2a5a7a 白天 / 0x0a1a2a 夜晚 ≈ water 锚点(52,92,140)。远景纯色剪影无 1px 描边属合理设计（描边规则针对近景 tile 资产）。
4. **探针修复（重要）**：原探针轮询读 `cam.scrollX` 属性误判"相机未到位"——farm 场景 follow+setBounds 下 scrollX 属性（40）与实际渲染视野（getWorldPoint(0,0).x=240）不一致，海角其实一直在视野内。已改为轮询 `getWorldPoint(0,0).x`（期望 ≥200），重跑 6/6 且"视野到位"日志正确。**教训：Phaser 相机判定用 getWorldPoint 语义，勿信 scrollX 属性。**
5. **已知偏差（非 bug）**：海角区实有默认树 5 棵（文档原写"无树"已修正），其中 2 棵大树局部遮挡码头东段/灯塔塔基，属自然遮挡可接受；若要完全露出可挪树（不动，避免连锁回归）。

# 十二、P1 储备：灯塔情绪反馈（2026-08-09 记录，暂不实施）

制作人提出，未来 PV 或试玩时考虑：玩家**第一次靠近海角**时，不触发任务，只触发林澈一句情绪台词：

> "以前这里应该很热闹吧。"

或：

> "不知道还有没有人记得这座灯塔。"

原因：现在灯塔（玩家看到）+ NPC（玩家听到），还差"玩家角色对它产生情绪"——一句台词即可让灯塔从"地图装饰"变成"故事空间"。

**注意：制作人明确"属于 P1，不要现在插"。** 实施时需保证：一次性触发、不落档、不影响现有对白池。

# 十四、空间扩展实验结论（P0 复盘，2026-08-09）

> 本节是本次 P0 的可复用经验总结。半年后若有人问「要不要加一个港口？」，先读本节，而不是直接开始设计港口。

## 实验假设

增加不可进入的远景地标，是否可以提升玩家对岛屿完整性的感知？

## 实施

新增：
* 灯塔（远景）
* 废弃码头（远景）
* NPC 历史对白（镇长 / 阿风 各 1 句）

未新增：
* 可探索区域
* 新任务
* 新系统

## 结果

| 维度 | 结果 |
|---|---|
| 开发成本 | 低（MapScene +91 行，零资源纯 Graphics） |
| 代码影响 | 极低（不动 tilemap / 碰撞层 / 交互逻辑） |
| 存档影响 | 0（纯视觉层 + 台词池数据，无字段变更） |
| 玩家心理目标 | 达成（地图空间感 6.5/10 → 8/10） |

## 结论

对于《归星物语》：

> **空间感优先通过"暗示未来"获得，而不是通过增加当前内容获得。**

落地提问模板（未来 AI 提新区域时先自问）：

> "是不是只需要一个远景地标 + NPC 对白，就能达到同样的心理效果？"
