## 〇、总纲

所有系统都应该回答一个问题：

> **这个东西有没有让青禾镇变得更像一个活着的地方？**

---

## 一、六层升级

### 第一层：让"种什么"有意义（已部分落地）

作物不是时间/价格的差异，而是生活场景：

- **萝卜** = 青禾镇日常（腌萝卜 / 集市摊位 / 居民晚饭）——"这个东西属于这里"
- **番茄** = 夏天、厨房、分享（夏雅："以前爷爷总会种一排番茄。"）
- **玉米** = 丰收（未来丰收节核心作物）

玩家自然产生："这个季节我应该种什么？"而不是"哪个卖钱多？"

### 第二层：农场变化（世界回应）

- 连续种花 → 农场边缘出现蝴蝶 / 蜜蜂 / 小动物
- 种满蔬菜 → NPC 偶尔来："小菜园看起来不错。"

不是数值奖励，是世界回应。

> ✅ **v1.4「土地回应系统」首片已实现（2026-08-15 制作人拍板）**：
> - 触发：farm 同时 ≥3 格成熟作物（世界状态，不做成就/生态值）→ `crop_field_alive` 一次性入档（永久记录）
> - A 花园回应：农田边缘出现 3 蝴蝶 + 2 蜜蜂（非可捕捉，纯环境生命感）；夏雅路过一句"感觉这片地又活过来了"（一次性）
> - B 菜园回应：农田有成熟作物时，小梅日常偶尔一句"最近菜园看起来不错"（seed 轮换=偶尔，非次数判断）
> - 与番茄架的区别：番茄架=一株植物→一个人→一段记忆；农场回应=玩家长期行为→整个环境→生命变化
> - 命名：种植系统内部设计正式改名「**土地回应系统**」（鱼会回应 / 森林会回应 / 居民会回应 / 土地也回应）
> - 探针 `.tmp/probe-crop-field-life.mjs` 8/8；切片 A 回归 10/10

### 第三层：作物成长事件（最有特色）

植物可以成为剧情入口。例：种番茄 → 某天夏雅路过 → "这个地方以前也有一排番茄。" → 她帮忙搭架子 → 永久留下小番茄架。

### 第四层：种植和庆典连接

EventPlan 素材来自作物：艺术展需要野花；丰收节需要玉米；灯塔观海夜需要海边植物。不是"收集 100 个玉米"，是"镇上准备丰收展示，需要一些今年种出的玉米"。

### 第五层：种子来源

- 老居民："这是我年轻时留下来的种子。"
- 探索：森林发现野生植物
- 活动：艺术展后获得特殊花种

种子本身变成故事。

### 第六层：收获后的去向

三条路：

1. 留给小镇 → 提升关系
2. 用于制作 → 料理、装饰
3. 出售 → 获得金币

不是让玩家算收益，而是不同选择产生不同反馈。

> ✅ 切片 A（2026-08-15 已闭环验收）：萝卜×老张（赠予 → 河边腌萝卜罐 + 晒萝卜干句）/ 番茄×夏雅（"她记得"→ 番茄架永久）/ 玉米×小镇（丰收台词，为 v1.5《秋日晒场》铺垫）。触发=种→收→路过→NPC 发现，非任务。`probe-crop-slice-a` 12/12。
> 📌 制作人拍板（2026-08-15）：**v1.4 不扩内容、正式收口**；不补傍晚番茄，保留"清晨唯一遇见"的偶然感（符合 D-032）。玉米丰收台词即 v1.5《秋日晒场》的伏笔钩子（见 `docs/design/秋日晒场-垂直切片设计稿-v1.0.md`）。

## 二、长线招牌：《老种子的故事》

玩家偶然获得一包旧种子，不知道是什么。种下、成长，最后发现是青禾镇以前很常见的花。居民看到："好多年没见过这种花了。"

> 不是种植系统，是**让消失的东西重新回来**。
