# 《丰收节》垂直切片设计稿 v1.0（v1.5 · 生活循环闭合后的第一次全镇回应）
> 系统：EventPlan 第二个实例｜关联：`星光艺术展-垂直切片设计稿-v0.2-拍板基线.md`（首个实例，模板已验证）、`庆典筹备系统设计-v0.2-拍板方向.md`（四活动方向：丰收祭为本)、`种植系统生活化方向-v0.1.md`(玉米=丰收节核心作物伏笔)、`第一章剧情大纲-v0.3-归园新序-拍板基线.md`
> 前置里程碑：🏁「生活循环闭合」（2026-08-15 制作人确认，四大基础循环全部有出口）
> 核心立意：**丰收节不是"种植系统大型玩法"，是"第一次全镇因为玩家这一季的生活而回应玩家"。**

---

## 〇、一句话定位

> 之前玩家帮助一个人（老张/夏雅/老姜）；这一次，**整个青禾镇因为玩家这一季的生活，第一次聚在一起庆祝有东西可庆**。

秋收时节，玉米成熟，镇上的人想起很久没办过的丰收节——于是这一次，是镇子主动为玩家的收获摆起的一场「回应」。

## 一、设计红线（对齐既有护栏）

1. **规模 ≤ 春日集**（克制版 ≤ 观星夜 40%）——不做大型活动、不做复杂玩法、不做倒计时/失败惩罚。
2. **复用 EventPlan 模板**（prepare / active / aftermath / permanent）——它是第二个实例，不是再造系统。
3. **三类准备都是"镇子在准备什么"的世界状态**，不是玩家待办清单（庆典筹备系统 §九.2）。
4. **解锁由"生活事件完成"决定**，不做"人气数值涨到 X"的成长条（庆典筹备系统 §九.1）。
5. **不新增资源/不新增地图/不新增常驻 NPC**——资源全部来自现有玩法产出（玉米/蔬菜/鱼/采集物）。
6. 台词方向稿施工，制作人"人话化"定稿后替换（同星光艺术展/钓鱼标准）。

---

## 二、触发前提（发现 → 第一阶段）

- 前置事件链（生活事件解锁，非数值）：
  - 章节 ≥1
  - 春日集完成（`ch1_spring_fair`）——镇子"重新热闹起来"的基线
  - 首次收获玉米（`crop_corn_first_harvest`）——玉米丰收是"今年有什么可庆"的物质前提
- 弱引导（写在居民台词里，不广播）：第一次收玉米时镇长/老张那句"今年玉米长得不错。"（已实现，作为伏笔钩子）。

## 三、EventPlan 三阶段（对齐星光艺术展模板）

### 3.1 准备期（prepare：三类准备，世界状态）

> 触发后，镇子进入准备期。玩家回 town 时能看到镇子在为丰收节做这事——**不是任务板**。

| 类 | 世界状态 | 复用/落点 |
|---|---|---|
| 环境 | 广场挂谷穗 / 摆农产品桌（零素材 Graphics，对齐星光艺术展环境物件范式） | town create 按准备进度渲染 |
| 人际 | 老张负责传统食物 / 夏雅整理旧照片 / 阿风帮忙搬东西（一次触发，对话后世界变化） | showDialogue 注入（对齐 `buildArtShowDialogue`） |
| 资源 | 玉米 / 蔬菜 / 鱼 / 采集物——"为丰收展示准备点今年种出来的东西" | 素材箱交付点（复用 `artShowBox` 范式） |

### 3.2 当天（active：规模 ≤ 春日集）

收获之夜（夜晚进 town 触发，一次性）：

- 篝火 + 人群剪影（复用春日集灯火/剪影视觉语言，零新素材）
- 食物（桌上的蔬菜/鱼 = 玩家这一季的产出被吃/被摆）
- 老人讲以前的丰收节（一段对白，勾连"镇子曾经的热闹"）
- 林澈发现：**自己已经不是游客了**（一句内敛对白，不广播、不总结）

### 3.3 余波 / 永久变化（aftermath / permanent）

- 广场新增**丰收展示架**（永久，读档保持）——上面是玩家这一季的作物（简单的谷物穗 + 展示牌）
- 商店新增**本地食材**台词/语境（丰收后店里供应的东西多了）
- NPC 每逢秋收聚集一句（淡，不重复播放）

---

## 四、为什么是"第一次全镇回应玩家"（价值）

- 采集/钓鱼/种植此前都是**单个居民**对玩家的反馈（小梅/老张/夏雅）。
- 丰收节是第一个**全居民共同**的回应：镇子因为玩家这一季种下的东西，聚在一起庆祝。
- 与第二章《故人远来》呼应：镇子"被记住"后，外面的人开始重新发现这里——丰收节的展示架和商店本地食材，是"镇子开始向外流动"的第一个常驻痕迹。

## 五、验收标准（对齐星光艺术展 §八：共两条）

1. **永久变化存在**：广场丰收展示架 + 商店本地食材语境 + NPC 秋收集结句（读档保持）。
2. **第二次路过广场"不一样"**：丰收节后广场有展示架；秋天 NPC 会聚在展示架/篝火附近；商店里能感觉到"今年有收成了"。

## 六、明确不做（本切片）

- ❌ 复杂玩法（QTE / 计分 / 挑战）
- ❌ 倒计时 / 限时 / 失败惩罚
- ❌ 新增资源 / 新增地图 / 新增常驻 NPC
- ❌ "收 100 个玉米"式肝度——准备期资源是"放一些今年种出的东西"，不是数值收集
- ❌ 人气数值成长条

## 七、技术映射（零新系统）

| 能力 | 复用 / 落点 |
|---|---|
| EventPlan 状态 | 复用 `mapFlags` + 一次性 `triggerOnce`（对齐 artShow 字段范式），**不新增顶层存档字段/不新增 EventPlan 框架** |
| 三类准备 | town create 状态渲染 + showDialogue 注入 + 素材箱交付 |
| 当天演出 | 春日集灯火/剪影视觉语言（`buildSpringFairFX` 范式），零新素材 |
| 永久变化 | 广场展示架 Graphics + 商店台词/本地食材语境（读档保持） |
| 触发 | `ch1_spring_fair` + `crop_corn_first_harvest` 均完成 → 软触发（进 town 夜晚） |

## 八、边界：与春日集 / 星光艺术展的区分

| 事件 | 是谁的回应 | 立意 |
|---|---|---|
| 春日集 | 镇子自发的热闹（集市恢复） | "原来还能热闹起来" |
| 星光艺术展 | 外向——把光展示给世界 | "青禾镇重新被看见" |
| **丰收节** | **内向——镇子为玩家这一季的收获回应** | "今年终于有东西可以庆祝了" |

## 九、待制作人拍板项

1. 触发时机 & 前置：玉米首次收获即可，还是需要"种过 ≥ 规定季数"？倾向前者（生活事件解锁，非数值）。
2. 当天演出时段：夜晚（对齐春日集灯火）还是黄昏（暖）？倾向"收获之夜 = 过午/傍晚开始，夜里篝火"。
3. 人际准备三人选（老张/夏雅/阿风）是否符合你心里的分工。
4. 永久变化的展示架形态（谷物穗展示牌）是否符合尺度。
