## 一、两张地图的定位差异（核心）

| | 青禾河畔 | 废弃果园 |
|---|---|---|
| 情绪 | 开放、治愈 | 怀旧、温暖 |
| 玩法密度 | 高 | 低 |
| 资源 | 水边资源（芦苇/贝壳/河草/河螺/萤火虫） | 植物资源（野花/蜂巢/果树枝/落果） |
| 核心 | 人与自然连接 | 人与过去连接 |
| NPC | 多人偶遇 | 单人剧情 |
| 功能 | 日常地点 | 故事地点 |
| 关键词 | 我开始重新融入这里 | 我开始理解这里曾经发生过什么 |
| 承担 | 新探索空间 / 钓鱼入口 / 水资源采集 / NPC 日常 / 复兴反馈 | 回忆 / 成长 / 旧生活 / 季节感 |

> 一句话：一个负责「留下来」，一个负责「为什么留下来」。

## 二、青禾河畔（推荐第一章）

### 地图定位

- 新探索空间
- 钓鱼入口
- 水资源采集
- NPC 日常活动
- 城镇复兴反馈

### 尺寸建议

**40×30 tile（16px → 640×480 px）**，移动端刚好，不要更大。

### 结构示意

```text
        北
 ┌────────────────┐
 │      小树林     │
 │  🌲       🌲    │
 │                │
 │      河流       │
 │================│
 │~~~~~~河~~~~~~~ │
 │~~~~~~河~~~~~~~ │
 │                │
 │ 码头     草地   │
 │                │
 │入口            │
 └────────────────┘
        南
```

### 区域拆分

#### ① 入口区（南侧）

- 作用：玩家进入后的缓冲
- 内容：路牌 / 长椅 / NPC 闲聊点
- 初期荒废：杂草、坏木箱、断掉的小路
- 复兴后：石板路、花、路灯（对齐 FarmRestore 思路）

#### ② 河岸区（核心，玩法中心）

- 钓鱼点：小码头 / 木桩 / 水波动画
  ```ts
  FishingSpot {
    id: "qinghe_river_01",
    fishPool: ["鲫鱼", "青禾河虾", "稀有鱼"]
  }
  ```
- 河边采集：
  - 普通：芦苇 / 贝壳 / 河草
  - 雨天：河螺
  - 夜晚：萤火虫

#### ③ 河边小亭/旧凉亭（停留空间，非功能建筑）

- 玩家可坐下、看风景、触发 NPC
- 夏雅：白天整理照片 / 晚上看星星

#### ④ 河上桥（未来扩展点）

- 当前：断桥，需木材修复
- 以后：通往废弃果园（两张地图自然连接）
- 第一章建议只做「看到断桥 + 老人提及 + 入口封锁」，制造期待：
  > “河对面还有地方。”

### 状态变化（三阶段）

| 阶段 | 条件 | 变化 |
|---|---|---|
| Stage 0 | 初见 | 脏乱、杂草、断桥 |
| Stage 1 | 木材×20 | 码头出现、钓鱼开放 |
| Stage 2 | 集市事件完成 | 长椅、灯、NPC 出现；晚上有人聊天 |

## 三、废弃果园（第二章预埋）

### 定位

偏剧情：回忆 / 成长 / 旧生活 / 季节感。**不做经营农场**，重点是探索和情绪。

### 尺寸建议

**35×25 tile**，略小于河畔。

### 布局示意

```text
        北
 ┌────────────────┐
 │   老果树区域    │
 │ 🌳 🌳 🌳 🌳    │
 │       小屋      │
 │                │
 │  果园道路       │
 │                │
 │入口             │
 └────────────────┘
        南
```

### 区域设计

#### ① 果园大道

- 现在：落叶、荒草、倒下的木牌
- 修复后：小路、花、果树开花

#### ② 老果树区（核心 = 记忆地点，非资源点）

- 一棵老树互动：「爷爷以前总喜欢坐在这里。」
- 触发短剧情，一个画面就够，不堆文本

#### ③ 果园小屋

- 类似旧宅：旧篮子 / 剪枝工具 / 收音机
- 可接 EventPlan（例：「小梅帮忙整理果园」）

#### ④ 果园采集

- 不大量出水果（避免与农田重复）
- 特殊资源：野花 / 蜂巢 / 果树枝 / 落果
- 用途：堆肥 / 花肥 / 染料

## 四、工程结构建议（方案，未实施）

不要做两个大 Scene 平铺；共享系统、数据驱动。

```text
scenes/
  MapScene.ts
   ├─ QingheRiverMap
   └─ OldOrchardMap

systems/（共享）
  ResourceSpawner.ts
  NatureSystem.ts
  EventManager.ts
  WorldState.ts
```

数据驱动示例：

```ts
{
  "map": "qinghe_river",
  "resources": [
    { "id": "reed", "condition": { "weather": "rain" } }
  ],
  "events": ["river_restore_01"]
}
```

> 原则：逻辑不写死在 Scene。

## 五、工程评估（Agent 建议，供制作人拍板）

### 与现有系统的复用（零新系统）

| 方案需求 | 现有资产 |
|---|---|
| 钓鱼点 | ✅ 钓鱼系统已跑通（`tryFishingInteract` / FISHING_SPOTS / 鱼池分层） |
| 河边/场景采集 | ✅ 生活采集 Phase 1（Gathering.ts + triggerOnce 已采持久化） |
| 码头/河畔修复 | ✅ FarmRestore 范式（`markRestored` / 资源交付 / 一键补齐） |
| NPC 日常/偶遇 | ✅ NPCSystem 作息 + StoryDialogue |
| 凉亭停留/小事件 | ✅ 老树/观景台交互范式 + 相簿 |
| 雨天/夜晚条件资源 | ✅ WeatherSystem + TimeSystem |
| 断桥修复→果园 | ✅ 出口 locked 预埋范式（同灯塔 exits.ts locked） |
| EventPlan 活动 | ✅ EventPlan 准备系统（秋日晒场模板） |

### 与第一章红线的冲突点（需制作人决策）

- 第一章总纲红线：**❌ 无限扩张：大地图/新大陆/大量 NPC/复杂剧情线**
- 当前阶段原则：**「制造未来，不制造地图」**——新区域只做视觉+台词起步

因此 Agent 建议的第一刀（不等同于已拍板）：

1. **青禾河畔**：以「河畔修复垂直切片」形式进入第一章收尾或后续批次（Stage 0→1：断桥可见 + 木材修复 + 码头 + 钓鱼开放）；Stage 2（NPC 聚集/夜晚聊天）可后置。
2. **废弃果园**：第一章只做「预埋」——河畔断桥、老人一句提及、入口封锁；完整地图留第二章。
3. 两张地图共享 `MapScene.ts` 实例配置，不新建重型 Scene 框架。

### 待拍板问题

- 青禾河畔是否纳入第一章（若纳入，挂在哪一批次/哪条主线之后）
- 河畔 Stage 2 与集市/EventPlan 的先后
- 果园第一章预埋的具体形态（断桥位置/老人台词）
