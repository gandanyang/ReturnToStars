## 〇、定位

钓鱼从「赚钱 / 换物」升级为**探索入口**，玩家对每竿有三层期待：

1. 今天能钓到什么鱼？（普通鱼层）
2. 河里的小生命有没有变化？（小鱼苗事件，✅ v1.3 已实现）
3. 这条河会不会带回来一个故事？（河流故事物品层）

采集 = 自然给予；种植 = 玩家创造；钓鱼 = **河流回应**。

## 一、概率分层（制作人方向 80 / 15 / 5）

| 层 | 概率 | 内容 | 状态 |
|---|---|---|---|
| 普通鱼 | 80% | 青禾鲫 / 河虾 / 黄昏鱼（+ 可选新增物种） | ✅ 现有 |
| 特殊生态事件 | 15% | 小鱼苗（青禾鱼苗）→ 放回/带走 | ✅ v1.3 已实现（探针 10/10） |
| 河流故事物品 | 5% | 漂流瓶 / 旧钥匙 / 老照片碎片 / 特殊贝壳 / 奇怪的木牌 | ⏸ 待拍板 |

> 实现位置：`MapScene.pickCurrentFish` 普通钓点分支（独立随机，不影响原物种概率表）。

## 二、特殊鱼（制作人拍板：分两类，遵守「遇见原则」D-032）

**不做"传奇鱼刷新"**。特殊鱼分两类：

### 2.1 普通特殊鱼（生态类，可重复，✅ v0.5 已实现 2026-08-15）

属于世界的常态，可以反复钓到：

| 鱼 | 出没 | 建议售价 | 一句话描述方向 |
|---|---|---|---|
| 河鳗 | 夜间（19:00-23:00，55%） | 60G | 夜里才从石头底下钻出来 |
| 鲤鱼 | 全天低概率（8%） | 35G | 老河里的常客，个头不小 |
| 大青鱼 | 黄昏（17:00-19:00，35%） | 90G | 咬了就跑，收竿要更稳 |

用途：出售 / 料理 / 交换；直接进背包，不打断。实现位置：`MapScene.FISH_KINDS / pickCurrentFish`（独立随机，不影响原物种表）+ `Economy.SELLABLE_ITEMS`（60/35/90G）+ `Inventory` 条目 + 老姜鱼种评价（台词初稿待定稿）；探针 `probe-fishing-phase1.mjs` T8 全绿。

> **老姜台词方向（制作人 2026-08-15 拍板）**：不做"鱼图鉴说明"——老姜不是系统，是**见过这条河变化的人**，作用是帮玩家感受到"这条河以前是什么样，现在又回来了一点"。三句已按此原则改写（河鳗：以前夜钓的人等它 / 鲤鱼：这几年又见着它 / 大青鱼：好些年没见这么大的），仍待"人话化"定稿。

### 2.2 故事鱼（唯一，一次经历）

例："银鳞小鱼"——**不是收藏品，是一次经历**：

- 玩家"刚好遇见"它（唯一一次，不重复刷新）；
- 放生 → 以后河里多鱼影（与鱼苗生态事件不同：唯一、故事性更强）；
- 具体流程（是否给选择 / 是否进背包 / 触发时机）待拍板。

### 2.3 原则延伸（覆盖采集 / 种植 / 探索）

- 例：一朵特殊老花——不做"每天刷新"，而是"**玩家第一次发现它**"；
- 核心：不是"我刷到了一个稀有道具"，而是"**我刚好在那个时间，遇见了一件事情**"；
- 实施检查：任何稀有/故事级内容立项前先过「遇见原则」（可重复生态 vs 一次性遇见）。

待定项：
- 普通特殊鱼是否新增（或保持现有 3 种普通鱼 + 月光鲈即可）；数值待拍板；
- 新增物种是否绑定钓鱼修行/图鉴；
- 是否需要新立绘/图标（当前鱼用 emoji + 程序鱼形，零素材可先跑）。

## 三、河流故事物品（5%，核心待拍板项）

原则：**不是垃圾，是"河流把过去送回来"**。钓到即暂停一小段（旁白 + 老姜一句解释），物品进背包收藏，不设售价。

### 巧合原则（制作人拍板 D-031，2026-08-15）

- **每件故事物品在整个游戏中只出现一次**——尤其漂流瓶，钓到是巧合，重复钓到就太刻意。
- 故事物品层（5%）从"未获得"的物品池中抽取；已获得的物品移出池子。
- 若未来需要第二次"漂流瓶式"事件 → 改用**其他物品**指代（旧钥匙 / 老照片碎片 / 特殊贝壳 / 奇怪的木牌，或新增物品）。
- 池空后：该 5% 回到普通鱼，不再掉落故事物品（"河里的故事讲完了"，本身也是一种留白）。
- 实现提示：`triggerOnce('storyitem_<id>_found')` + 池子只放未触发物品；不用次数/随机权重重复给同一物品。

### 候选清单与未来钩子

| 物品 | 钩子 | 首次获得反馈（方向） |
|---|---|---|
| 旧钥匙 | 老仓库 / 老屋某处 | "不知道能开哪扇门" |
| 老照片碎片 | 第二章《故人远来》 | 交给夏雅/老木匠可拼合 |
| 特殊贝壳 | 灯塔观海夜 | "海边才有的东西，怎么在河里" |
| 奇怪的木牌 | 未来修复 / 支线 | "上面刻着半个字" |

### 漂流瓶：保留给「星星线」（制作人拍板 D-033，不施工）

漂流瓶**移出待施工清单**——它是唯一一次、跨时间空间的叙事媒介，留给真正重要的主题：

- 署名《来自星海的旅人》/"星海的旅人 A"，是"**来自远方的回应**"，不是普通奇遇（思念故乡等交给老照片 / NPC 回忆 / 故人远来）。
- 出现条件 = **世界回应**，不是抽奖：完成"星光相关事件"（观星夜 / 灯塔亮起 / 夜晚海边）后，某天钓鱼才有概率遇见。
- 与灯塔线连接：灯塔重新亮起 → 有人在远方看见 → 漂流瓶 / 信件 / 照片回应。
- 晚揭开：第一章见到署名，第三章/后续才知道 A 是谁。
- 实施时先过星光事件门禁；具体文案与时机待制作人排期（未来章节伏笔）。

### 河流故事物品：暂缓（制作人 2026-08-15 拍板）

- 旧钥匙 / 老照片碎片 / 特殊贝壳 / 奇怪的木牌 **暂缓施工**，不再追加。
- 原因：钓鱼已有普通收益 / 特殊生态 / 放生反馈 / 未来故事入口（漂流瓶），再继续加容易让河流变成"**随机剧情箱**"，违背 D-032。
- 漂流瓶继续锁死星星线——它的价值是"当星星主题真正需要回应的时候，河流送来的第一句话"，**不提前消费**。

### 老姜 = 解释者（非任务发布者）

制作人示例句：

> 老姜："河流有时候会把很久以前的东西带回来。"

建议只做 1 句/物（一次性），不解释用途、不给任务——玩家自己决定拿它做什么。

## 四、建议施工范围（若拍板）

垂直切片建议（一次只做一个闭环）：

1. **漂流瓶已保留给星星线（D-033，不施工）**；
2. 其余故事物品（旧钥匙 / 老照片碎片 / 特殊贝壳 / 奇怪的木牌）是否施工、先做哪个——待制作人拍板（可考虑也后置，先保生态层）；
3. 特殊鱼视拍板并入同一批或后置。

验收：探针验证概率分层存在 / 首获暂停反馈 / 物品进背包 / 读档保持 / 无运行时错误。
