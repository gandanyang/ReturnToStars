# 《星光艺术展》垂直切片设计稿 v0.1

> 状态：⚫ **已被替代**（2026-08-15）：制作人逐项拍板后升级为 `星光艺术展-垂直切片设计稿-v0.2-拍板基线.md`。本稿仅作历史存档。
> 定位：庆典筹备系统的**垂直切片**——用一次完整的星光艺术展证明"小镇复兴是持续发生的过程"，不是一次性剧情事件。
> 模板属性：本设计稿是未来所有活动的模板（村超 / 丰收节 / 观星夜 / 灯塔观海夜 / 外来摄影展 复用同一骨架）。
> 依据：`庆典筹备系统设计-v0.2-拍板方向.md`｜关联：`第二章剧情大纲-故人远来-v0.2-拍板基线.md`、`第三章剧情方向-商业化与本土情怀-v0.1.md`

## 〇、一句话

> **"把青禾镇曾经拥有的光，重新展示给世界。"**

星光艺术展不是普通艺术展——它连接星之碎片、观星夜、灯塔与第二章的"被看见"。展出的不是外来作品，是青禾镇自己曾经拥有的光（老照片、孩子的画、星空装置、镇民的生活）。

---

## 一、定位与命名

- **系统暂名**：「小镇计划」/「近期筹备」（二选一，见待拍板）。玩家感知是"青禾镇最近准备举办一件大事"——**观察，不是接任务**。
- **人气指标**：改名「小镇回响」。不是进度条、不加分；它是**结果**——玩家通过世界变化看到"镇子被记住了多少"（居民谈外面的来信 / 商店出现新客人留言 / 港口偶尔出现陌生面孔）。
- **切片范围**：只做星光艺术展一次完整闭环（解锁 → 筹备 → 当天 → 永久变化）。不搭通用 EventPlan 框架，不做第二个活动。

---

## 二、EventPlan 数据结构理念（概念层，不写代码）

一次"筹备"= 镇子的**一个生活阶段**，由五部分组成：

1. **目标**：一件大事（星光艺术展）+ 一句话主题。
2. **筹备**：三类准备，每一项都是**世界状态**（展台已修缮 / 鲜花已备好 / 夏雅答应帮忙），不是数量条。
3. **当天**：一段约 10 分钟的节拍演出（居民入场 → 展示 → 夜晚）。
4. **回响**：完成后小镇永久留下什么（艺术角 / 新台词 / 新访客）。
5. **唯一性**：每个活动一次性；完成后进入"永久态"，不再重复办。

理念核心：**EventPlan 不是任务包，是"镇子正在发生什么"的容器**。未来每个新活动 = 同一个模板的新实例，差异只在目标 / 素材 / 居民参与 / 当天节拍 / 永久变化。

---

## 三、解锁与契机

**前置**：春日大集（`ch1_spring_fair`）完成。

**契机流程**：

1. 春日大集后，居民生活台词变化："原来咱们还能热闹起来。"
2. 夏雅向林澈提出："把现在的青禾镇摆出来，给大家看看。"（不是任务，是一句生活里的想法）
3. 一封来自远方的信（呼应第二章旧信意象，但方向相反——第二章是"外面的人想回来"，这里是"外面的人想来看"）：一位旅人艺术家听说了青禾镇，想来办一场小展览。
4. 解锁「近期筹备」菜单（只读观察）。

> 旅人艺术家 = 轻量角色（当天到场、展后离开，但**每年展览季会再来**——C 季节性原型的第一个实例）。他不是工具角色：留下长期联系 + 一件展品（永久变化的一部分）。

## 四、筹备阶段（7-12 游戏日）

### 三类准备（固定结构）

#### ① 环境准备（改变空间，完成后永久保留）

- 修复广场展台（中央广场东侧空地，避开石井/石凳/灯柱）
- 布置灯光（复用广场灯柱 + 夜晚灯光系统）
- 摆放花艺（小梅布置，素材来自采集野花）

#### ② 人际准备（改变关系，让居民参与）

- 邀请夏雅帮忙策划（对话 + 她在广场出现的点位）
- 镇长协调开放区域（对话 + 公告板贴出"展览告示"）
- 老周提供旧照片（对话 + 物件：一组旧照片进入展品）
- 孩子们画画（镇上孩子的生活动画 / 展品）

#### ③ 资源准备（连接采集循环，叫"准备展览素材"）

- 野花（小野花 / 蒲公英——**采集系统首个"世界变化"出口**）
- 木材（展台搭建）
- 矿石（星空装置的底座）
- 鱼（展览当晚的晚餐食材，连接钓鱼）

> 呈现方式：每项素材到位 = 世界状态更新（"花艺已经摆上了"），**不是**"收集 100 木头"。
> ⚠️ 贝壳不在现有资源里，垂直切片**不新增资源**；贝壳类素材留给未来活动（如灯塔观海夜）。

### 筹备期的逐日世界变化

广场每天多一样东西（顺序可固定可随机）：

```
搭木架 → 挂灯 → 摆花 → 立展台 → 贴告示 → 孩子们在广场试挂画
```

居民台词随之变化（"听说要办展览" / "我家那口子翻出老照片了"）。

### 完成判断与时间

- 三类准备的世界状态全部到位 → 镇子说"都准备好了，明晚办展"。
- 时间处理（待拍板）：**建议无惩罚软期限**——不设硬倒计时，活动在准备完成后触发；「近期筹备」菜单显示"准备进度"而非"剩余 X 天"（治愈游戏不制造 deadline 焦虑）。

## 五、活动当天（约 10 分钟）

时间线：**傍晚开始 → 夜晚收尾**（正好走一遍阶段3 光照：黄昏暖光 → 夜晚灯光）。

### 开始（下午）

玩家进入广场，发现平时空荡荡的位置变了——展台、灯光、花艺全部就位（筹备期的成果直接可见）。

### 第一阶段：居民入场

- 老人带旧照片走来
- 孩子抱着画跑进广场
- 夏雅最后检查花艺
- （复用 NPC 站位/日程系统，居民走到各自点位）

### 第二阶段：展示（不是演讲，是几个小事件）

- **看画**：展品交互（老照片 / 孩子的画 / 星空装置）——复用 oldTree / grandpaNote 交互文本范式，每件展品一句生活化的故事
- **听故事**：旅人艺术家/老周讲一张旧照片背后的故事（短对白，反 AI 味）
- **看星空装置**：广场中央的灯光装置，夜里亮起（星之碎片意象）

### 第三阶段：夜晚

- 广场灯光亮起（灯柱 + 挂灯）
- 河面倒影（复用河岸光斑/水面反光）
- **远处灯塔回应**（春日集后灯塔已亮，现成资产）

### 收尾

一句生活化谢幕，不总结主题。例如夏雅：

> "明年来的人，就能看到今天这些了。"

---

## 六、永久世界变化（必须有，否则庆典就是烟花）

完成后，中央广场永久增加：

- **艺术角**：展台 + 展示牌 + 长椅 + 夜晚灯光
- **NPC 会在这里停留**（日程增加一个广场艺术角点位）
- 镇子台词变化（居民谈论展览 / 外面的来信）
- 商店出现**新客人留言**（商店面板一条生活留言）
- 港口偶尔出现**陌生面孔**（轻量视觉/台词）
- 旅人艺术家每年展览季回来（C 季节性原型）

**"小镇真的发生变化"——这是本切片的第一验收标准。**

## 七、与现有系统 / 剧情的连接

| 系统 | 连接方式 |
|---|---|
| 剧情 | 解锁于 `ch1_spring_fair` 后；星之碎片/观星夜/灯塔意象贯穿；为第二章"被看见"留第一个回声；为第三章商业化引信（展览让镇子被看见 → 有人想放大） |
| 采集 | 野花 = 采集系统首个"世界变化"出口（补核心循环缺口） |
| 钓鱼/挖矿 | 鱼（晚餐食材）、矿石（装置底座） |
| 光照（阶段3） | 当天傍晚→夜晚的完整光照演出（黄昏暖光 + 夜晚灯光 + 河面光斑） |
| 灯塔 | 春日集后灯塔已亮（现成资产，"远处灯塔回应"直接可用） |
| 居民关系 | 夏雅（策划/花艺）、镇长（协调/告示）、老周（旧照片）、小梅（花）、孩子（画）——人际准备 = 让居民参与 |
| 观星夜 | 星空装置的视觉与气氛复用第 0 章观星夜资产 |

## 八、模板性（未来扩展）

星光艺术展 = 第一个 EventPlan 实例。未来活动套同一骨架，差异只在五处：

| 活动 | 目标主题 | 素材 | 居民参与 | 当天节拍 | 永久变化 |
|---|---|---|---|---|---|
| 星光艺术展 | 把曾经的光展示给世界 | 野花/木材/矿石/鱼 | 夏雅/镇长/老周/小梅/孩子 | 看画→听故事→星空装置→夜晚 | 广场艺术角 |
| 青禾村超 | 乡村活力 | 木材/食物/应援物 | 年轻居民/老姜当裁判 | QTE/点击/观众/直播镜头 | 年轻居民增加 |
| 丰收节 | 农业收获 | 作物/食材 | 全员 | 居民展示成果 | 丰收纪念碑/田边装饰 |
| 星辰观测夜 | 未完成的梦想 | 望远镜零件/饮品 | 镇长/夏雅 | 观星 | 新的夜晚场景 |
| 灯塔观海夜 | 守夜 | 贝壳/矿石/饮品 | 灯塔守护者 | 点灯/海面 | 灯塔区域开放（远期） |
| 外来摄影展 | 被看见之后 | 照片/布展 | B 记录者 | 看展/对话 | 第三章商业化张力（远期） |

## 九、待制作人拍板项

1. **菜单命名**：「小镇计划」vs「近期筹备」
2. **旅人艺术家角色轻重**：当天轻量角色（有名字、无立绘）vs 无实体（只留信件与作品）
3. **时间处理**：无惩罚软期限（推荐）vs 硬倒计时（"剩余 X 天"）
4. **展览素材具体项**：确认野花/木材/矿石/鱼四类（贝壳后置）
5. **当天演出**：是否复用观星夜资产做星空装置
6. **艺术角位置**：中央广场东侧空地（推荐）还是北侧老街
