## 〇、一句话

**第二章的问题是"人为什么回来"；第三章的问题是"这个岛最终会成为什么"——答案不在镇上，在西边那座终于可以走进去的灯塔里。**

- 章题《归位》三层含义（方向，待拍板）：碎片**归位** / 灯塔**归位**（重新接管海路）/ 人**归位**（留岛或返城的选择）。
- 章节关键词（叙事原则 v1.2）：**理解 → 选择**。第一章"发现"、第二章"行动"攒下的所有东西，在这一章被理解，然后被选择。
- **红线**：第三章的"谜底"（灯塔是什么、爷爷发现了什么、黑点是什么船、夏雅与灯的关系）**本文一律不写**——
  只规划"答案在哪个节拍、由哪个物件承载、给玩家什么情绪"。谜面解法待制作人逐项拍板后填入。

## 二、章节结构（五幕方向稿）

```
幕一 灯塔开门（章节奖励落地：走进灯塔）
  ↓
幕二 执灯人（新 NPC + 灯塔三件套：航海日志/铃铛/老望远镜）
  ↓
幕三 外来的船（黑点靠岸 → 商业化冲突开局，B 立场展开）
  ↓
幕四 理解（观察日记线：爷爷为什么等林澈回来——碎片集齐的推进节奏待拍板）
  ↓
幕五 归位（岛屿苏醒的方向性演出 + 留岛/返城选择 → 多结局）
```

### 幕一 · 灯塔开门
- 直接落地灯塔区域生产方案 §七接口：`worldRestore.lighthouseUnlocked`（序列化同 FarmRestore 模式）→
  `exits.ts` 移除 farm 西侧海湾 locked → **新地图：灯塔半岛**。
- 解锁前置（行为链，非任务——对齐灯塔方案 §二）：复兴节点由制作人定；建议=秋日晒场+第二章全节拍完成。
- 首次进入的"章节奖励"感：观海崖视野 + 灯塔内部 + 执灯人初见（不解释身份，同老船长范式）。

### 幕二 · 执灯人与灯塔三件套
- **执灯人 NPC**（灯塔方案预留："这个岛重新开始运转之后，有人重新回来接过这盏灯"）：
  短句范式同老船长；身份背景待拍板（不新增身世谜团——谜团预算已满，见 §四）。
- 灯塔三件套（灯塔方案预留交互，本幕激活）：**航海日志**（观察日记线的物质载体——顶层设计"观察日记揭开
  爷爷为什么等林澈回来"）/ **铃铛**（可与夜航/黑点事件联动）/ **老望远镜**（观海夜演出 + 贝壳钩子的家）。
- 玩法映射：维护行为链（灯塔方案 §二范式：不是"修灯塔"任务，是日常使用产生意义）。

### 幕三 · 外来的船
- 黑点靠岸。来船性质/来人身份 = **谜团预算项，待拍板**；唯一硬约束：**B 不是反派**（拍板原文），
  B 的冲突是"记录 vs 被看见"与"留下 vs 被知道"，不是商业入侵打脸戏。
- 冲突玩法映射：不新增系统——复用需求板/对话分支/EventPlan 范式的"全镇反应"（镇民立场分化用注脚台词，不站队任务）。

### 幕四 · 理解（观察日记线）
- 顶层设计既定：观察日记揭开"爷爷为什么等林澈回来"。载体=航海日志+碎片（**碎片集齐节奏/每片位置：待拍板**，
  碎片骨架 v1.2 纪律：骨架不写答案）。
- 与既有系统联动：自然笔记（小梅线）×B 的影像档案（第二章预留的呼应点）——两条"记录"在幕四合流。

### 幕五 · 归位（多结局）
- 顶层设计既定：多结局（留岛/返城）。方向稿建议 **2+1 结局骨架**：留岛 / 返城 /（待拍板：第三态——
  "两边的桥"，与 A/B 之争的解法同构）。选择机制：不用选项面板硬选，用**最后一个行为**承载（对齐
  "关键剧情节点/玩家选择=制作人权限"，仅列框架）。
- 岛屿苏醒的方向性演出：复用灯塔阶段 3（船回灯火）的语言——全镇在场的告别/清晨场景，EventPlan 范式。
