# 《归星物语》反馈层级 v1.0

> 状态：✅ 制作人拍板（2026-08-15）｜目的：以后所有游戏反馈按"重量"分级，不混用；普通事件用轻反馈，重要事件用醒目反馈，避免全员弹窗廉价化。
> 关联：`src/ui/StoryNotification.ts`（Level 3-4 的载体）、`MemoryMoment` / `showDialogueText` / 现有 toast / QuestPanel。
> 核心气质：不是"恭喜完成任务"，而是**"记忆被翻开了一页"**；告知玩家"你改变了什么"，不只是"完成了"。

---

## 一、为什么需要层级

现状：`MemoryMoment` / `QuestPanel` / `Toast` / `DialogueText` 分散在不同地方，同一个任务完成有的弹记忆卡、有的浮字、有的只有音效——**不统一、没有按重量排序**。

下一步不是再加一个弹窗，而是**建立分级准绳**：所有反馈按重量走，以后新增内容知道该用哪一级。

## 二、四层反馈（制作人拍板）

| Level | 名称 | 停留/表现 | 典型内容 | 现有/未来载体 |
|---|---|---|---|---|
| **L1** | 即时反馈 | ~0.5s，浮字 | 采集「获得蒲公英×1」/ 砍树 / 挖矿 浮字 | `showDialogueText`（现有） |
| **L2** | 事件反馈 | ~2s | NPC 小事件（夏雅想起一段往事）/ 捡到相簿解锁 toast | `showMemoryMoment`（现有）／相簿 toast |
| **L3** | 重要记忆 | ~3s | **心语任务完成 / 重要支线完成 / 复兴事件**：标题 + 一句"你改变了什么" | **`StoryNotification`（新建，本规范的核心用途）** |
| **L4** | 章节节点 | 全屏 | 章节卡：第一章《归园新序》主线某阶段开启 | 章节 Banner（已有 D-020）/ StoryNotification 扩展 |

> **普通事件继续用 L1/L2**（浮字 / toast / 小提示），不做成 L3 弹卡——否则会廉价化。
> **L3 只给重要事件**：主线目标、心语任务（春深有信）、复兴事件。

## 三、L3「StoryNotification」的关键写法：言之有物

主标题 = 事件名；副标题 = **"你改变了什么"**（一句话生活场景，不是"任务完成"）。

| 事件 | ❌ 普通写法 | ✅ 《归星物语》写法 |
|---|---|---|
| 心语·一 完成 | 任务完成：春深有信·一 | 春深有信·一<br>沉睡的花种，又在青禾镇的一角发芽 |
| 花田反馈 | 已修复花田 | 青禾镇的新芽<br>有人开始照料那些被遗忘的花了 |
| 复兴事件 | 复兴进度解锁 | 归园新序<br>镇子慢慢从寂静里醒过来 |

## 四、L3 视觉风格（制作人拍板：暖金星光，克制）

- **不要**：金色边框 / 大量粒子 / 类原神任务完成。
- **要**：旧纸张 + 星光 + 呼吸感。
- 节奏：淡入 → 标题慢慢出现 → 背景有星尘漂浮 → 停留 ~1.5-3s → 淡出。
- 感觉像："记忆被翻开了一页。"而不是"恭喜玩家完成任务！"

## 五、职责边界（重要）

- `QuestPanel`：玩家**主动查看**任务的列表/领取。
- `StoryNotification`：**世界主动告诉玩家**重要事件发生了。
- 两者职责不同，**不互相污染**；StoryNotification 独立新建。

## 六、使用约束（避免滥用）

1. 只有 L3 范围（主线 / 重要支线 / 心语 / 复兴事件）才用 StoryNotification。
2. 同一事件只弹一次（读档不重弹，随已有一事件标记/存档）。
3. 不打断玩家操作（类似 showMemoryMoment 的不冻结特性；L4 章节可考虑短暂停顿）。
4. 副标题必须"言之有物"，写"你改变了什么"，不写"任务完成"。
