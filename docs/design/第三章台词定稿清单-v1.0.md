# 第三章台词定稿清单 v1.0（幕一~幕三方向稿汇总，供制作人批量改定）

> 用途：全部第三章新增台词（方向稿、未定稿）按场景汇成一表。制作人逐句改定后，本表回填 → IndexTTS 生成 → 试听 → 接入（语音交付红线）。
> 范围：幕一初见 / 幕二三件套+执灯人 / 幕三靠岸+记录计划+镇民注脚 / 幕三后半碰面 / 幕四日记+碎片+结算 / 幕五归位+三结局（共 89 句）。**不含**谜底类台词（幕四/五待拍板）。
> 定稿纪律：文本风格与反AI味标准 v1.1（遮掉名字能猜出是谁；行动型角色不解释）；老周/老船长式短句 ≤15 字优先。
> 日期：2026-08-31

## 使用方式

直接在「制作人定稿」列改写；不改的句子标 ✅ 即视为定稿。改定后：
`tools` 生成 → 试听 → 接入（同试玩-07 流程）→ probe-ch3-lighthouse/keeper/ship 回归（断言含台词锚词的需同步更新探针）。
