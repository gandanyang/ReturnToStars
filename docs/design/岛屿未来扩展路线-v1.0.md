## 一、路线核心原则

> **灯塔不是新地图，是"修复灯塔 → 海上航线恢复 → 新人物回来"。**
> **废弃码头不是场景，是"恢复农业供应 → 旧船重新靠岸"。**

所有扩展区域都是**玩家行为的果**，不是凭空出现的地图。

---

## 二、扩展路线全景（按"玩家做了什么 → 世界变成什么"组织）

```
玩家劳动
   ↓
土地恢复 / 岛回应
   ↓
居民重新产生希望
   ↓
【解锁条件达成】→ 新的区域 / 人物 / 故事出现
```

| 区域 | 解锁条件（玩家做什么） | 世界变化（出现什么） | 当前状态 |
|---|---|---|---|
| **灯塔** | 修复灯塔（未来） | 海上航线恢复 → 执灯人归来 → 灯塔开放 | P0 远景已实施，可进入 locked 预埋 |
| **废弃码头** | 恢复农业供应 / 岛恢复生机 | 旧船重新靠岸 → 新人物随船回来 | P0 远景已实施 |
| **老街** | 小镇恢复生机 | 老店铺重新开张 / 老居民回来 | 未实施（视觉+台词起步） |
| **温泉** | 森林深处探索解锁 | 休闲设施 / NPC 故事 / 季节活动 | 未实施 |
| **封锁山路** | 矿山恢复 / 后山道路修复 | 山路开放 → 岛更深处 | 未实施 |
| **港口** | 航线恢复 | 重新连接外界 → 商路 / 新资源 | 未实施 |

> 全部以"远景 + 一句对白"起步，玩家产生"以后我要回来看看"即可；可玩化是**第四阶段**（修复它们）的事。

---

## 三、灯塔扩展链路（P0 → 未来）

### 现状（P0 已实施）
- 农场西侧海湾，白天可见轮廓；夜晚灯室**恒黑**（"现在它是黑的，有一天它会亮"）
- 可进入：否（出口 locked 预埋）
- 叙事定位：岛曾经连接外界的证明

### 未来链路（对应碎片第二章"改变岛"）
```
修复灯塔
   ↓
灯塔重新亮起（恒黑 → 亮）
   ↓
海上航线恢复
   ↓
执灯人归来（新人物）
   ↓
灯塔开放（可进入）
   ↓
新的人物 / 故事 / 资源出现
```

### 与碎片系统的连接
灯塔是碎片第二章"它改变岛"的关键表现之一：**灯塔重新亮起 = 世界变化可感知**。

---

## 四、废弃码头扩展链路（P0 → 未来）

### 现状（P0 已实施）
- 车站/海岸附近，破旧木板 / 生锈吊机 / 停泊小船
- 叙事定位：人曾经离开的地方——过去热闹，现在没人来了

### 未来链路（对应碎片第四章"新未来"）
```
恢复农业供应 / 岛恢复生机
   ↓
旧船重新靠岸
   ↓
有人回来（过去离开的人）
   ↓
码头重新热闹
   ↓
商路 / 新资源 / 新故事出现
```

### 与碎片系统的连接
码头是"玩家行为让离开的人回来"的直接可视化——**关系恢复的证明**。

---

## 五、储备区扩展（老街 / 温泉 / 封锁山路 / 港口）

全部按"四级递进"（看到 → 听说 → 进入 → 修复）实施，当前**只走前两级**：

| 区域 | 看到（视觉层） | 听说（台词池） | 优先级 |
|---|---|---|---|
| 老街 | 小镇边缘远景 | 老居民一句对白 | 中 |
| 温泉 | 森林深处远景 | NPC 暗示 | 中 |
| 封锁山路 | 矿山附近远景 | 封锁路牌 / 台词 | 低 |
| 港口 | 老航线远景 | 恢复后重新连接外界的对白 | 低 |

> 全部以"远景 + 一句对白"起步，玩家产生"以后我要回来看看"即可；可玩化是**第四阶段**的事。

---

## 六、验收标准

- 玩家第一次进入岛屿后产生："这里以前一定发生过很多事情。"（已完成）
- 玩家产生"这里有个地方我以后要去"（空间扩展成功——不需要它现在可进入）
- 修复灯塔/码头后，玩家能明确感知"我的行为让世界变了"

---

## 七、红线

- ❌ 不扩可玩区域（Alpha 阶段）
- ❌ 不新增 tilemap / 碰撞 / 任务 / 存档字段（仅为实现"看到/听说"时）
- ❌ 不为空间感新增系统
- ✅ 优先：视觉层 + 台词池 + 一句对白 + 环境音
- ✅ 灯塔/码头/老街不写成"答案"，而是"这里曾经有人认真生活过"的证明

> 完成一个闭环 > 添加十个半成品。
