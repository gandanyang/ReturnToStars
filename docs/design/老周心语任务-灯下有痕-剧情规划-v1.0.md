## 〇、制作人拍板记录（2026-08-30，本文 v1.0 的定调来源）

1. **正式定名《灯下有痕》**，弃用暂名《修物的人》。标题气质对齐《春深有信》《旧梦新芽》：
   含蓄克制、生活意象、不把主题说破、不用任务说明式标题；玩家在故事结束后才真正理解标题。
2. **"痕"的四层指向**（后续所有规划/台词/任务卡必须保护这组意象关系，不得围绕"修家具"展开）：
   旧物的岁月痕迹 / 老周与爷爷的手艺痕迹 / 认真生活过的人生痕迹 / 复兴中重新出现的生活痕迹。
3. **"灯下"双承担**：现实层（灯下修木料、修小凳）+ 叙事层（幕三老屋亮灯 = 生活重新回来、有人真正留下）。
4. **核心命题**："人会离开，物会变旧，但曾经认真生活过的人，会在物与生活里留下痕迹。而当旧屋重新亮起灯，
   这些痕迹便重新成为当下生活的一部分。"
5. **定位**：第一章人物生活内容 / 世界复兴注脚——不是独立大型角色支线，不追溯完整人生、不展开家族史。
6. **幕二修复物定为小凳**；交互克制、不建制作系统、不建工艺流程。
7. **第二章边界（硬性）**：老周在第一章展开《灯下有痕》；**第二章仍只作注脚**；不得通过追加老周剧情
   解决第二章内容；与外来者 A 保持主题镜像（老周=留下建设 / A=归来确认）；预埋注脚
   （"你走的时候，这镇上的灯还没这么亮。"）控制在环境/人物注脚量级，不重开支线。
8. **禁做清单**：大段人物自传 / 老周讲大道理 / 强行煽情 / 回忆 CG / 明示主题的总结性台词 /
   独立任务系统、奖励系统或新存档字段。

## 三、主题命题（已拍板）

**核心命题**："人会离开，物会变旧，但曾经认真生活过的人，会在物与生活里留下痕迹。而当旧屋重新亮起灯，这些痕迹便重新成为当下生活的一部分。"（拍板原文，见 §〇.4）

- 标题意象绑定（后续一切产出必须优先保护）："灯" "木" "痕" "留下" "生活重新发生" 五者的关系，
  **不围绕"修家具"本身展开**；标题在故事结束后才被理解。
- 情绪目标：林澈第一次**以手艺人的方式**接过爷爷的东西——不是读信（夏雅线是"信"），不是看星（镇长），而是**手上有木屑**。
- 过滤三问自检：
  1. 强化"岛曾经存在过"？✅ 爷爷与老周当年一起修物的旧事（具体物件承载，不主题演讲）
  2. 强化"玩家正在改变它"？✅ 玩家亲手参与修复，留下永久痕迹（老屋灯亮）
  3. 留下未来期待？✅ 老周"喊我一声"变成真的有活儿一起干（第二章注脚的根）
- 反AI味红线：老周台词必须极简——短句、停顿、动作代替表达（行动型角色：做，不说）。全场老周台词预计 ≤10 句，每句 ≤15 字优先。
- **禁做清单（拍板）**：大段人物自传 / 老周讲大道理 / 强行煽情 / 回忆 CG / 明示主题的总结性台词。

## 四、任务结构（三幕，拍板基线；结构覆盖完整三幕，标题不只服务幕二）

> 复用清单：triggerOnce 一次性范式（含占用守卫+重试+owed 补播——本会话沉淀的演出规范）/
> 采集交换（wood/树枝）/ StoryNotification L3 记忆卡 / NPC 每日台词条件分支注入 / InteractionRouter 注册。
> **零新系统、零新存档字段**（进度用 triggerOnce 事件 ID 承载，同 houseTidy 范式）。

### 解锁锚点（主线时间线上的位置，不早不晚）
`carpenter_returned`（老周已回归）**且** `isRestored('marketSquare')`（集市已开张）。
——对齐铁律"世界恢复 → 居民关系恢复 → 个人故事展开"（夏雅线同序）。

### 幕一 · 木料（观察，无任务感）
- 老周在老屋旁刨一块旧木料（日常 idle 注脚台词，条件分支注入日池）。
- 方向示意（未定稿）：老周：`……这块料，是老林的。`（说完继续刨，不解释）
- 玩家交互一次（按 E），老周不交任务、不发委托——只是让玩家**看见**。

### 幕二 · 修复（动手，一次交互完成，不做清单感）
- 老屋工作台交互点：老周在修**小凳**（拍板定物），缺一块合适的料。
- 玩家交 `wood ×3`（现有素材，与"树枝→小木鸟"同语义：木头=心意）。
- 幕二完成触发 `triggerOnce('ch1_laozhou_xinyu_work')`：演出极短（2-3 句+刨木声），**不煽情**。
  - 方向示意（未定稿）：老周：`（把修好的小凳放回原处，看了很久）……手艺没丢。`

### 幕三 · 灯亮（世界回响，D-012 落地）
完成 → 两个"不解释"的世界变化（**正是挂起项 S4 的落地**）：
1. **老屋灯亮**：当夜起老屋窗户常亮暖光（复用 ArtShow/春日集的 FX 范式，`markRestored` 同族持久化）。
2. **老周的半句话变化**：日池条件分支注入一句——方向示意（未定稿）：老周：`灯修好了。夜里路过，看一眼。`
3. **StoryNotification L3 记忆卡**（复用既有组件，对齐反馈层级 v1.0）："那张凳子修好了。爷爷的刨子，挂回了墙上。"

> 幕三即本任务的"心语回响"：不设完成面板、不发奖励台词——玩家在之后的夜里路过老屋，看见灯亮着。

## 五、与第二章的衔接（本规划给拍板的额外价值）

- 老周心语完成后，第二章 A（老木匠）登场时，老周可有一条**条件分支注脚**（方向示意，未定稿）：
  老周：`（对 A）……你走的时候，这镇上的灯还没这么亮。`
