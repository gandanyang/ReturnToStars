# 种植玩法四阶段优化 v0.1（2026-08-15）

> 状态：✅ 已实现（探针 37/37 + first-crop 12/12 绿）｜范围：不新增复杂农业系统，只用现有资产/字段

---

## 一、目标

让三种作物从"等待收获的资源"变成"有生命成长的植物"：

- 增加作物成长阶段表现：**播种 → 幼苗 → 成长 → 成熟**，不同阶段有视觉变化
- 强化作物差异（萝卜快 / 番茄藤蔓等待 / 玉米长周期 / 草莓稀有治愈）
- 增加收获反馈：动画、音效、文字描述，收获有仪式感
- 增加轻量照料反馈（无肥料/品质/数值养成）
- 保持核心：种植不是赚钱工具，是让土地重新恢复生命

---

## 二、实现

### 1. 四阶段视觉（零新素材）

复用现有 `farm_plot`（5 帧）+ `crops`（每作物 3 帧）：

| 阶段 | 地块帧 | 作物帧 |
|---|---|---|
| 播种（种子） | frame 1（播种土，自带种子点） | 隐藏 |
| 幼苗 | frame 2（湿润土） | cropIdx×3+0（发芽） |
| 成长 | frame 3（更湿土） | cropIdx×3+1（生长） |
| 成熟 | frame 4（成熟土） | cropIdx×3+2（成熟，分品种） |

### 2. 阶段节奏差异

- `CropData.grownDays`（可选字段，旧档兼容）：已浇水成长天数
- 阶段推导：`grownDays >= growthDays-1 → 成长；否则幼苗`
- 萝卜(3天) 快：种子→幼苗→成长→成熟全四阶段；番茄(4)/玉米(5)/草莓(6) 幼苗期更长

### 2.5 成熟周期与售价（2026-08-15 制作人定稿）

| 作物 | 周期 | 售价 | 种子价 |
|---|---|---|---|
| 萝卜 | 3 天（原 2） | 45G（原 30） | 10G |
| 番茄 | 4 天（原 3） | 80G（原 55） | 20G |
| 玉米 | 5 天（原 4） | 75G（原 45） | 15G |
| 草莓 | 6 天（原 5） | 150G（原 120） | 50G |

周期延长 + 单株售价上调作为补偿；`CROP_DEFS` 与 `Economy` 收购价同步（探针 `probe-sell-all` 19/19）。

### 3. 收获仪式感

- 每次收获：作物图标上浮渐隐动画 + 作物专属描述（"水灵灵的萝卜 / 熟透的番茄 / 饱满的玉米 / 红得发亮的草莓"）
- 首次收获的"情绪瞬间"长镜头保留

### 4. 轻量照料反馈

- 浇水后：水光微闪（ADD 光斑渐隐）+ 作物轻摆（"水浇下去，植物回应了一下"）
