## 一、定位与原则

音乐在《归星物语》里不是"背景装饰"，而是 **80 分瞬间的催化剂**——玩家在青禾镇听到的第一段旋律、观星夜响起的那首曲子，都是"这艘船有温度"的地方。

三条原则：

1. **音乐服务情绪，不抢戏**：旋律是"陪伴感"不是"表演"，任何段落都不比画面/剧情更用力。
2. **低成本优先**：MIDI 作曲数据 → WAV 合成试听 → SoundFont/DAW 重渲染（旋律不重写）。不追求交响级 OST。
3. **移动端体积可控**：每首 ogg ≤3.5MB，加载不卡、LRU 缓存兜底。

## 二、风格方向（正式确认）

**星露谷田园（悠闲民谣）+ 原神抒情（叙事感/五声点缀）**——沿用立项 v0.1，正式立项确认。

| 维度 | 定案 |
|---|---|
| 和弦底色 | G-Em-C-D / C-Am-F-G / Am-F-C-G（温暖、流动、不快不赶） |
| 结构 | 起承转合（ABA），短语-应答，结尾淡出收束 |
| 点缀 | 竖琴/五声音阶（宫商角徵羽）点缀、抒情长乐句 |
| **红线** | **不诡异**——无稀疏、不协和、尖锐音；低音与高音点缀克制 |

## 七、验收标准

1. **听感**：不诡异（无稀疏/刺耳/不协和）；与场景情绪匹配（标题/白天/夜晚/剧情各归其位）。
2. **循环**：正式版需无缝 loop 点（试听版至少"无突兀跳变"）。
3. **全流程走查**：title→农场→小镇→森林→观星夜，无叠播、无中断、音量一致。
4. **探针回归**：probe-music-v1（6/6）+ probe-sfx-v1（5/5）保持全绿；新增缺口曲目后补探针。
5. **移动端**：加载不卡、无内存膨胀（LRU 兜底）。
