> 状态：📋 设计规则（2026-08-15 制作人拍板：B 观星夜呼应为首个实例，确立"心语任务 → 世界回响"体系规则）
> 关联：`任务-夏雅春深有信DemoCut-v1.0.md`（·一实例）、`第一章春深有信-主线与心语任务衔接-v1.0.md`（B 观星夜呼应）、`T_DECISION` D-012（心语任务体系）

## 核心原则

> **心语任务不是"做完给奖励"，而是"改变 NPC 在世界里的状态"。**

玩家完成一个 NPC 的心语任务后，世界不是弹窗给奖励，而是**该 NPC 在某个后续事件/场景里，主动说/做一件"记得你"的事**——一件事、半句话、一个状态变化，让玩家感到"这件事被世界记住了"。

## 反例 / 正例

- ❌ 完成 → 弹奖励（金币/物品/好感数值）
- ❌ 完成 → NPC 再无变化（像一次性消耗品）
- ✅ 完成 → 某事件里该 NPC 主动找玩家说一句话 / 世界出现一处痕迹 / 一处状态变化，且**不解释"这是任务奖励"**

## 尺度（B 观星夜呼应确立）

- **轻**：一件事/半句就够，不写重、不走苦情线。
- **不是感谢拯救**：角色是"看见过去但继续向前"，不是"被你从孤独里救出来"。
- **不解释系统**：玩家应从台词/痕迹自己会意（如"今晚的星星，好像比以前亮了一点。"——她说的不只是星星），NPC 不总结"因为完成了任务"。

## 落地范式（参考 ·一 B 观星夜呼应）

- 在**既有的定稿场景**里注入，不新增完整剧情段。
- 用"条件分支注入"实现，不改动定稿对白数组（观星夜等有"一字不改"红线）——`[...DEMO_ENDING_DIALOGUE]` 副本 + `if(条件) splice` 注入。
