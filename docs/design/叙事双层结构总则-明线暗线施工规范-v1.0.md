# 叙事双层结构总则 v1.0 —— 明线/暗线施工规范（制作人总则落档）

> 性质：**门禁级叙事施工规范**（制作人 2026-09-01 总则，本文为其可检索落档）。
> 一句话原则：**明线推动玩家往前走，暗线重新解释玩家已经走过的路。**
> 适用：此后所有章节/剧情/事件的设计与施工。AI 做每个剧情节点前必须回答三问：
> ① 玩家当下"看懂了什么"？② 玩家暂时"没看懂什么"？③ 后面的什么东西会重新解释它？
> 建议注册 AI_GUARDRAIL 第 16 条（编号由制作人确认）。

---

## 一、总规则：一件事，两层意义

每个重要剧情节点都写成两层：

| 节点 | 明线：玩家当下理解 | 暗线：玩家当下不必理解 |
|---|---|---|
| 灯塔亮起 | 灯塔恢复使用 | 有人早就在等"回来的人" |
| 玻璃被擦 | 有人在维护灯塔 | 这里一直有人在照料 |
| 夏雅回来 | 熟人重新回来生活 | "回来"不是林澈一个人的选择 |
| 老周修旧物 | 修东西 | 老一代留下的生活正在续上 |
| 旅人拍照 | 记录小镇 | 有人在把"岛存在过"传给外面 |
| 爷爷日志 | 过去的航海记录 | 他留下的是给未来回来者的路 |
| 林澈结局 | 留岛 / 返城 / 连接 | "归位"不是地点，而是关系 |

**硬约束**：不新增"大秘密"（爷爷的巨大秘密/神秘组织——禁止）；只做"信息重解释"：
同一个事实，第一次理解 A，后面理解 B。

---

## 二、四条暗线（不要只设一条神秘主线）

| 暗线 | 串联 | 明线 | 暗线 | 施工方式 |
|---|---|---|---|---|
| **A 回来的人** | 夏雅→老船长→旅人→林澈 | NPC 一个个回来 | "回来"不是偶然，是核心主题 | 每人一个不同版本的"回来"细节：夏雅回来住／老船长回来修船／旅人回来记录／林澈决定怎么回来。**不统一讲主题** |
| **B 留下来的东西**（最推荐） | 老周→爷爷→日志→灯塔→玩家 | 修东西/读日志/看灯塔 | 人走以后，东西替人留下 | 小木鸟（老周）／旧信（夏雅）／旧日志（爷爷）／旧灯（灯塔）／玩家自己写的日志（林澈）。几乎零新系统 |
| **C 灯塔真正照的不是海** | 灯塔→船→人 | 只允许"给归航的船引路"的理解 | 灯→人→归来 | 前期只出现"船"的理解；铭牌句"不是写给船的"即本暗线的首次重解释 |
| **D 林澈其实已经在留下** | 作物→帮助镇子→日志→结局 | 第五幕才开始决定留不留 | 他早就在留下了 | 留岛=留下身体／返城=带着记忆离开／桥=留下东西保持连接。三结局是**三种归位方式**，不是 A/B/C 选项 |

## 三、信息等级（防剧透硬规则）

| 等级 | 定义 | 例 |
|---|---|---|
| L0 | 玩家看到，但不知道重要性 | 灯塔玻璃被擦过 |
| L1 | 觉得有点意思 | 谁每天来擦？ |
| L2 | 开始形成猜测 | 这里一直有人守着 |
| L3 | 部分确认 | 爷爷以前也这么做 |
| L4 | 重新解释 | 灯不是给某一艘船，而是给所有回来的人 |

**禁止**：第一幕直接给 L4。每条暗线至少出现 3 次：第一次=生活细节，第二次=轻微异常，第三次=新解释。

## 七、最高纪律

1. **暗线不依赖"玩家必须发现"**——所有玩家都看到全部内容；第二层意义可以晚一点才浮上来。
2. **不新增谜团**（谜团预算已满）；只做重解释。
3. **不搞 NarrativeManager 2.0**——triggerOnce + StorySequenceRunner + EventPlan + 日池 + 记忆卡已够；本文档即"系统"。
4. E1（来船=B 的船）与 C1（不是预言，是相信）为制作人拍板红线，任何后续内容不得推翻。
