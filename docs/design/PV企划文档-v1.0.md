## 一、PV 定位与目标

PV 不是"功能展示片"，是**30 秒的情绪邀请**——让陌生玩家在商店页停留时感到：

> "这里有一个地方，我想回去看看。"

对齐 TapTap 专项 §二 目标：浏览 10 秒内理解 ①这是什么游戏 ②为什么值得玩 ③和别的种田/像素游戏有什么区别。

**定位一句话**（复用上架文案定稿）：
> 一个被 AI 时代推着前进的年轻程序员，回到爷爷留下的荒废小岛，种田、修复、陪伴这里的人，让归星岛重新迎来星光。

---

## 二、PV 叙事结构（分镜表 v1.0）

节奏：**离开 → 回归 → 生活 → 星光 → 收束**（情绪曲线：低 → 缓升 → 平 → 高潮 → 余韵）

| 时段 | 段落 | 画面（实机为主） | 字幕 | 配乐（title_main） |
|---|---|---|---|---|
| 0-5s | 城市与离开 | 车站/背影/手提箱（实机序章或 AI 补绘） | "如果有一天，你最擅长的事情不再被需要……" | 前奏（安静） |
| 5-15s | 回归 | 火车/海风/荒岛老屋（实机：到站→老屋） | "他回到了爷爷留下的小岛。" | 主旋律进入 |
| 15-30s | 生活与修复 | 种田蒙太奇（锄地→播种→浇水→收获）｜小镇 NPC 招呼｜修复点变化 | —（不压字，让画面说话） | 中段（轻快） |
| 30-45s | 陪伴与探索 | 森林/后山老树｜夏雅对话｜春深有信 | "这里还有人，在等他回来。" | 抒情段 |
| 45-55s | 星光 | 观星夜：星空+人物+小镇灯光（**氛围画面，不展示演出过程细节**） | "归星岛，重新迎来了星光。" | 高潮段（stargaze_final 可做情绪叠加） |
| 55-60s | 收束 | 黑场 → Logo | "《归星物语》｜ 等你回来。" | 尾音淡出 |

**剧透红线**：观星演出是 Demo 核心高潮——PV 只展示"星空 + 人物 + 灯光"的**氛围画面**，不展示碎片幻影、星空轨迹等演出过程，保留首次游玩冲击力。

## 四、制作管线

```
① 分镜定稿（本档 §二）→ ② 录屏脚本（探针驱动各点位，固定视口 1024×768→16:9）
→ ③ 实机录屏（BGM 按需入轨：MusicSystem BGM_MUTED 开关可临时控制录制干净度）
→ ④ 素材整理（marketing/trailer/ 目录）→ ⑤ 剪辑（段落按 §二 时间轴）
→ ⑥ 字幕（对齐 tap 文案定稿）+ ⑦ 配乐（title_main 剪裁，必要时 stargaze_final 情绪叠加）
→ ⑧ 输出规格（1080p / 16:9 / H.264 mp4 / 30fps / ≤60s / 单文件 ≤30MB）
→ ⑨ 验收（§五）→ 上架
```

> 音乐交付遵循语音试听流程：PV 配乐定稿前，先给制作人试听音频版本。

## 五、验收标准

1. **10 秒抓人**：前 5s 字幕钩子成立，陌生玩家愿意看下去。
2. **情绪曲线**：离开→回归→生活→星光，起承转合成立，不拖沓。
3. **玩法可见**：种田/修复/NPC 互动真实可见（实机画面，非纯氛围）。
4. **差异化**：看完能答"不是普通种田游戏"——是"回乡让一个地方活起来"。
5. **无剧透**：观星演出过程细节不出现在 PV。
6. **规格**：1080p / 16:9 / H.264 / ≤60s / ≤30MB，手机端播放流畅。
