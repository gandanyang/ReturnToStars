# 《归星物语》人生连接系统（关系深化 v0.2）

> 状态：📋 深化提案（承接 v0.1 定稿方向，**制作人未拍板，仅归档**）
> 承接：docs/design/NPC好感系统规划-v0.1.md（2026-08-04 定稿：关系记录系统，非好感度）
> 归档：Codex 2026-08-08（来源：制作人/GPT 讨论）
> 一句话：**不设计"恋爱路线系统"，设计「人生连接系统」**——每个角色不是提供恋爱对象，而是提供一种人与人连接的可能。

---

## 〇、为什么需要 v0.2

v0.1 已确立"关系记录系统"方向（不做养角色、不显示数值、奖励=记忆）。但若未来多个角色都有感情线，仍可能滑向"恋爱模拟器的攻略列表"。

追问：**如果《归星物语》未来有很多角色都有感情线，怎么避免变成"攻略列表"？**

v0.2 的回答：不设置排他性攻略，改为**每个角色让林澈成为不同的自己**。

---

## 一、重新定义感情线

不要：

> 夏雅恋爱线 / 神秘女性恋爱线 / 花匠恋爱线

这种命名会让团队陷入"谁是女主 / 谁更重要 / 玩家选谁"。

改成：

| 角色 | 主题命名 |
|---|---|
| 夏雅篇 | 归处主题 |
| 神秘女性篇 | 心动主题 |
| 花匠篇 | 理解主题 |

> 每个角色不是提供一个恋爱对象，而是提供一种人与人连接的可能。

---

## 二、三层情感结构

### 第一层：羁绊（所有角色都有）

基础连接："我认识这个人。"

- 林澈帮助夏雅整理花种
- 帮助花匠修复花园
- 陪阿风修船

### 第二层：专属关系（部分角色有）

这里进入深度。

| 角色 | 关键词 | 事件 | 玩家感受 |
|---|---|---|---|
| 夏雅 | 「陪伴」 | 一起恢复春祭 / 一起照顾老花圃 | "这个人懂我的疲惫。" |
| 神秘女性 | 「心动」 | 一起冒险 / 一起探索碎片 / 一起做冲动的决定 | "这个人让我重新活起来。" |
| 花匠 | 「灵魂共鸣」 | 一起看花开 / 讨论生命 / 讨论孤独 | "这个人理解我没有说出口的东西。" |

### 第三层：恋爱可能性（非常克制）

- 不是所有角色都有
- 甚至不要明确
- 只留下："如果继续走下去，也许会成为某种关系。"

这样作品气质会高级很多。

---

## 三、多角色共存原则（非排他性）

传统恋爱游戏：A 线结束 → B 线重开，互相不存在。

《归星物语》：**所有关系发生在同一个世界，但每个人看到林澈不同的一面。**

| 角色 | 她知道的林澈 |
|---|---|
| 夏雅 | 林澈小时候的故乡 |
| 神秘女性 | 林澈隐藏的野心 |
| 花匠 | 林澈内心的孤独 |

她们不是竞争，因为她们喜欢的是**不同层面的林澈**。

---

## 四、神秘女性定位

- 主题：「让林澈重新心动的人」——不是"最适合结婚的人"
- 与星之碎片绑定：不是因为她知道秘密，而是**她曾经因为碎片看到过一个可能性**——一个没有逃避梦想的自己，她一直追寻那个瞬间
- 为什么吸引林澈：林澈现在最大的问题不是孤独，而是**已经不相信自己还能改变什么**
  - 夏雅告诉他："你可以停下来。"
  - 神秘女性告诉他："你还可以重新开始。"

---

## 五、花匠定位（Soulmate 线）

- 不要成为"第三个恋爱竞争者"
- 她是 **Soulmate 线**——甚至可以不是男女爱情
- 一种"如果世界只剩两个人，你知道对方会理解你"的关系

示例对白：

> 林澈："我以前一直觉得自己不够好。"
> 花匠："可是花不会因为开得慢，就觉得自己失败。"

---

## 六、系统落地：关系等级（替代"好感度"）

以后 NPC 关系不叫"好感度"，叫**关系等级**，每角色专属命名：

### 夏雅（归处）

```
Lv1 认识 → Lv2 熟悉 → Lv3 信任 → Lv4 约定 → Lv5 归处
```

### 神秘女性（选择）

```
Lv1 相遇 → Lv2 好奇 → Lv3 同行 → Lv4 共鸣 → Lv5 选择
```

### 花匠（灵魂相伴）

```
Lv1 交流 → Lv2 理解 → Lv3 默契 → Lv4 知己 → Lv5 灵魂相伴
```

这样玩家不会觉得"我要刷谁"，而是"我和不同的人形成不同关系"。

---

## 七、最关键的一条规则（写入剧情规范）

> **任何角色的情感价值，不来自"她比别人更爱林澈"，而来自"她让林澈成为不同的自己"。**

这条规则可以解决 80% 的多角色管理问题。

---

## 八、最终结构

| 角色 | 关系类型 | 作用 |
|---|---|---|
| 夏雅 | 归处型 | 让林澈重新拥有根 |
| 神秘女性 | 热烈型 | 让林澈重新拥有火 |
| 花匠 | 灵魂型 | 让林澈被理解 |
| 阿风 | 友情型 | 让林澈看到远方 |

这不是后宫，这是一个关于"人在不同关系里找到自己"的作品。

> 《归星物语》本来就不是"追女孩"，而是"一个人重新连接世界"。感情线应该服务这个主题。

---

## 九、与现有系统的关系

- **不新建系统**：v0.1 的关系记录数据结构（affinity 内部值 / stage / memories）不变
- **命名升级**：展示层用角色专属阶段名，替代通用 0~3 阶段
- **实现挂起**：关系系统整体仍冻结（T2-T4 期间 + 存量消化期），本提案仅归档
- **需制作人拍板**：若采纳，更新 v0.1 阶段表与《剧情规范》关系红线
