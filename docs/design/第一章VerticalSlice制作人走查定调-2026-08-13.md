## 五、P0：制作人真人 Vertical Slice 走查

**不是探针 / 不是 Agent / 不是自动化** —— 制作人亲自以「第一次玩这个版本」的玩家身份走一遍。

主线链：
```
观星夜 → 第一声回应 → 镇长介绍 → 老屋整理 → 镇长来访 → 集市恢复 → 春日集
```
穿插：捉虫 → 昆虫观察 → 夏雅·一 → 旧日留影

**只需回答三个问题**：
1. **① 我什么时候开始觉得「这里正在恢复」？** —— 若到集市才第一次明显感到「哦，真的在变」，前面的反馈就有问题。
2. **② 我有没有主动想去做下一个事情？** —— 不是「任务告诉我去哪」，而是「看到那个东西后就自己想过去看」。这是「生活游戏」与「任务模拟器」的分水岭。
3. **③ 三个轻玩法有没有真正产生差异？** —— 不能变成「捉虫小游戏→集市小游戏→观察小游戏」排队；应是「我发现岛上还有自然 → 我开始参与这里的人们生活 → 我开始理解这里为什么值得留下」。

## 六、集市 = 第一章核心体验锚点

集市「重新开张」同时具备：玩家行动 · 空间变化 · NPC 变化 · 生活恢复 · 集体事件 · 后续期待。它不只是小游戏，而是验证整个第一章核心设计「**我做了一件事 → 这个地方真的发生了变化**」。

目标：把集市做到「**这是我第一次真正觉得这个岛活过来了**」，比加十个系统更有价值。


最大变化：从「做完一个功能 → 再做下一个功能」改为「**做出一段完整体验 → 玩 → 找问题 → 修 → 再扩**」。

## 八、乐观判断

已跨过「有没有东西可玩」的危险阶段。现有：种田 / 探索 / 老屋整理 / NPC 事件 / 集市恢复 / 捉虫 / 昆虫观察 / 春日集 / 夏雅线，以及足够多的音乐、语音、环境反馈。

现在真正的问题变成：**「这些东西放在一起，是不是一个完整、舒服、有记忆点的游戏？」**
这个问题 AI 可以分析，但最终答案只能由制作人玩出来。
