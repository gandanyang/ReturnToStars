## 一、核心结构（纵向空间叙事）

```
北部老街（y2-5，破损屋 ×2）
  ↓
集市广场（y2-7，x18-32，gid6 石板）
  ↓
中央镇区（原有：四民居+竖路+横路）
  ↓
居民区（原有：NPC 站位+需求板+售货机）
  ↓
宅基地（y29-33，三面残垣，待叙事启用）
```

制作人评价：**"玩家走路本身就在理解'这里以前是什么地方'"**——空间叙事替代功能堆叠。

## 二、设计决策记录

| 区域 | 决策 | 理由（制作人拍板/认可） |
|---|---|---|
| 老街 | 放北侧，破损（屋顶缺角/墙面裂口） | 复兴最怕"第一眼是新的"——先破旧，后修复，才是复兴 |
| 集市 | y2-7 / x18-32，靠近北部入口 | 连接竖路、不碰 NPC 区、赶大集有扩散空间（中心摊位→闲聊→边缘经过的三层结构） |
| 宅基地 | 南侧，**只做残垣，不做内容** | 给未来角色（尤其夏雅：小花园/旧物小屋/记忆角落）留空间 |
| 河边 | 西侧 x0-4 gid4 水 + 岸线 | 低成本高收益的治愈感；"什么都不做也舒服的位置"（同尘歌壶/星露谷逻辑） |
| 道路 | 竖路 col24-25 贯通 y0-34；横路 y17-18 x5-44 | 四区由道路骨架串连，入口有引导 |

## 三、Phase 2 建议（制作人 2026-08-13，记录不改）

### 建议 1：集市留一个"空角"
赶大集版本不要把整个广场填满，留一个空位置（人停下来聊天的地方）：

```
摊位 摊位 摊位
      空地
摊位       老树
```

理由：真实集市不是商业展厅，需要"人停下来说话"的空间。

### 建议 2：宅基地不要过早解释
不要马上给"这里未来可以建 XX"。让玩家看到一片荒地，某一天 NPC 说"这里以前也是一户人家"——**让玩家自己产生想象**。

## 四、验证标准（制作人 2026-08-13 拍板）

**玩家第一次进入新 town 时，5 秒内能不能理解：这里曾经有人生活，但现在正在慢慢回来。**

- 若成立 → 第一章空间基础稳固，后续集市/夏雅/NPC 日常都轻松
- 验证方式：探针模拟 farm→town 首见视角，检查视野内"曾有人生活"（破损屋/残垣/民居）与"正在回来"（石板广场/路灯/修复痕迹）两类信号
- 结论：见 `probe-ch1-town-first-impression` 结果
