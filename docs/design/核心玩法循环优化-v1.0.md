## 文档目的

当前项目已经具备：

- 农田种植
- 钓鱼系统
- NPC交换
- 城镇复兴
- 图鉴收藏
- 探索地图
- 剧情事件
- 时间系统

当前主要问题：

> 游戏内容丰富度已经达到一定程度，但玩家行为之间缺少强关联，导致部分玩法像独立功能，而不是一个完整的生活循环。

本轮目标：

不是增加大量新系统。

不是复制星露谷式玩法。

目标：

**建立《归星物语》独有的核心游戏循环，让玩家因为"想让小镇变好"而主动探索、收集、交流和行动。**

---

## 一、核心定位重新确认

《归星物语》不是：

- 农业模拟器
- 资源刷取游戏
- 数值成长游戏
- 收集肝度游戏

核心体验：

> 回到故乡，通过日常生活一点点恢复人与土地之间的联系，让一个沉寂的小镇重新拥有生命。

## 附：核心循环草案（Codex 补完，2026-08-15）

### 循环图

```
        ┌──────────────────────────────────────────────┐
        ▼                                              │
  ① 探索发现（采集 / 钓鱼 / 捕虫 / 收获 / 捡拾）       │
        │                                              │
        ▼                                              │
  ② 带回青禾镇（"我手里有一种东西"）                  │
        │                                              │
        ▼                                              │
  ③ 让东西流动（卖 / 换 / 送 / 用）                   │
        │                                              │
        ▼                                              │
  ④ 世界变化（灯亮 / 长椅 / 饭桌 / 门轴 / 人回来）    │
        │                                              │
        ▼                                              │
  ⑤ 镇子被记住（图鉴 / 相簿 / 居民记住我）            │
        │                                              │
        ▼                                              │
  ⑥ "我想让这里更好"（情感驱动 → 继续探索行动）──────┘
```

### 循环的五个支柱

1. **驱动 = 情感，不是数值**：玩家行动的动机是"想让小镇变好"，不是金币/等级/进度条。
2. **资源 = 连接媒介，不是商品**：探索获得的东西是"可流动的生活资源"，价值在流向（卖/换/送/用），不在售价。
3. **反馈 = 世界变化，不是奖励**：每个行为产生可见的生活痕迹（灯亮、长椅、饭桌、门轴、夜灯），不是弹窗奖励。
4. **留存 = 被记住，不是背包数字**：图鉴、相簿、居民评价让玩家感到"镇子记住了我"。
5. **扩展 = 复苏引来新人，不是地图扩张**：循环第五步"新的人回来"就是第二章《故人远来》——核心循环与章节叙事同构。

### 与现有系统的挂接

| 玩法 | 进入循环的路径 | 现状 |
|---|---|---|
| 农田 | 收获 → 卖/送/用（复兴交付） | ✅ 已闭环 |
| 钓鱼 | 鱼 → 卖/换/送（四流向已实现） | ✅ 已闭环 |
| 捕虫 | 标本 → 图鉴墙（被记住） | ✅ 已闭环 |
| 交换 | 鱼/物 → 世界变化（饭桌/热汤/门轴/夜灯） | ✅ 已闭环 |
| 复兴 | 交付 → 灯亮/集市/人回来 | ✅ 已闭环 |
| 采集 | 5 种自然物（蒲公英/野莓/野蘑菇/小野花/树枝）→ 送/用网络 + 世界小变化 | ✅ 已闭环（2026-08-15：野莓→小梅野莓篮 / 野蘑菇→老张晾蘑菇串 / 小野花→夏雅窗台花 / 蒲公英→阿风河岸蒲公英丛 / 树枝→老周老屋小木鸟；每样 ≥1 一对一单跳交换，复用钓鱼「可流动资源」模板，零新系统） |

### 检查标准（每个玩法/新内容自测）

1. 这个玩法获得的东西，能不能"流动"到镇子里？
2. 它让小镇发生了什么**可见**变化？
3. 有没有人被它打动 / 记住它？
4. 它是否给了玩家"再出去看看"的理由？

> 答不上 = 它可能只是功能，不是生活循环的一部分。
