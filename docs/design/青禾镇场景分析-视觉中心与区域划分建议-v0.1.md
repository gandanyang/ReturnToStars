## 三、视觉中心分析：不明确

**结论：当前青禾镇没有明确的视觉中心。** 证据：

1. **几何中心 ≠ 视觉中心**：几何中心（交叉口 x24-25, y17-18）地面统计 = 路 40 格、草 33 格、石板仅 4 格——是一条十字路穿草地，不是"广场"。
2. **视觉重点与生活重点错位**：全图最重的视觉质量在北石板（30×8），但它是空的（A 侧 0 建筑、集市区 0 装饰）；生活发生在中部草地上。
3. **四民居严格对称**：左右各两栋，注意力被平均分配，无主次锚点。
4. **最有故事的两点不在动线交汇处**：老街区 B 街屋、S4 残垣都不在十字路口，起不到中心作用。

**对体验的影响**：玩家进镇后无法一眼认出"这是镇心"；「三镜叙事」第一镜（S4 爷爷旧宅遗址）成立，但第三镜「中央广场=现在的人」在空间上不成立——中央广场并不存在，NPC 站在路上。

## 五、制作人评审结论与阶段化决策（2026-08-14）

### 5.1 评审结论（制作人原话要点）

1. **核心判断成立**：问题不是"美术不好看"，而是地图作为舞台没有形成空间叙事；与真人试玩反馈（"素材乱堆、不漂亮"）对应——玩家不知道哪里该看、哪里该停、哪里代表这个镇子。
2. **中央广场是质变**：NPC 从"堵在路上"变成"站在镇中心"；同时为春日集 / 小吃摊 / NPC 活动 / 夜晚灯光预留容器——否则加小游戏只是往空地上塞东西。
3. **不追求对称**：主题是"正在恢复的小镇"；北边老街"左边残破、右边有屋"本身就是叙事（过去的痕迹）。星露谷也不是对称地图，不完整更像真实。
4. **反对全量重构**：一次大改 town.json 会同时牵动 NPC 坐标 / 出口 / Phase3 挂载 / 集市运行时覆盖，容易"看起来漂亮但玩法断了"。先看 P0 效果再继续。
5. **记忆点优先于瓦片**：一棵大树 > 10 个小装饰；当前地图最缺"我为什么记住这里"。

### 5.2 采纳 / 暂缓清单

| 原方案项 | 制作人决策 |
|---|---|
| 中央广场石板化（x20-29, y15-20） | ✅ **采纳 = P0（唯一必做）** |
| 老街区 A 补对称屋影 | ❌ 不采纳（不对称 = 叙事） |
| 北石板隔离带 / 顶边收边 | ⏸ 并入 P3 再议 |
| 东农田田埂化 | ⏸ P3 再议 |
| S1 镇门疏散 | ⏸ P3 再议 |
| 河岸补树 | ✅ 采纳方向，升级为 P1「河岸散步路线」 |
| 过渡林带 | ⏸ 视 P0 效果后再定 |
| 留白（空角） | ✅ 维持 |

## 六、区域划分方案（纯瓦片布局，零新素材，全案保留）

### 6.1 总原则

1. 分区只用 **Ground 层（gid1/2/6/7，无碰撞）** 表达；碰撞瓦片（树/屋/井/栅栏）只沿**不通行边界**放置。
2. **gid 语义、碰撞编号、tileset 引用零改动**；出口 / NPC / 商店坐标不动；存档无影响。
3. 沿用已拍板 8 舞台块 + 南北轴（北=记忆、中=生活、南=行动）。
4. 遵守 Phase3「每块一个记忆点，不堆砌装饰」与「空角留白」原则。

### 6.3 逐条调整（坐标级）

1. ✅ **中央广场石板化（建立视觉中心）——P0 采纳（制作人拍板）**
   - x20-29, y15-20 铺 gid6 石板；竖路 col24-25 保留 gid7 穿心。
   - x20 / x29 两端各留 gid7 接口连横路；四民居门口各引一条 gid7 短支路接入。
   - 效果：交叉口从"十字路"变"石板广场 + 十字路"，成为全图唯一规则几何中心；7 个 NPC 站上广场。

2. ⏸ **北石板三块化——暂缓（制作人：不对称是叙事；A 侧对称屋影不采纳）**
   - x18-19 与 x28-29 两列（y0-7）改 gid1 草地作隔离带。
   - 老街区 A：x12-17, y2-4 用现有 gid9/gid10 拼一栋与 B 侧对称的残破屋影（只做屋顶+墙剪影，不做门/窗，保持衰败感）。
   - 集市区：y7 南沿改一行 gid2 荒地过渡（接运行时荒土）；y0-1 顶边改 gid1 收边。
   - ⚠️ 碰撞影响：A 侧补屋使该处北两行不可通行，动线改走屋前 y5-6 石板。

3. ⏸ **东农田田埂化（P3 再议）**
   - rows 14-16 / 20-26 的整行石板横带改为「1 行田埂 + 3 行荒地」垄结构：y14 埂 + y15-17 地；y20 埂 + y21-23 地；y25 埂 + y26-27 地。
   - gid8 杂草只留 3-4 处田埂交叉点；x40 / x49 两侧保留 gid1 草边。

4. ⏸ **S1 门区疏散（P3 再议）**
   - 木牌 → (20,26)；路灯基座 → (23,27)；井留在 (22,28)；栅栏 (25,28) 保持；件与件间隔 1-2 格。
   - x24-25 门位保持净空。

5. ✅ **河岸韵律（采纳方向，升级为 P1 散步路线）**
   - x5 列隔 2-3 行补 gid16 树（建议 y8/y12/y20/y23/y26，**避开长椅 (5,15)、夜灯 (5,11)、横路 y17-18**）。
   - 岸线偶发 3-4 处 gid8 花丛；不堵横路出口。

6. ⏸ **过渡林带（视 P0 效果后再定）**
   - y8-11 保持草地；在 x6 / x12 / x19 / x30 / x42 竖列间隔补 6-8 棵 gid16 树，把北石板"帧"起来。
   - 具体树位以**不压建筑、不堵路**为准。

7. ✅ **留白（维持）**
   - x40-49, y32-34 与 x0-4, y29-34 保持空地不加内容（守住"空角"原则）。

### 9.1 硬约束

- 只改 `public/assets/maps/town.json` 的 Ground / Walls 瓦片数据；**P0 阶段仅允许 Ground 层**（Walls / 代码 / 素材零改动）。

- 存档无影响（地图瓦片与 SaveData 无耦合）。

### 9.2 运行时覆盖提示

- 集市解锁后运行时 `putTileAt(gid2, cols 18-32, rows 2-7)` 会覆盖该矩形内的静态地面。
- 因此集市分界主要做在**不被覆盖的区域**（y0-1 顶边、y7-8 下沿），两态表现需接受：未解锁 = 草带分界可见；开张后 = 荒土矩形覆盖。
