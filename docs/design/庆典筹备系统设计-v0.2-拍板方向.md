## 〇、系统定位

解决核心短板：**长期目标感**。

玩家从：

> "钓鱼挺有趣，我去钓一下。"

变成：

> "还有 15 天艺术展，我得帮夏雅把广场布置好。"

核心不是"举办活动赚钱"，而是：

> **让小镇重新被世界看见。**

---

## 一、核心循环（制作人拍板）

```
解锁大型活动
  ↓
选择未来目标
  ↓
小镇进入准备期
  ↓
玩家投入资源/行动
  ↓
居民参与建设
  ↓
活动当天发生变化
  ↓
小镇永久留下影响
```

**关键**：活动不是一次性消耗品——它改变城镇状态（永久影响）。

---

## 二、解锁（第一阶段）

春日大集成功举办后，居民发现：

> "原来青禾镇还能重新热闹起来。"

于是出现：

> "我们是不是可以尝试举办更大的活动？"

解锁菜单「复兴企划」：玩家可以查看未来活动。

---

## 三、活动示例（四个方向）

### ① 星光艺术展（文化复兴）

- 准备：收集野花 / 修缮旧展馆 / 装饰广场 / 提供食材
- 当天：NPC 增加 / 作品展示 / 特殊剧情 / 夜晚灯光
- 长期影响：广场增加艺术装饰

### ② 青禾村超（乡村活力）

- 准备：修整球场 / 招募队员 / 制作应援物 / 准备食物
- 当天：不做复杂体育游戏——QTE 小游戏 / 点击互动 / 观众反馈 / "直播镜头"（叙事性）
- 长期影响：年轻居民增加

### ③ 星辰观测夜（世界观契合）

- 准备：修复观星台 / 收集望远镜零件 / 准备饮品
- 当天：观星活动
- 长期影响：解锁新的夜晚场景

### ④ 丰收祭（农业方向）

- 准备：农作物 / 食材 / 装饰
- 当天：居民展示成果

## 四、三类准备（防肝度核心）

不要让玩家觉得"我要肝材料"——准备阶段不能只是"收集 100 木头"：

### ① 环境建设

玩家直接改变场景（例如装饰广场 / 修缮展台）。

### ② 人际动员

和居民互动（例如邀请夏雅帮忙布置）——居民参与建设。

### ③ 资源准备

提供物资（花 / 鱼 / 农产品）。

---

## 五、青禾镇人气（暂名）

类似开罗的发展指标，**不叫等级**，叫"青禾镇人气"。

随：活动成功 / 居民参与 / 环境改善 提升。

效果：解锁更多活动 / 更多访客 / 更多商店内容。

## 八、垂直切片（先做「星光艺术展」）

原因：

- 最符合《归星物语》气质
- 不需要复杂玩法

- 可以展示美术升级成果

## 九、Codex 评审调整建议（待制作人确认）

### 1. 人气的驱动方式：解锁由"生活事件"触发，人气只做显示

如果人气是"数值涨到 X → 解锁 Y"，就会变成可刷的成长条。建议：**解锁由"完成了哪些生活事件"决定**（活动办成、居民归来、环境改善），人气只是这些事件的**回声显示**——玩家看到 42% 是"镇子被记住了多少"，而不是"还差 58% 的活儿"。

### 2. 准备事项清单：是"镇子正在准备什么"，不是"玩家待办"

清单逐项应显示**世界状态**（展台已修缮、鲜花已备好、夏雅答应帮忙），而不是"去收集 X"。玩家从清单里看到的是"镇子在为它准备"，不是"我还有多少任务"。这决定它和已回滚的 QuestPanel 是两种东西。

### 3. 直播镜头：叙事性表现

"直播"表现为"外面的人在看"（旁白 / 信件 / 新来的人），不做真实联网——符合禁止引入后端红线，也更贴治愈气质。

### 4. 星辰观测夜复用既有观星资产

观星台 / 观星夜演出已有成熟资产（第 0 章观星夜），星辰观测夜应直接复用其视觉与气氛范式，零新素材。
