## 一、四个固定检查（每个 P3 方案必须逐条通过）

### 检查 1：玩家行为是不是前置，而不是任务目标？

| | 错误 | 正确 |
|---|---|---|
| 写法 | 镇长拜托你修灯塔 | 玩家已经改善岛屿 → 发现以前没人管的地方 → 自己决定处理 |
| 玩家感受 | 在完成居民需求 | 在改变世界 |

> 前置：玩家先有行为，世界后给回应。不是"给任务 → 完成 → 奖励"。

### 检查 2：第一次回应必须"小"

- 灯塔方案的「玻璃没灰」是标准示范——**不是奖励**
- 玩家第一反应可以是："是不是我看错了？"
- 这种小变化，比"灯塔恢复了一丝光芒！"高级很多
- ❌ 第一次回应就大张旗鼓 = 破坏克制的预期

### 检查 3：第二次回应必须有人感受到

归星岛与普通种田游戏的最大区别：

- 普通游戏：玩家修 → 数值变化
- 归星岛：玩家修 → **别人的生活变化**

灯塔完整闭环示范：

```
第一阶段（环境）：灯塔玻璃干净了
第二阶段（人）：  镇长："以前晚上这里没人看。现在倒有人往这边走了。"
第三阶段（世界）：远处船灯
```

> 没有"人"感受到的变化，不构成归星岛式回应。

### 检查 4：不允许区域自己宣布意义

- ❌ 灯塔："谢谢你，我终于重新找回意义。"
- ❌ NPC："你让这个岛重新拥有未来。"
- ✅ 永远停留在："哦，原来有人又开始用了。"
- 让玩家自己完成解释（与老周 A1、反 AI 味原则同源）

## 二、区域回应强度分级（防止越级）

| 等级 | 名称 | 表现 | 例子 |
|---|---|---|---|
| **Lv1** | 痕迹 | 玩家怀疑（不是奖励） | 灰少了 / 门打开了 / 灯芯换过了 / 花重新长出来 |
| **Lv2** | 生活 | 别人开始使用 | 有人在附近停留 / NPC 路线变化 / 老物重新进入生活 |
| **Lv3** | 连接 | 世界关系改变 | 船回来 / 商店恢复 / 新旧居民产生联系 |
| **Lv4** | 未来 | 大型变化 | 新航线 / 新产业 / 新区域 |

**规则：**
- 回应必须**逐级递进**（Lv1 → Lv2 → Lv3 → Lv4）
- 一个小修复事件**禁止直接跳 Lv4**
- 每次升级之间有明确的世界回应事件（P2.5 事件库）衔接
- 灯塔示例的对应关系：玻璃没灰 = Lv1 → 镇长台词 = Lv2 → 远处船灯 = Lv3（航线和开放 = Lv4，未来）

---

## 三、与既有原则的衔接

| 本标准 | 对应原则 |
|---|---|
| 检查 1（行为前置） | 新区域 = 玩家行为带来的世界回应（核心叙事原则） |
| 检查 2/3（小回应 + 人感受到） | 分次递进，不做"一次完成"（P2.5 事件库） |
| 检查 4（不宣布意义） | 反 AI 味标准（老周 A1：展示行动，不替玩家解释） |
| 强度分级（Lv1-4） | 制造未来，不制造地图（区域响应是"生活状态"，不是"解锁内容"） |

## 四、P3 方案自检清单（每个方案交付前勾选）

- [ ] ① 玩家行为前置（不是任务目标）
- [ ] ② 第一次回应足够小（玩家可能以为看错了）
- [ ] ③ 第二次回应有人感受到（NPC 生活变化，非数值）
- [ ] ④ 无任何角色宣布意义（反 AI 味通过）
- [ ] ⑤ 回应按 Lv1→Lv4 逐级递进，无越级
- [ ] ⑥ 复用现有机制（triggerOnce / 台词池 / 视觉层 / farmWarm 模式），零新增系统

> 六项全过才算合格的区域生产方案。
