## 一、制作人定稿方向（原稿要点存档，本文档以此为准）

1. **章题**：《归园新序》——"归园"直扣"回到家园安顿"，新序=新生活的序章。
2. **开场不从林澈开始**：先切青禾镇清晨，先听村民声音（议论昨晚的星星），**不解释、不写"碎片拯救小镇"**——玩家知道发生了什么，村民不知道，只感到"小镇好像重新有了一点生气"。
3. **老屋整理 = 第一章第一个玩法**：轻量、无家具系统；床/灯/书桌/小物件是**叙事工具**不是装修；找到爷爷旧物（如旧收音机）→ 触发一段过去的声音。
4. **夏雅线自然接入**：整理柜子发现旧物件 → 去问夏雅 → 她帮整理 → 引出她"保存小镇记忆"的性格。
5. **主线 = 青禾复兴计划**：以"邀请"而非"任务"呈现（村长说"以前这里有很多东西……现在有人愿意回来，也许我们可以试试"）。
6. **第一章结构（制作人定）**：观星夜余波 → 村民重新谈论希望 → 林澈整理老屋真正开始生活 → 认识"留下"的意义 → 青禾复兴计划启动 → 修复第一个公共区域 → 夏雅记忆线推进 → 第一次小镇活动。
7. **人物弧线递进（制作人定）**：第0章回来了 → 第1章住下了 → 第2章融入了 → 第3章守护了。
8. **设计判断（制作人）**：复兴不是从修建筑开始，而是**一个人先重新安顿下来，然后影响周围的人**——比"直接复兴小镇"高级。

---

## 二、Fun Hypothesis（一句话，随 v0.2 更新）

> **一个人先把自己安顿下来，然后他周围的人开始重新相信：这个地方可以活回来。**

v0.1 版本强调"发现自己的用处"；v0.2 按制作人方向改为**"安顿 → 影响"**——先有生活，再有复兴。复兴是生活的副产品，不是任务列表。

---

## 三、Design Pillars（三条不可妥协）

1. **安顿是叙事，不是装修**：床/灯/书桌/小物件的每次选择都推进一步"这里是家"的认知；**零数值影响**（不做家具属性/不做布置评分）。
2. **余波靠生活，不靠播报**：观星夜的秘密通过村民的议论、小镇的灯光、人的走动来传递，NPC 不总结"发生了什么"。
3. **复兴是邀请，不是任务**：村长给的不是任务板，是"要不要一起试试"——玩家接受邀请后，才进入公共区域修复。

## 四、章节定位与人物弧线（制作人四章递进）

| 章 | 制作人定义 | 林澈的状态 | 核心动作 |
|---|---|---|---|
| 第0章《归星》 | 回来了 | 处理遗产 → 试着留下 | 修复庄园（老屋/花园/道路） |
| **第1章《归园新序》** | **住下了** | 试着留下 → 开始生活 | **安顿老屋 → 影响小镇** |

> 四章递进的自然性 = 每章主角与岛的"关系深度"递增，不是内容量递增。

## 五、开场设计（制作人定：从青禾镇清晨开始）

### 5.1 镜头与声音（不是林澈，先听声音）

```
【清晨·青禾镇】
镜头从小镇开始。先听到声音，再看到人。

村民甲："你们昨晚看到了吗？"
村民乙："好多年没有看到那么亮的星星了。"
村民丙："我记得小时候，爷爷还带我去山坡上看过。"
村民丁："自从那以后，好像很久没有这么热闹过了。"
（停顿。有人抬头看了看天。）
```

### 5.2 叙事规则（硬性）

- ❌ 禁止出现："星之碎片拯救了小镇""碎片让岛活过来了"。
- ✅ 村民只知道：昨晚星星特别亮，很久没这么热闹过。
- ✅ 玩家知道：观星夜发生了什么（第0章已体验）。
- 作用：信息差 = 玩家"经历了大事"的叙事地位 + 小镇"重新有生气"的余波感。

### 5.3 接入方式（工程建议）

- **复用村民议论机制**：AmbienceSystem/NPC 气泡或 town 场景一次性背景对白（`triggerOnce('ch1_morning_murmur')`）。
- **触发时机**：观星夜次日清晨，玩家首次进入 town 时。
- **演员**：可复用现有 NPC 站位的台词气泡（老张/小梅/阿风等说"生活话"），或用纯背景音人声 + 字幕。

## 六、第一玩法：老屋整理（归园）

> 制作人判断：这可以是第一章第一个玩法，因为它非常符合"归园"。**家具不是装修，是叙事工具。**

### 6.1 设计原则

- **无家具系统**：不做放置/摆放/自由度。
- **无数值影响**：床/灯/书桌/小物件不改变任何属性。
- **有叙事影响**：每次整理推进"这里是我的家"的认知 + 触发小镇记忆片段。
- 玩家从"被安排的过客"变为"主动安顿的主人"。

### 6.2 整理对象（四个交互点）

| 对象 | 现状描述（玩家看到） | 整理后（玩家获得） | 叙事作用 |
|---|---|---|---|
| **旧床** | "虽然还能用，但睡起来应该不会太舒服。" | "终于像一个可以生活的地方了。" | 家感第一步 |
| **灯** | 昏暗 | "晚上，房间亮起来了。" | 光=有人住 |
| **书桌** | 空/旧 | 放置电脑 | **林澈身份落点**（程序员/现代人/带进旧屋的新生活） |
| **小物件**（花瓶/相框/收音机） | 灰尘/旧 | 摆放整齐 | 家的细节；其中**收音机触发记忆** |

> 电脑上桌 = 关键设计：不是"丢下过去"，而是"把过去的自己带进来重新安顿"（呼应核心矛盾：把过去的自己接回现在）。

### 6.3 记忆触发（收音机）

- 玩家找到**爷爷的旧收音机** → 擦拭 → 旋钮转动 → 播放一段"过去的声音"（爷爷在世时收听的电台/新闻/天气预报的旧录音感）。
- 触发一段**小镇记忆**：收音机曾经是岛上每户人家的"夜晚陪伴"。
- 实现：复用 MemoryFlashback 闪回 + 程序合成/现有音频素材（零新素材优先）。

### 6.4 与现有系统的关系（零新系统）

| 复用 | 现状 |
|---|---|
| house 场景交互物 | 已有音乐盒、爷爷包裹（`MapScene.setupMusicBox`/`setupGrandpaGift`）——交互物范式现成 |
| 可读物件/整理 | 爷爷笔记模式、`tryGardenRestoreInteract` 三阶段清理模式（FarmRestore） |
| 记忆触发 | `MemoryFlashback`（闪回）+ `MemoryMoment`（飘字） |
| 存档 | 每个整理点一次性 → `EventManager.triggerOnce`（如 `ch1_bed_done`/`ch1_lamp_done`/`ch1_desk_done`/`ch1_radio_done`） |
| 状态 | 零新增存档字段风险（一次性事件走现有 triggeredEvents） |

### 6.5 验收标准

- 玩家整理完全部 4 点后，能说出"这间屋子开始是我的了"
- 玩家不觉得这是在"做装修任务"
- 收音机记忆触发自然（不打断、不突兀）
- 电脑上桌不突兀（程序员身份合理落点）

## 七、夏雅线接入（制作人定：整理柜子 → 旧物件 → 问夏雅）

### 7.1 场景

```
林澈整理柜子，翻出一个旧物件（比如老式相框/旧工具/褪色的绸缎）。
不知道该怎么处理。
→ 带着物件去找夏雅。
夏雅："这个啊……以前大家搬家的时候，都舍不得丢。"
（她接过物件，小心擦干净。）
夏雅："镇上有的人走了，东西留下来了。总得有人记得它们。"
```

### 7.2 叙事作用

- 引出**夏雅的性格底色：保存小镇记忆的人**（与第0章"迎接回来的人"衔接，深化）。
- 为第二章/夏雅心语任务（春深有信）埋线。
- 符合夏雅人物圣经（照顾者语言：用行动表达，不宣言）。

### 7.3 工程建议

- 复用夏雅支线范式（`xiya_garden`/`xiya_photo` 一次性触发模式）。
- 触发：整理完柜子（或找到特定旧物件）后，house/farm 找夏雅对话。

## 八、主线：青禾复兴计划（邀请，不是任务）

### 8.1 村长来访（夜晚，林澈整理好的屋子里）

```
窗外能看到青禾镇的灯光。
村长来访（或手机消息）。
村长："以前这里有很多东西。花园、集市、老街……"
"后来大家慢慢离开，也慢慢忘了。"
"现在有人愿意回来——也许，我们可以试试。"
林澈：（没有立刻回答。他看着窗外的镇子。）
```

### 8.2 设计要点

- **不写任务面板式**"主线任务：青禾复兴计划（进行中）"。
- 以"邀请"呈现：村长给的是可能性，不是工作清单。
- 玩家接受邀请 = 主动选择（呼应观星夜三选项的延续）。

### 8.3 第一个公共区域修复

- 建议（待拍板）：**老街/集市广场**（与"花园、集市、老街"对应，且小镇场景现成）。
- 修复模式：复用 FarmRestore（如 `markRestored` 扩展或类似 `oldHouse` 资源交付模式）。
- 修复完成后 = 第一次小镇活动的基础。

## 八·五、第一章三阶段总纲（v1.5 制作人补定：宏观主题收束）

> 2026-08-15 制作人补充：第一章不仅是八步节拍的推进，更是一条**宏观主题递进**。下面三阶段用一句话概括"第一章在讲什么"；第九节"八步"是这张总纲下的子节拍。

| 阶段 | 主题 | 讲什么 | 对应内容/结束点 |
|---|---|---|---|
| **第一阶段** | 「这里还能住人。」 | 老屋恢复——个人安顿 | 老屋整理（床/灯/书桌）+ 爷爷旧物记忆 |
| **第二阶段** | 「这里还能生活。」 | 四大生活循环建立、居民有人情、镇子重新运转 | 采集/钓鱼/种植/城镇复兴闭环（🏁生活循环闭合）＋春日集＝中部聚能节点 |
| **第三阶段** | 「这里值得留下。」 | 镇子第一次为玩家这一季的生活聚一次 | **《秋日晒场》＝第一章章末收束（总结型事件）** |

> **关键定位调整（v1.5）**：原第九节第九行把"第一次小镇活动（春日集）"设为第一章终点。现按制作人 v1.5 拍板——**春日集＝中部聚能节点**（"原来还能热闹起来"），**《秋日晒场》＝第一章小结尾**（"证明这里还有人在生活"）。晒场是**总结型事件**：它不靠玉米成立，而是靠老张有故事、夏雅有记忆、阿风有未来想法、玩家已经改变过很多地方之后，大家把这一年的东西拿出来。
