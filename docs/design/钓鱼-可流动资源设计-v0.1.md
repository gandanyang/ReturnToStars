## 〇、一句话定位

**钓鱼 = 获取一种可流动的生活资源。**

玩家对鱼的选择（卖 / 换 / 送 / 放）产生不同质地的回报——不是限制玩家，而是**让不同选择产生不同价值**。

**设计原则（制作人定稿）：「鱼是资源，但不是答案。」** 游戏不评价玩家哪种选择更正确（卖 / 换 / 送 / 留），只提供更多认识这个小镇的方式。

## 一、核心原则（四条护栏，评审重点）

1. **卖是基础闭环**：全部鱼可卖、价格合理，玩家"钓鱼能补一点钱"的预期成立；不搞"禁止卖鱼"的教育式设计。
2. **换不是数值题**：交换回报必须包含至少一项**无法量化的内容**（台词 / 场景 / 相簿 / 世界变化）；禁止出现"永远换最划算"的计算。
3. **换不是制造链**：所有交换**一对一、单跳、每 NPC 一次性**；禁止多跳合成（鱼→木→花架→旧照片）——那是配方表，不是人与人的私事。
4. **发现是偶遇不是教学**：第一次交换由夏雅自然搭话引出；无任务板、无弹窗教学。

| # | 问 | 答 |
|---|---|---|
| 1 | 解决什么问题 | 河边（S6）"能停留但无事可做"；资源只有卖/用两种出口，缺少生活感流动 |

## 三、玩法设计（MVP）

### 3.1 钓鱼点

- S6 老河堤（town 西侧 x5 列岸线，长椅 (5,15) 附近）；未来扩展 farm 水塘。
- 交互：河岸出现「钓鱼」标记（复用 `tryInteract` 范式）→ 按 E 抛竿。

### 3.2 交互流程（轻量，无复杂小游戏）

```
抛竿 → 水面漂浮物/波纹（Graphics 程序绘制，零素材）
  → 3~6 秒随机咬钩（波纹变大 + 音效）
  → 2 秒窗口内按 E 收竿 = 成功
  → 错过 = 鱼跑，无惩罚，可重试
```

## 四、四层价值落地

### 4.1 卖（基础闭环）

鱼进入背包（新增 3 个 ItemDef，16×16 图标走脚本管线），直接复用 FEATURE-039 智能出售。

### 4.2 换（一对一、单跳、每 NPC 一次性）

| 玩家持有 | 找谁 | 回报 | 类型 | 事件 id |
|---|---|---|---|---|
| 青禾鲫×1 | 夏雅（首次钓鱼后偶遇） | 果干 → 次日河边长椅小场景 → 相簿《果干与河风》 | 发现时刻 + 相簿 | fish_exchange_xiya |
| 青禾鲫×1 | 商店老板 | 「明天给你留一碗热汤」→ 归星记录标签 + 老板台词变体（复用 shopRevivalTier） | 非数值 | fish_exchange_shop |
| 河虾×1 | 小梅 | 花田旁小饭桌（GameObject）+「今天刚好想吃鱼。」 | 世界变化 | fish_exchange_gardener |
| 黄昏鱼×1 | 老张 | 老屋门轴修好（house 视觉）+ 夜晚老张家灯亮（❌ 无木材） | 世界变化 | fish_exchange_miner |
| 黄昏鱼×1 | 阿风 | 晚上河边生火烤鱼（S6 河堤火堆，「这次不会糊」）——儿时旧友的共同记忆 | 世界变化 | fish_exchange_adventurer |

### 4.3 送（无数值，事件化，符合 D-004）

上表即"送"的实现——**不给好感数值**，回报全部是剧情事件 / 世界变化 / 相簿。

### 4.4 放生（生态事件，✅ v1.3 已改造 2026-08-15）

- **改造点（制作人拍板）**：不再"每次收竿都做收/放选择"（会变流程负担）；改为**低概率小鱼苗事件**——普通鱼直接进背包，15% 概率钓到"青禾鱼苗"才暂停弹「放回河里 / 带回去」。
- 放回 → 首次放生记天（`mapFlags.fishReleaseDay`，读档保持）→ **无任何奖励**，纯氛围。
- 带走 → 青禾鱼苗进背包（收藏/研究，不可售，无惩罚）——没有正确答案，两种选择都是"参与了这个世界"。
- 放生 2 天后河面出现鱼影（Graphics 4 条游动，town S6 河堤）→ 玩家自行联想"是不是因为我放生了？"
- 老姜台词（一次性 `laojiang_release_line`）："最近河里的小家伙，好像多起来了。"
- 实现位置：`MapScene.onFishingSuccess`（普通鱼直接收 / 鱼苗走 `presentFryReleaseChoice`）→ `releaseCurrentFish` / `keepCurrentFry` / `setupReleasedFishShadows` / `buildLaoJiangDialogue`；概率 `FISHING_CONFIG.fryChance=0.15`；探针 `.tmp/probe-fish-release.mjs` 10/10。
- 历史：2026-08-14 拍板后置；2026-08-15 v1.2 落地（每次选择版）；同日 v1.3 改造为低概率鱼苗事件（见 `钓鱼生态化-v1.3-方案-v0.1.md`）。

## 五、发现时刻（招牌）

第一次钓到鱼后，夏雅在 farm/town **偶遇**（非任务）：

> 夏雅："这是你刚钓的吗？"
> 林澈："嗯。"
> 夏雅："那要不要拿它换我刚晒好的果干？"

交换后 → 次日河边长椅出现小场景（夏雅 + 果干 + 林澈坐着看河）→ 相簿解锁。

> ✅ **台词已定稿（2026-08-14 制作人拍板）**：
> - 夏雅（发现时刻）：「刚钓的？」「嗯。」「我那晒了点果干……要不，拿鱼换？反正我一个人也吃不完。」
> - 次日河边：「来了？坐。」「（咬一口）嗯，甜。」「（笑）晒的时候放了一点盐。」
> - 商店老板：「哟，这鱼新鲜。搁我这，明天给你留碗热汤。」
> - 小梅：「呀，河虾！」「拿着吧，今天刚捞的。」「嗯，谢谢。……你等下再来看。」
> - 老张：「这鱼不错。晚上来家里吃。」（+ 往老屋看一眼的旁白动作）
> - 阿风（儿时的旧友，非冒险家）：「哟，今天钓的？」「嗯。」「小时候咱们在河边烤过鱼，还记得不？」「记得。糊了。」「……这次不会糊。晚上来。」
> 原则：NPC 先作为"人"对鱼做反应，不解释交换系统；少讲情绪，多讲具体生活。

## 八、扩展路线（后置）

野莓 / 蘑菇 / 昆虫 / 花 / 木材逐步进入同一交换网络——玩家最终发现"我捡到的每一样东西，都可以拿去和别人发生一点关系"。

**扩展铁律**：每个新资源都走「卖 = 基础闭环 + ≥1 个一对一交换 + 非数值回报」最小模板；**禁止做全局配方表 / 价值换算表**。

## 九、验收标准

1. 探针全绿：钓 3 种鱼 / 卖 / 4 交换 / 世界变化（小饭桌 / 门轴 / 夜灯）/ 一次性 / 读档保持。（放生后置）
2. 玩家首次钓鱼后 5 分钟内经历一次"发现"（夏雅果干），自然说出"还能换东西？"。
3. 河边停留测试（Phase3 §七.2）：S6 停留率相比当前明显提升。
4. 反 AI 味抽查：交换对白遮名可辨认；无"这个镇子的东西是会流动的"式主题演讲。
5. 存档兼容：旧档加载无新字段报错。
6. **隐藏 P0（体验验收）**：玩家第一次拿到鱼时不应想当然全部卖掉——首次钓鱼存在一次轻微"人际碰撞"（夏雅看见鱼才产生偶遇），玩家有机会发现"鱼不只是拿来卖的"；不教学、非弹窗、非任务。
