## 四、接入原则（对齐反馈层级规范）

1. **只 L3 范围**（主线 / 重要支线·心语 / 复兴事件）；普通采集钓鱼继续 L1/L2。
2. **同事件只弹一次**：随已有一事件标记（triggerOnce / mapFlags / restore）判定，读档不重弹。
3. **不打断操作**：StoryNotification 不冻结玩家（对齐 showMemoryMoment）。
4. **副标题写"你改变了什么"**，不写"任务完成"。
5. registry 新增重要事件时，先在这里登记，再接入。
