---

## 〇、一句话定位

> 之前玩家帮助一个人（老张/夏雅/老姜）；这一次，**整个青禾镇因为玩家这一季的生活，重新想起来了"把这一年的东西拿出来晒一晒"这件事**。

收成的时候，镇上的老人想起：青禾镇以前有个晒场——大家把这一年的收成摆出来，晒的不只是粮食，也是生活。于是镇子第一次为了玩家这一季种下的东西，重新把晒场摆起来。

## 一、文化内核（与"丰收节"的根本区别）

**不是**通用小镇的"丰收庆典"（谷物展示架 + 篝火 + 农产品篮——放日本乡村/欧美小镇/星露谷都成立）。

**而是**中国沿海小镇记忆里的一件事——**晒秋 / 秋日晒场**：

> **不是庆祝丰收，而是证明这里还有人在生活。**

"晒"的动作里藏着：收成、旧手艺、海边鱼干、家家户户忙几天、以及"把这一年的东西摆出来给人看"的生活气。

## 二、设计红线（对齐既有护栏 + 本次拍板）

1. **规模 ≤ 春日集**（克制版 ≤ 观星夜 40%）——不做大型活动、不做复杂玩法、不做倒计时/失败惩罚。
2. **复用 EventPlan 模板**（prepare / active / aftermath / permanent）——第二个实例，不是再造系统。
3. **不引入季节系统**（无四季循环 / 无作物季节限制 / 无节气系统 / 无年复一年活动）。
   - 避免把项目推向"模拟经营"。核心不是"我经营一个小镇很多年"，而是"我回来以后，让一个正在消失的地方重新发生生活"。
4. **用"收成的时候"代替"秋季机制"**，不写"秋天到了"（避免"为什么一直春天突然秋天"）。
5. **三类准备是"镇子在准备什么"的世界状态**，不是玩家待办清单（庆典筹备系统 §九.2）。
6. **解锁由"生活事件完成"决定**，不做"人气数值涨到 X"（庆典筹备系统 §九.1）。
7. **不新增资源/不新增地图/不新增常驻 NPC**——资源全部来自现有玩法产出。
8. 台词方向稿施工，制作人"人话化"定稿后替换。

## 三、命名（拍板）

| 项 | 定名 |
|---|---|
| 活动名 | **《秋日晒场》** |
| 永久地点 | **「青禾晒场」** |
| 完成文案（UI） | **「青禾晒场已恢复」** |

## 四、触发（决策 1 · 拍板：玉米首次收获即解锁）

触发逻辑（避免"玉米收获→解锁活动"的系统奖励感，玩家感受到的是"镇上的人想起了一件被遗忘的事"）：

```
首次收获玉米
  ↓
镇民讨论今年收成
  ↓
老张提起晒场
  ↓
EventPlan 开始
```

- 前置链：章节 ≥1 → 春日集完成（`ch1_spring_fair`）→ 首次收获玉米（`crop_corn_first_harvest`）
- 弱引导（居民台词，不广播）：「最近这批玉米刚好收下来。」/「以前每到这个时候，镇里都会把这一年的东西拿出来晒一晒。」

## 五、EventPlan 三阶段

### 5.1 筹备（prepare：三类准备，世界状态）

> 目标不是"举办庆典"，是"**恢复青禾镇曾经的晒场**"。

| 类 | 世界状态的名称 | 内容 | 复用/落点 |
|---|---|---|---|
| 环境 | **「晒场恢复」** | 木架 / 竹席 / 晒篮 / 玉米串 / 南瓜 / 辣椒串 / 海边鱼干架 | town create 按准备进度渲染（零素材 Graphics，对齐星光艺术展环境物件范式） |
| 人际 | **老张·过去 / 夏雅·现在 / 阿风·未来** | 老张恢复旧手艺；夏雅整理旧照片发现旧晒场位置；阿风年轻时的新视角 | showDialogue 注入（对齐 `buildArtShowDialogue`） |
| 资源 | **「今年的收成」** | 玉米 / 蔬菜 / 鱼 / 采集物——玩家**只是其中一部分**，NPC 也会准备 | 素材箱交付点（复用 `artShowBox` 范式） |

### 5.2 人际三时代（决策 3 · 拍板）

老张 / 夏雅 / 阿风三人组合已稳定，他们分别代表青禾镇三个方向：

| 角色 | 时代 | 台词意象 | 定位 |
|---|---|---|---|
| **老张** | 过去 | 「以前就是这么过来的。」 | 恢复旧手艺：晒鱼干 / 腌菜 / 教年轻人处理收成 |
| **夏雅** | 现在 | 「那些消失的东西，可以重新回来。」 | 整理旧照片，发现旧晒场位置——玩家正让它重现 |
| **阿风** | 未来 | 「如果有人看到这里，也许会喜欢。」 | 年轻人的开放视角，**不站队商业** |

> ⚠️ **阿风不要变成"商业派"**：他只是年轻人的开放视角（"让外面人也看看"）。第三章真正冲突时他可以有变化，现在不能提前站队。

### 5.3 当天（active）

**傍晚 · 晒场**：
- 老张整理晒架 / 夏雅摆旧照片 / 阿风帮忙搬东西 / 孩子跑来跑去
- 声音：风 / 木架 / 聊天
- 远处晒着一排排东西，风吹过去

**夜晚 · 海边长桌**：
- 灯笼 / 海风 / 食物 / 老人聊天
- **不要篝火**（决策 2 · 拍板：去掉篝火）。篝火太像"游戏活动模板"（庆典=篝火=烟花=欢呼）。青禾镇应该是"很久没有这样坐下来吃一顿饭了"。
- 老人：「以前镇里人多的时候，每年都这么坐一桌。」「好多年没坐这么多人了。」

**高潮**：
- 不是烟花，是**人回来了**。
- 最后：远处**灯塔亮一下**——不是庆典效果，是"这里重新被看见"（连接灯塔线，复用 `setupLighthouseDistant`）。
- 林澈看过去——发现自己已经不只是游客。

### 5.4 永久变化（aftermath / permanent）

- **「青禾晒场」成为一处永久地点**（读档保持）：

```
青禾晒场
├── 晒架
├── 鱼干架
├── 收成展示
└── NPC停留
```

- **不要加摊位**（摊位会让它变成集市）；**不做"每年自动举办"**（无年份循环；EventPlan 一次性人生阶段）。

> **小孩玩耍的自然表现（非功能）**：不增加互动点。偶尔——一个小孩跑过去 / NPC 一句「别踩到晒好的东西。」这种随口一句比加互动点更好。

## 六、为什么是"第一次全镇回应玩家"（价值）

- 采集/钓鱼/种植此前都是**单个居民**的反馈（小梅/老张/夏雅）。
- 秋日晒场是第一个**全居民共同**的回应：镇子因为玩家这一季种下的东西，重新恢复了晒场生活。
- 与第三章商业化矛盾强连接——**未来的冲突不是"要不要办活动"，而是**：

> **"这个晒场，是留给镇里人的生活，还是变成给游客看的景点？"**

- 生根台词（只作方向种子，阿风当前不站队）：
  - 阿风（年轻人）：「其实这里很有潜力，可以做成旅游路线。」——**此句为第三章预留，本切片不落地**（阿风现在只说开放视角）
  - 老人：「晒给自己看，和晒给别人看，不是一回事。」——**此句为第三章预留，本切片不落地**（本切片老人说的是"以前都是这么过来的"）
  - 备注：商业化矛盾的两句只在**第三章**正式出现，本切片不提前站队。

## 七、验收标准（对齐星光艺术展 §八：共两条）

1. **永久变化存在**：「青禾晒场」成永久地点（晒架 + 鱼干架 + 收成展示 + NPC 停留 + 收成时令语音），读档保持。
2. **第二次路过广场/晒场"不一样"**：完成前广场空、无晒场；完成后晒场有人晒东西、NPC 在晒场停留、收成时令台词。

## 八、明确不做（本切片）

- ❌ 复杂玩法（QTE / 计分 / 挑战）
- ❌ 倒计时 / 限时 / 失败惩罚
- ❌ 新增资源 / 新增地图 / 新增常驻 NPC
- ❌ "收 100 个玉米"式肝度——"今年的收成"是放一些今年种出的东西，玩家只是其中一部分
- ❌ 人气数值成长条
- ❌ **季节系统 / 年复一年活动**
- ❌ 篝火（决策 2）
- ❌ 摊位（决策 4）
- ❌ 小孩"互动点"（决策 4：用自然表现取代）
- ❌ 商业化矛盾具象化（决策 3：阿风本切片不站队）

## 九、技术映射（零新系统）

| 能力 | 复用 / 落点 |
|---|---|
| EventPlan 状态 | 复用 `mapFlags` + 一次性 `triggerOnce`（对齐 artShow 字段范式），不新增顶层存档字段/不新增 EventPlan 框架 |
| 三类准备 | town create 状态渲染 + showDialogue 注入 + 素材箱交付 |
| 当天演出 | 春日集灯火/剪影视觉语言（`buildSpringFairFX` 范式）+ 海边长桌（零素材 Graphics）+ 灯塔回应（`setupLighthouseDistant`），**无篝火** |
| 永久地点 | 青禾晒场 Graphics（晒架/鱼干架/收成展示）+ NPC 停留 + 收成时令语音（读档保持） |
| 触发 | `ch1_spring_fair` + `crop_corn_first_harvest` 均完成 → 软触发（进 town 傍晚；收成时令"最近这批玉米刚好收下来"） |

## 十、与春日集 / 星光艺术展的区分

| 事件 | 是谁的回应 | 立意 |
|---|---|---|
| 春日集 | 镇子自发的热闹（集市恢复） | "原来还能热闹起来" |
| 星光艺术展 | 外向——把光展示给世界 | "青禾镇重新被看见" |
| **秋日晒场** | **内向——镇子为这一季的收成恢复生活** | "证明这里还有人在生活" |
