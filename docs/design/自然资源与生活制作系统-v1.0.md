## 〇、为什么需要这份蓝图

砍树 / 挖矿 / 采集三个玩法，现状是**并列的"收集材料"**：

| 玩法 | 现状 | 症结 |
|---|---|---|
| 采集 | 生活采集 Phase1 已做（蒲公英/野莓/蘑菇/野花/树枝），已接交换网络 | **无自然状态/条件/观察**，不知道"为什么要收集" |
| 砍树 | `tryChopTree`，砍→木材×2 | 纯消耗，无树木状态、无建设反馈 |
| 挖矿 | `tryMine`，铁/铜/石头 | 浅层单一，无"星辉/过去"连接 |

如果只做采集深化，会出现"采集有图鉴，但木材仍废料、矿石仍卖钱"的**割裂**。所以先定总框架，再分期。

## 一、总框架（自然资源生态系统）

```
自然资源
  采集（花/果/菌/草/树枝）
  砍树（木材/枯枝/树叶）
  挖矿（石/黏土/铁/铜/星辉）
     ↓
观察 / 发现（★ 归星特色核心层）
  第一次采集 / 特殊条件发现 / 图鉴记录 / 「爷爷说…」认知
     ↓
理解价值
     ↓
加工 / 生活制作（P1）
  堆肥 / 花肥 / 鱼饵 / 染料 / 装饰材料 / 木板
     ↓
重建土地 / 城镇建设（P2）
  木板→修复桥/摊位/家具/旧宅→窗户亮
     ↓
居民事件 / 世界状态变化（贯穿）
  NPC 反应 / 区域亮起 / 图鉴 / 故事
```

> **回归核心**：归星和星露谷最大的区别之一 = **"观察/发现"层**。普通玩家看到蒲公英是一个采集物；林澈观察后解锁图鉴："爷爷以前说，青禾镇的蒲公英在雨后会开得特别好。"——这才是"认识这片土地"。

## 二、资源哲学（三条主线分属三个时空）

| 主线 | 核心 | 时空 | 升级方向（不是"更快"） |
|---|---|---|---|
| **采集** | **认识这片土地** | 现在 | 认识世界——自然观察 / 特殊条件发现（雨后、夜发光、时令植物） |
| **砍树** | **重建这片土地** | 未来 | 懂木材价值——木材/香木/特殊木 → 镇子家具/观景台/灯塔木结构 |
| **挖矿** | **寻找这片土地的过去** | 过去 | 发现过去——旧矿灯/旧工具/爷爷记录/星辉→修天文设备 |

> "重建"而非"建设"：玩家不是在打造超级村庄，而是**修复过去留下来的家园，创造新的生活**——这个地方曾经有过生活，现在我让它重新回来。
> 情感落点：不是"更快赚钱"，而是"玩家越来越像一个真正生活在青禾镇的人"。

## 三、环境状态（不是"季节系统"）

> 制作人拍板：**不引入四季系统**（作物限制/年循环/季节日历会产生大量设计债，把项目拉向《星露谷》）；用**轻量"自然状态"**替代——玩家感到"最近天气转暖，森林里的蒲公英多了"，而不是"现在是春天只能种春季作物"。**不绑定"春夏秋冬"概念**，未来可扩展 暴雨周/花期/星辉夜/灯塔季 而不被四季限制。

| 自然状态 | 词 | 影响 | 不影响 |
|---|---|---|---|
| `germination` | 萌芽期 | 采集物池（野花/春笋）、景观、少量 NPC 对话 | 作物/主线/自由度 |
| `thriving` | 繁盛期 | 采摘（浆果/荷花）、景观 | 同上 |
| `harvest` | 收获期 | 采集（果实/菌类）——与《秋日晒场》联动 | 同上 |
| `serene` | 静谧期 | 特殊植物（仅在静谧期出现） | 同上 |

**天气 / 时段影响**（生活感来源，"今天下雨去森林看看"）：
- 雨后：蘑菇增多、河边出现贝壳
- 夜晚：萤火虫、夜花

## 四、资源 / 加工 / 用途 / 居民事件表

### 采集（认识土地 → 图鉴）

| 资源 | 现状 | 深化 |
|---|---|---|
| 蒲公英/野莓/蘑菇/野花/树枝 | ✅ 已有 | 环境状态下数量/是否出现变化；加入"星露蒲公英"（雨后、夜发光、可做特殊肥料）等认知向采集物 |
| **自然图鉴（植物观察册）** | ❌ 无 | 发现→记录"青禾镇常见野花"→完成图鉴→解锁花园装饰 / NPC 故事 |

### 砍树（重建土地）

| 阶段 | 设计 |
|---|---|
| 树木状态 | 小树（不可砍，可观察成长）/ 成熟树（可砍，高木产）/ 老树（掉特殊材料·砍了影响环境）——让玩家权衡"这棵要不要砍" |
| 加工 | 木材 → 木板 |
| 建设 | 木板→修复桥梁/摊位/家具/装饰；第一章旧宅→木板→窗户亮点亮 |

### 挖矿（寻找土地的过去）

| 阶段 | 设计 |
|---|---|
| 矿层差异 | 浅层：石头/黏土/铁；深层：铜/水晶/特殊矿物——每次进入玩家选"今天找什么" |
| **星辉石** | 雨后矿洞深处；用途：修复旧天文设备 / 制作观星装置 / 点亮灯塔（与星之碎片主线咬合） |
| 过去发现 | 旧矿灯/旧工具/爷爷留下的记录——连接林澈过去 |

## 四、自然观察系统（★ 归星核心特色，采集的中枢）

> P0 不只是"自然图鉴"——是**自然观察系统（轻量）**。归星与星露谷最大的区别：普通玩家看到蒲公英=采集物；林澈观察后解锁图鉴="爷爷说青禾镇的蒲公英在雨后会开得特别好"。

### 观察层（插入"资源 → 理解价值"之间）

```
资源
 ↓
观察
 ↓
理解价值
 ↓
加工
 ↓
使用
```

### 观察构成

| 观察维度 | 定义 | 例子 |
|---|---|---|
| 发现记录 | 第一次采集即记录 | 蒲公英：「青禾镇常见野花」 |
| 特殊条件发现 | 特定条件触发更丰富的记录 | 蒲公英特殊：「雨后的清晨，花瓣上的露珠会反射星光。」 |
| 解锁渠道 | 观察获得图鉴，不直接给属性 | NPC 对话 / 图鉴文字 / 小事件 |

### 奖励（不是属性，是"认识"）

- NPC 对话（夏雅/老周等多一句：指向过去）
- 图鉴文字（"青禾镇常见野花"→ 特殊记录）
- 小事件（解锁花园装饰 / 观察箱等）

## 五、工具升级（低比例，不做纯数值）

- 可以有，但**不是木斧→铁斧→金斧**的传统模拟经营式成长。
- 方向：
  - **斧头**：旧柴刀（普通树）→ 木工斧（效率）→ 祖传斧（特殊木材）
  - **镐子**：旧镐（浅层）→ 铁镐（深层）→ 星辉镐（发现特殊矿物）
  - **采集篮**：普通篮→藤编篮（多带）→ 观察箱（保存昆虫/植物研究）

> 升级的价值落点不是数值，而是**解锁"认识/重建/发现"的新内容**。

## 六、工程实施（分期，代码 P0-P3）

> ⚠️ 工程边界（制作人 2026-08-15）：**不要急着往 `Gathering.ts` 塞**。这个系统未来会扩张（钓鱼/捕虫也要接），倾向新增独立 **`NatureSystem`**：
> ```
> NatureSystem（当前自然状态 / 天气影响 / 时段影响 / 特殊资源生成）
>    ↓
> ResourceSpawner（资源生成）
>    ↓
> Gathering（玩家采集动作，只负责"采"）
>    ↓
> Inventory
> ```

| 期 | 内容 | 价值 |
|---|---|---|
| **P0 采集深化** | **P0-1 自然状态**（影响资源池）/ **P0-2 条件采集**（雨后蘑菇/夜晚萤火虫/森林特殊植物）/ **P0-3 自然观察**（图鉴）/ **P0-4 资源标签**（`resource_tags`：wood/plant/food/insect/mineral/special，为 P1 制作准备） | 最快收益；连接已有采集；**制作解锁挪到 P1** |
| **P1 生活制作** | 堆肥/花肥/鱼饵/染料/装饰材料 + 木材用途（木板）；例：蒲公英+树叶+食物残渣→堆肥 | 连接所有资源的"桥" |
| **P2 砍树 + 重建城镇** | 树木状态 / 木板 / 旧宅修复 → 窗户亮 | 情感最强差异点（重建家园） |
| **P3 挖矿 + 星辉体系** | 矿层 / 星辉石 / 天文设备 / 灯塔点亮 | 大版本亮点，需最多配套 |

## 七、边界红线

- ❌ 不做"四季系统"（作物季节限制/年循环/季节日历）；自然状态**不绑定春夏秋冬**
- ❌ 不做纯数值工具升级（木斧→金斧）
- ❌ 三套不做成"收集材料"的并列循环——必须有观察/加工/重建/发现的连线
- ✅ 自然状态不影响作物种植 / 主线推进 / 玩家自由度
- ✅ 代码分期 P0-P3；工程走独立 `NatureSystem`，不污染 `Gathering.ts`

## 八、优先级判断（制作人 2026-08-15）

从产品效果看：**P0 采集深化（自然状态+条件采集+自然观察+资源标签）> P1 生活制作（连接所有资源的桥）> P2 砍树重建城镇（情感差异点）> P3 挖矿星辉（后期大亮点，需配套）。**
