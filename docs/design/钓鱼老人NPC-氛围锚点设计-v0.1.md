# 钓鱼老人 NPC「江叔」— 氛围锚点设计 v0.1

> 状态：📝 方案稿（B 类：新 NPC，待制作人拍板后施工）｜日期：2026-08-14
> 定位：青禾镇**最后一个还坚持每天去河边坐一下午的人**——氛围锚点，不是任务机器。
> 命名：⚠️「老周」已被木匠占用；主推 **江叔**（江=河，天然贴人设），备选 **老姜**。
> 关联：钓鱼 Phase 1-4（已有玩法/交换）、青禾镇美术质感升级执行方案（河岸段 P0）

## 〇、一句话

> 玩家第一次来到河边，看到一个老人坐在那里——竹竿、小板凳、茶杯，没有感叹号、没有任务。
> 靠近，他问：「年轻人，也喜欢看水？」

---

## 一、角色定位

- **不是**任务发布机器，不是钓鱼教学弹窗。
- **是**青禾镇的一个"记忆点角色"——定位接近夏雅 / 爷爷这一类"让人记住这个镇子的人"。
- 视觉：草帽/斗笠、灰旧衫、竹竿、小板凳、茶杯；下午坐在 S6 河堤，傍晚收竿回家。
- 语言指纹（反 AI 味）：话少、慢、带河/水/时间意象；金句稀缺；「坐得住」是他的口头生活观，不喊口号。

---

## 二、功能分层（第一版 vs 后置）

### 第一版：氛围锚点（约 3-4 人日）

**1. 出场与常驻**
- 每天 13:00-17:00 在 S6 河堤坐着钓鱼（小板凳 + 竹竿 + 茶杯，程序绘制零素材；傍晚收竿回家）。
- 无条件感叹号；走近才有互动（靠近按 E）。

**2. 钓鱼教学（NPC 教，不弹窗）**
- 玩家第一次靠近河边（未钓过鱼）时，江叔自然搭话：
  > 江叔：钓鱼啊，不难。
  > 江叔：别急着想鱼什么时候上钩。
  > 江叔：先学会坐得住。
- 之后第一次钓鱼由玩家自己开始（沿用现有手感，无强制引导）。
- 一次性 `triggerOnce('fisher_teach_done')`。

**3. 鱼类记录者（鱼 = 记忆，不是资源）**
- 钓到鱼后靠近江叔，他按鱼种评价（一次性每种）：
  - 青禾鲫：「小鲫鱼，小时候我天天吃。」
  - 河虾：「河虾啊……以前河边一捞就是一碗。」
  - 黄昏鱼：「黄昏鱼？这个点来钓，会钓鱼。」
- 让"钓到什么"变成"被记住"。

**4. 复兴连接（三阶段台词变体）**
- 前期（一个人）：氛围对白。
- 集市恢复后：「今天河边突然热闹起来了。」
- 后期（可选视觉）：钓鱼点旁出现一两个小孩，江叔：「年轻时候觉得热闹烦。老了才发现，没人吵才是真的安静。」（小孩视觉后置）

### 第二版：小事件《江叔的最后一条鱼》（后置，约 3-4 人日）

- 认识江叔后某天，他说年轻时在这里钓到过一条特别大的鱼。
- 玩家帮他找特殊鱼饵 + 特定天气/时间 → 钓上「大青鱼」。
- **奖励不是钱**：江叔把旧鱼竿送给玩家——「以后啊，这根杆子就交给你了。」
- 旧鱼竿 = 背包纪念物（不可售），零新存档字段。

## 三、技术实现映射（零新系统）

| 能力 | 复用 |
|---|---|
| 常驻 NPC | NPCSystem 条件性注册（参照木匠老周范式），下午时段在场 |
| 对话注入 | showDialogue 条件注入（参照钓鱼交换范式：背包/事件条件） |
| 一次性 | EventManager.triggerOnce（教学/各鱼种评价/小事件各步） |
| 鱼种评价 | 背包有对应鱼 + 未评价过 → 注入评价对白 |
| 复兴台词 | getRevivalLevel / isRestored('marketSquare') 条件分支 |
| 贴图 | 新 32×32 精灵（草帽渔翁，走美术管线）；立绘按老周立绘流程 |
| 小事件 | 事件链（triggerOnce 多步）+ 旧鱼竿 ItemDef（forbidden 不可售） |
| 存档 | 零新顶层字段（全部 triggerOnce + Inventory） |

## 四、与现有钓鱼的关系

- 江叔是"氛围层"，不改钓鱼手感（Phase 1 已定：等待→判断→收竿）。
- 教学由江叔承载后，现有"无教学自己悟"的 Phase 1 验收仍成立——江叔只是给第一次来的玩家一句"坐得住"的生活化提示，不弹窗、不强制。
- 与五条 NPC 交换共存（鱼可以换、可以卖、可以给江叔看）。

---

## 五、范围与红线

- **只做 1 个氛围锚点 NPC**（不扩成"大量 NPC"，遵守第一章禁止事项）。
- 不堵主线、不强制触发；错过江叔不影响钓鱼/交换。
- 台词过 D-017/D-018 审查（遮名可辨认、不解释系统、不主题演讲）；最终文案制作人定稿。
- 配音走语音交付流程（先试听→确认→打包）。
