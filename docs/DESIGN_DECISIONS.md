## D-001 移动端只支持横屏

- **日期**：2026-08-08（明确拍板；此前 AndroidManifest 已锁横屏）
- **决定**：游戏只支持横屏。所有移动端 UI / 触控 / 镜头 / 安全区以横屏 16:9 为基准。
- **原因**：Phaser 地图展示需要宽视野；UI 信息密度适合横向；目标设备为横屏体验。
- **拒绝**：竖屏手游方案；"顺便适配竖屏"的增量建议。
- **强制手段**：`AndroidManifest.xml` `screenOrientation="landscape"`；`index.html` 竖屏旋转提示层；代码常量 `MOBILE_ORIENTATION='landscape'`（`src/constants/platform.ts`）。
- **状态**：**永久决定**。

## D-014 主角特殊性尺度（《天命之子之辩》半天命/半选择模型）

- **日期**：2026-08-10（制作人拍板，设计冻结暂不改代码与剧情正文）
- **决定**：主角林澈采用**「半天命、半选择」**特殊性模型。特殊性 = **关系 + 条件 + 选择**，不是天命 + 血统 + 预言。
  - 长期停留区间：「与世界存在特殊关系」～「能够触发某些特殊回应」，**不跨入「被世界选中」**。
  - 禁止：被世界选中 / 唯一救世主 / 爷爷早知会回来 / 碎片只等林澈 / 血统注定 / 第一章给出完整答案。
  - 允许：碎片特殊回应但不解释原因、NPC 对特殊性无统一解释、靠林澈「选择留下」触发岛屿回应（因果模糊不回答）。
  - 稀缺性预算 ≈ 90% 普通 / 8% 关系特殊 / 2% 神秘特殊；「仅林澈能做到」的 C 类必须极少。
  - 主角特殊是「关系型特殊」不是「能力型特殊」：不因特殊而最强 / 最聪明 / 人人依赖。
  - 设计剧情自检：把林澈换成普通年轻人，这件事还能否发生？（A 普通 / B 关系 / C 仅林澈，C 极少）
- **原文**：`docs/design/天命之子之辩-主角特殊性尺度设计原则-v1.0.md`
- **状态**：已拍板，已同步写入 AI_GUARDRAIL.md（第 13 条）。

## D-015 碎片结构尺度修正（六根式许可，撤销"制造牵挂"过激表述）

- **日期**：2026-08-10（制作人更新观点，v1.1 修正）
- **撤销**：此前"制造牵挂，不制造谜底"的过度解读——差点从"不要把碎片做成纯粹解谜钥匙"滑到"不能做收集碎片→集齐→解锁秘密"，不是本意。
- **新原则**：**允许谜底存在，但不要让谜底成为唯一价值。**
  - 允许"收集 → 解锁 → 揭示"传统结构（六根式）；「收集」本身就是玩法，「解锁」本身就是反馈。
  - 但每次解锁必须同时带来**世界变化 / 关系变化 / 玩家意义上的变化**。
  - 碎片可以是钥匙，但不能只是钥匙——既打开门，也让玩家看到门后的人、土地和未来。
  - 反范式：集齐七颗珠子→门开→得到与玩家无情感关系的"终极真相"（禁止）；归星岛改法：集齐/恢复碎片→岛恢复功能→离开的人/船/商路/区域重新出现→玩家看到劳动改变世界。
- **三层结构**：① 玩家特殊但关系型（非血统/神选）；② 碎片承担"收集→解锁→推进"；③ 碎片解开的是"一段过去 + 一种联系 + 一个未来"。
- **与天命之子之辩合流**：主角可以特殊，但他的特殊不是"世界围着他转"；"天命"给他入口，不是通关答案；玩家自己的行动决定入口通向什么。
- **原文**：`docs/design/归星岛核心叙事原则-v1.0.md`（v1.1）、`docs/design/碎片系统长期路线骨架-v1.0.md`（v1.1）
- **状态**：已拍板，已同步 AI_GUARDRAIL.md（第 11 条）与岛屿世界观空间扩展方案（v1.2）。

## D-016 关系型天命正式命名 + 结构≠价值（碎片总纲）

- **日期**：2026-08-10（制作人更新观点，v1.2 增补）
- **关键澄清**：把两个不同维度分开——
  - **结构问题**（收集几个东西→解锁→揭示）：本身没有问题，允许甚至应该（游戏需要长期目标）
  - **价值问题**（为什么收集/获得什么）：真正要避免做空
- **碎片原则**：碎片允许是"钥匙"甚至应该是（否则玩家觉得"收集它有什么用"），但**不能只是钥匙**——**门后面必须有生活**（不是"恭喜打开古代遗迹"，而是"打开了一条重新有人经过的路"）。
- **关系型天命**（正式命名，取代"与天命之子之辩合流"表述）三层级：
  - ❌ 龙傲天型天命（世界选择我）：避免
  - ❌ 完全非特殊（谁来都一样）：不适合（"为什么是林澈回来"没答案）
  - ✅ **关系型天命**：我不是被世界选中的英雄，我是第一个重新回应世界的人。碎片选他的原因不是"血统特殊"，而是"愿意留下 + 愿意付出行动"
- **与爷爷闭环**：爷爷不是"预言主角的人"，只是"留下了一片等待被理解的土地"；林澈不是"完成爷爷使命的人"，是"重新开始这段关系的人"
- **四章关键词校准**：第一章发现 / 第二章行动 / 第三章理解 / 第四章选择（最终问题：当岛重新有机会连接世界时，你希望它变成什么？）
- **总纲**：归星岛不是反对传统收集结构，而是重新定义收集结构的意义。碎片可拥有谜底、承担主线、推动探索，但最终解开的是一段关系、一片土地和一个未来。主角不是天命之子，而是天命回应的人；天命给予入口，行动决定结果。
- **原文**：`docs/design/归星岛核心叙事原则-v1.0.md`（v1.2）、`docs/design/碎片系统长期路线骨架-v1.0.md`（v1.2）
- **状态**：已拍板，已同步 AI_GUARDRAIL.md（第 11 条）与天命之子之辩（第 13 条关联）。

## D-017 文本风格与反 AI 味标准（归星岛文风模型）

- **日期**：2026-08-10（制作人拍板，门禁级）
- **决定**：新增**《归星岛文本风格与反 AI 味标准 v1.0》**，与《天命之子之辩》同属 AI 生产护栏体系，管"角色怎么开口"。
  - 核心理念：不是"AI 去味器"（会形成所有人自然得一样的套娃），而是建立"这个游戏的人类作者会怎么写"的约束——模仿**一个具体的人在具体情境下说一句自己会说的话**。
  - 四层核心：① 禁止作者替角色说话；② 每个角色必须有说话缺陷；③ 允许对白不完整（停顿/改口/答非所问/说一半）；④ 主题词禁用/限用（回应/留下/记住/未来/命运/答案/意义等须稀缺）。
  - 文风指纹：从现有已获制作人认可的对白反向提取六角色语言特征（句长/`……`/信息密度/情绪表达/抽象词额度/说话缺陷/生活废话/绝不会说），新增角色须对照第五章表格。
  - 已拍板信号：说教句是禁区（StorySystem.ts:90-91 删除说教收尾；:398 "价值观但不演讲"）；NPC 必须保留无剧情价值的废话额度（NPCSystem.ts:273）。
  - 硬指标：**遮掉角色名能否猜出是谁**，猜不出=返工。
  - **v1.1 增补**（制作人 2026-08-10）：最高检测标准=遮名辨认（AI 味本质是所有人说话像同一个人，一个 ChatGPT 戴三顶帽子）；角色语言核心定位（夏雅=照顾者语言 / 老周=做事的人语言 / 镇长=守望者语言）；**不连续漂亮规则**（允许偶尔一句漂亮话，但连续两句=AI 味，每句漂亮话前后要有生活的缝隙）；四层过滤（角色→生活→信息→情绪）；**禁止 AI 替代角色思考**（AI 可扩写/提供多版本，但不得决定角色价值观/说话方式/自动补全剧情意义）。
  - **行动型角色原则**（2026-08-10 随 A1 定稿升级为最高级正面样本）：**角色不说"我为什么相信未来"，角色展示"我已经开始做未来需要的事情"**。行动型角色不表达价值，只留下痕迹（老周修门/阿风擦灯/居民摆摊，玩家自己看到"岛正在回来"）。老周性格="我来了，我东西都带来了"（生活事实），不是"我决定留下因为这里值得"（主题表达）。适用于灯塔/码头/老街/温泉等未来修复事件。
- **原文**：`docs/design/归星岛文本风格与反AI味标准-v1.1.md`
- **状态**：已拍板，已同步写入 AI_GUARDRAIL.md（第 14 条）。

## D-018 对白"角色自主表达测试" + 审查流程（文本重构前提）

- **日期**：2026-08-10（制作人拍板，随主线文本重构计划 v1.1）
- **核心判断**：**最大风险不是 AI 味，而是为了消灭 AI 味把已成立的温暖叙事拆掉**。第一章玩家情绪链（回来看看→土地活着→爷爷痕迹→岛曾有人→碎片→愿意留下）已成立，必须守护。
- **改名**：不再叫"去 AI 味"，改叫 **「角色自主表达测试」**。核心问题：**这句话是角色此刻想说的话，还是作者借角色说的话？**真正的 AI 味不是句子漂亮，而是**角色知道自己在表达主题**。
- **重构原则**：不是砍掉漂亮句，而是**降低"作者声音占比"**；归星岛不是真人聊天模拟器，需要文学感/余韵/温度。
- **新增第三条检查维度**（与遮名辨认/禁作者替角色说话并列）：**"删掉这句话，玩家是否仍然能理解？"**——删掉玩家就不懂=解释句（危险）；删掉仍懂=感受句（健康）。
- **分级施工**：第一批=A1 老周回归（必做，让老周描述动作不总结规律）；第二批=A2 林澈教学独白压缩（必做，观察→分析→一点感情）；第三批=B1 夏雅清晨 / B2 镇长碎片交付（**暂缓**，第一章情绪锚点，改需谨慎；B2 若改方向=NPC 不宣布结果，天命感还在但不是神谕）。
