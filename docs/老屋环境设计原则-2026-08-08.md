# 老屋环境设计原则：不是"爷爷纪念馆"，而是"有人生活过的旧房子"

> 版本：v0.1（2026-08-08 制作人定稿）
> 关联：`docs/开发约束与架构入口.md`、P0 体验优化设计文档（林澈与林远山"隔空对话"）
> 一句话原则：**不是把爷爷摆出来，而是让爷爷留下来的生活自然存在。**

---

## 一、为什么（设计动机）

早期风险：老屋容易做成"爷爷纪念馆"（墙上挂满照片、桌上放日记、旁边摆帽子），
这等于**告诉**玩家"这里有故事"，是游戏设计思维，不是真实的中国乡村老人故居。

真实感来源：**老人去世多年后，房子仍然保留生活痕迹**——家具还在，东西收在该收的位置，
私人遗物大多被家人收走/封存/缺失。**"一个人的痕迹正在消失"比"满屋子爷爷的故事"更有力量。**

## 二、爷爷留下的东西：三层分级

### 第一层：应摆在外面的——"生活家具"（无需解释，是房子的一部分）
木桌 / 椅子 / 床 / 衣柜 / 碗柜 / 木箱 / 凳子 / 电风扇 / 老式收音机 / 水壶 / 灯 / 农具柜
> 农村房屋很多家具不会因"某人去世"被清掉。它们的存在不是为了讲故事，而是因为曾经就是生活用品。
> **优先级：老屋升级的第一优先级。**

### 第二层：应该有但不"展示"的——"收起来的生活"（本土化处理核心）
农具 / 草帽 / 雨鞋 / 锄头 / 镰刀 / 水桶 / 麻袋 / 篮子 / 修理工具 / 旧衣服 / 被褥 / 杂物箱
> 不摆成"这里是爷爷的锄头"，而是：挂墙边、靠柴房、塞柜子、堆角落。
> 玩家第一次进去不会特别注意，走近才发现"哦，这里以前真的有人生活"。

### 第三层：真正属于爷爷的东西——**不要主动展示**（藏、缺、散、旧）
日记 / 个人照片 / 私人信件 / 教书留下的东西 / 重要证件 / 珍贵纪念品 / 与某人有关的私人物品
> 不能像博物馆展品摆桌上等玩家点击。现实中家人很可能早就收拾过/带走过/分过/扔掉过/封起来过。
> 甚至有些东西已经找不到了——**缺失本身就是叙事**。
> 例：整理柜子时才发现一本发黄的旧教材——
> 不写【爷爷的教书笔记】，而是"小学自然课本，封面已经磨掉了一角。" 林澈："爷爷居然还留着这个。"
> 没有把爷爷写成神秘人物，但玩家突然知道：这个房子里住过一个具体的人。

## 三、空间"生活逻辑"（交给美术设计）

| 空间 | 内容 | 基调 |
|---|---|---|
| 客厅 | 桌椅、柜子、电视/收音机、风扇 | 完整、普通、有人生活过 |
| 卧室 | 床、衣柜、床头柜 | 更私人，不刻意煽情（可能什么都没有） |
| 厨房 | 碗柜、锅、水壶、菜篮、灶台 | 最有生活感 |
| 院子 | 锄头、扁担、水桶、竹筐、晾衣杆 | 最有乡村感 |
| 杂物间 | 旧农具、纸箱、破凳子、废木料、旧瓶子 | 最有"时间感" |
| **某一个抽屉/柜子** | 照片、旧纸张、孩子们的作业、某件东西 | **才藏真正的故事** |

## 四、玩家体验曲线（为什么这样设计）

```
第一天： "哦，就是一间旧房子。"（背景噪声）
第三天： "这里原来还有这么多东西。"
某剧情： "原来爷爷以前还做过这个。"
到后面： "我好像慢慢认识这个已经不在的人了。"
```
爷爷的存在是"背景噪声"逐渐显影的过程，不强行灌输。

## 五、实施红线

- ✅ 桌椅板凳必须有（第一优先级）
- ✅ 农具应该有，但大多收在该收的位置
- ✅ 私人遗物不主动展示，而应藏、缺、散、旧
- ❌ 不做"博物馆陈列式"展示（照片墙/桌上日记/摆帽子）
- ❌ 不新增角色/任务链/存档字段；不改变主线流程
- ✅ 与既定爷爷设定一致：林远山是"留下生活痕迹的人"，不是"留下秘密的人"
