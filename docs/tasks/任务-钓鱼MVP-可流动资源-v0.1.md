## 一、目标

钓鱼 = 获取一种可流动的生活资源。四层价值（卖 / 换 / 送 / 发现）跑通，玩家第一次发现"东西不只是拿来卖的"。

**设计原则（制作人定稿）：「鱼是资源，但不是答案。」** 游戏不评价玩家选择（卖 / 换 / 送 / 留），只提供更多认识小镇的方式。

---

## 二、施工范围（MVP，制作人拍板）

1. **钓鱼本体**：S6 老河堤单钓点；抛竿 → 3~6s 随机咬钩（波纹 + 音效）→ 2s 窗口收竿；失败无惩罚可重试；成功收竿后游戏时钟 +5 分钟；不消耗体力。
2. **3 种鱼**（新 ItemDef + 16×16 图标，图标走 `tools/gen_item_icons.py` 脚本管线）：

| id | 名称 | 时段 | 概率 | 出售 |
|---|---|---|---|---|
| qinghe_carp | 青禾鲫 | 全天 | 55% | 30G |
| river_shrimp | 河虾 | 08:00-17:00 | 30% | 20G |
| dusk_fish | 黄昏鱼 | 17:00-20:00 | 15% | 45G |

3. **卖**：鱼进入背包，复用 FEATURE-039 智能出售。
4. **交换 ×4**（一对一、单跳、每 NPC 一次性，全部 `triggerOnce`）：

| 玩家持有 | 找谁 | 回报 | 事件 id |
|---|---|---|---|
| 青禾鲫×1 | 夏雅（首次钓鱼后偶遇） | 果干 → 次日河边长椅小场景 → 相簿《果干与河风》 | fish_exchange_xiya |
| 青禾鲫×1 | 商店老板 | 「明天给你留一碗热汤」→ 归星记录标签 + 老板台词变体（复用 shopRevivalTier） | fish_exchange_shop |
| 河虾×1 | 小梅 | 花田旁小饭桌（GameObject） | fish_exchange_gardener |
| 黄昏鱼×1 | 老张 | 老屋门轴修好（house 视觉）+ 夜晚老张家灯亮（❌ 无木材） | fish_exchange_miner |

5. **发现时刻（隐藏 P0）**：首次钓鱼时安排一次轻微"人际碰撞"——夏雅看到鱼才产生偶遇；**不教学、非弹窗、非任务**，让玩家有机会发现"鱼不只是拿来卖的"。

## 三、明确不做（本版）

- ❌ 放生彩蛋（后置 backlog）
- ❌ 复杂钓鱼小游戏（不做 QTE / 力度条）
- ❌ 木材等资源类交换回报
- ❌ 多跳交换 / 配方表 / 价值换算
- ❌ 好感数值（D-004）
