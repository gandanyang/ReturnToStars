> 来源：制作人 2026-08-15 拍板《星光艺术展-垂直切片设计稿-v0.2-拍板基线.md》｜状态：🟢 核心 + v1.3 余波已施工（永久变化 / NPC 停留旅人回访 / 商店留言），待制作人真机目测 + 收口

---

## 〇、一句话验收

玩家完成一次完整的"小镇主动准备迎接外界目光"的生活事件，并且**第二次路过广场时感觉不一样**。

---

## 一、目标

验证 EventPlan 循环闭环：

```
解锁 → 筹备（三类准备）→ 当天 → 永久变化
```

证明"小镇复兴是持续发生的过程"，不是一次性剧情事件。

---

## 二、范围（垂直切片，严格照拍板基线）

1. **「小镇计划」主菜单入口**（只读观察面板）：当前「星光艺术展 · 筹备中」；三类准备状态为**世界状态**（"展台已完成 / 灯光待准备 / 夏雅正在设计展区"），**不是任务板、不是倒计时**。
2. **EventPlan 实例（星光艺术展）**：目标 / 筹备 / 当天 / 回响 / 唯一性；状态进 SaveSystem（持久状态只进 SaveSystem 红线）。
3. **筹备·环境准备**：广场东侧逐日物件（搭木架 → 挂灯 → 摆花 → 立展台 → 贴告示），完成后永久保留。
4. **筹备·人际准备**：夏雅（策划）、镇长（协调 + 公告告示）、老周（旧照片）、小梅（花艺）、孩子（画）——对话 + 参与后世界变化。
5. **筹备·资源准备**：野花（小野花/蒲公英）/ 木材 / 矿石 / 鱼——"准备展览素材"；**采集循环首个世界变化出口**；贝壳后置不新增资源。
6. **当天演出（约 10 分钟）**：居民入场（老人带旧照片 / 孩子带画 / 夏雅查花）→ 看画 / 听故事 / 星空装置 → 夜晚灯光 + 河面倒影 + 灯塔回应。
7. **永久变化**：广场东侧艺术角（展台 / 展示牌 / 长椅 / 夜晚灯光）+ NPC 停留点 + 台词变化 + 商店新客人留言 + 港口偶尔陌生面孔。
8. **C 旅人艺术家**：当天实体；开幕 + 留下一件展品 + 一句评价；不做大量剧情；以后活动可回来（季节性原型，第一个被吸引回来的人）。

---

## 三、明确不做（本切片）

- ❌ 通用 EventPlan 框架 / 活动系统抽象（第二个活动以后再抽）
- ❌ 硬倒计时 / 限时挑战 / 失败惩罚
- ❌ 新增资源（贝壳等）
- ❌ 新大地图 / 大量新 NPC
- ❌ 直播 / 联网
- ❌ 复杂玩法（QTE / 体育小游戏等）

---

## 四、技术约束（零新系统）

| 能力 | 复用 / 落点 |
|---|---|
| 菜单 | 现有 DOM 面板范式（对齐 `shopPanel` / `backpackPanel`） |
| 状态 | SaveSystem 单字段（EventPlan 状态）+ `triggerOnce` 事件 |
| 对话 | `showDialogue` 注入（夏雅 / 镇长 / 老周 / 小梅 / C） |
| 演出 | 观星夜资产（星空装置 = 小型星光灯 / 玻璃瓶灯，**不做大特效**） |
| 光照 | 阶段3 时段光照（当天傍晚 → 夜晚） |
| 灯塔 | `setupLighthouseDistant` 现成（"远处灯塔回应"） |
| 物件 | 广场 Graphics（对齐中央广场生活化范式） |
| NPC | NPCSystem 日程（艺术角停留点） |

---

## 五、验收

1. **永久变化存在**：艺术角 + NPC 停留 + 台词变化 + 商店留言。
2. **第二次路过广场"不一样"**：
   - 完成前：空广场、NPC 少
   - 完成后白天：有人坐艺术角、有展示牌
   - 完成后夜晚：灯亮、河面反光
3. **完整闭环探针**：解锁 → 三类准备 → 当天 → 永久变化 → 存档（triggerOnce / SaveSystem 入档）。
4. `npx tsc --noEmit` EXIT=0；相关回归绿（Level 2 分级，改动涉及核心逻辑与存档）。
