# 任务卡：《秋日晒场》— EventPlan 第二个实例（v1.5，施工）

> 来源：制作人 2026-08-15 五项决策全拍板 + 微调（设计定稿 v1.1）｜状态：🟢 待施工
> 命名原则：本任务不是一个"庆典系统"，是在验证「生活循环 → 镇子恢复一种过去的生活 → 永久留下」。**核心立意：不是庆祝丰收，而是证明这里还有人在生活。**
> ⚠️ 前置：四大核心系统（采集/钓鱼/种植/城镇复兴）已闭环；春日集（`ch1_spring_fair`）、星光艺术展、玉米首次收获（`crop_corn_first_harvest`）已存在。

---

## 〇、一句话验收

玩家经历"收成时镇子重新想起晒场"的一次完整生活阶段，且**第二次路过晒场时感觉不一样**——它成了一处有生活的地方（晒架/鱼干架/收成展示/NPC 停留）。

## 一、目标

复用已验证的 EventPlan 模板（星光艺术展为第一实例），把「镇子因为玩家这一季的收成，重新恢复了旧晒场」做出来：

```
玉米成熟
 → 镇民讨论收成
 → 老张提起晒场
 → 恢复晒场（三类准备）
 → 全镇围桌吃饭
 → 灯塔回应
 → 青禾晒场留下
```

## 二、范围（对齐设计定稿 v1.1）

1. **EventPlan 状态（秋日晒场）**：目标 / 筹备三类 / 当天 / 永久；状态进 SaveSystem（`mapFlags` + `triggerOnce`，不新增顶层字段/不新增框架）。
2. **筹备·环境＝「晒场恢复」**：晒场设施（木架 / 竹席 / 晒篮 / 玉米串 / 南瓜 / 辣椒串 / 海边鱼干架），逐日/按进度叠加，完成后永久保留。
3. **筹备·人际＝三时代**：老张（过去·旧手艺）/ 夏雅（现在·旧照片）/ 阿风（未来·开放视角，**不站队商业**）——对话 + 参与后世界变化。
4. **筹备·资源＝「今年的收成」**：玉米 / 蔬菜 / 鱼 / 采集物——玩家是其中一部分，NPC 也准备。
5. **当天（≤ 春日集规模）**：傍晚晒场（老张整理晒架 / 夏雅摆照片 / 阿风搬东西 / 孩子跑闹）→ 夜晚海边长桌（灯笼/海风/食物/老人聊天）→ 高潮=人回来 + 远处灯塔亮一下。**无篝火**。
6. **永久变化＝「青禾晒场」**：晒架 + 鱼干架 + 收成展示 + NPC 停留 + 收成时令语音。**不加摊位**；**小孩用自然表现**（跑过 + 一句"别踩到晒好的东西"），不加互动点；**不做每年自动举办**。
7. **完成瞬间**：世界反馈句「多年以后，青禾镇又晒起了今年的收成。」→ UI「青禾晒场已恢复。」

## 三、明确不做（本施工）

- ❌ 复杂玩法（QTE/计分/挑战）
- ❌ 倒计时 / 限时 / 失败惩罚
- ❌ 新增资源 / 新增地图 / 新增常驻 NPC
- ❌ 季节系统 / 年复一年活动
- ❌ 篝火
- ❌ 摊位
- ❌ 小孩互动点（用自然表现）
- ❌ 商业矛盾具象化（阿风本切片不站队）

## 四、技术约束（零新系统）

| 能力 | 复用 / 落点 |
|---|---|
| EventPlan 状态 | 复用 `mapFlags` 字段 + `EventManager.triggerOnce`（对齐艺术展 artShow 字段范式） |
| 三类准备 | town create 状态渲染 + showDialogue 注入（对齐 `buildArtShowDialogue`）+ 素材箱交付（对齐 `artShowBox`） |
| 当天 | 春日集灯火/剪影视觉语言（`buildSpringFairFX` 范式）+ 海边长桌（零素材 Graphics）+ 灯塔（`setupLighthouseDistant`） |
| 永久地点 | 青禾晒场 Graphics + NPC 停留 + 收成时令语音（读档保持） |
| 触发 | `ch1_spring_fair` + `crop_corn_first_harvest` → 软触发（进 town 傍晚） |

## 五、验收

1. **永久变化存在**：青禾晒场（晒架/鱼干架/收成展示/NPC 停留/收成时令语音），读档保持。
2. **第二次路过晒场"不一样"**：完成前广场空；完成后晒场有晒的东西、NPC 停留、收成时令台词。
3. **完整闭环探针**：触发 → 三类准备 → 当天 → 永久 → 存档（triggerOnce / mapFlags 入档，读档保持）。
4. `npx tsc --noEmit` EXIT=0；相关回归绿（Level 2 分级）。

## 六、子任务拆分（建议顺序）

1. EventPlan 状态（mapFlags：`dryyard_*` 字段）+ 触发判定（玉米收获 + 春日集后进 town 傍晚软触发）
2. 「小镇计划」面板登记（秋日晒场 · 筹备中/已举办；世界状态展示）
3. 筹备·环境：晒场恢复（逐阶段 Graphics + 完成永久保留）
4. 筹备·人际：老张/夏雅/阿风 三时代对白 + 参与世界变化
5. 筹备·资源：素材箱「今年的收成」（玉米/蔬菜/鱼/采集物）
6. 当天演出（傍晚晒场 → 夜晚海边长桌 → 灯塔回应，≤春日集）
7. 永久变化：青禾晒场（晒架/鱼干架/收成展示 + NPC 停留 + 收成时令语音）+ 完成瞬间文案
8. 探针 `probe-dryyard.mjs` + 验收截图
