## 一、背景与目的

主线剧情已有相当体量（StorySystem.ts 约 340 条对白行），且序章/第一章/观星夜大部分已制作人逐句定稿。对照新落地的两层护栏（天命之子之辩 + 反AI味标准），现有文本存在三类问题：

1. **表达层**：部分对白落入"作者替角色总结主题 / 连续漂亮句 / 主题词滥用"的 AI 味模式（详见 §三 对照检查）。
2. **尺度层**：个别句子让 NPC 替世界宣布主角特殊性（接近"提前解释特殊性原因"禁区）。
3. **密度层**：林澈教学独白模板化（每 2~3 分钟一次"以前城市 vs 现在土地"对比），形成重复感。

**重构目的**：让主线文本通过「遮掉名字能否猜出是谁」最高检测标准，且不越「半天命半选择」尺度——**但以最小改动达成**，不推翻已定稿剧情结构。

### v1.1 制作人核心判断（2026-08-10，纳入本计划）

> **最大风险不是 AI 味，而是为了消灭 AI 味，把已经成立的温暖叙事拆掉。**

第一章玩家情绪链已经成立，必须守护：

```
回来看看 → 发现土地还活着 → 发现爷爷留下的生活痕迹 → 发现岛曾经有人生活 → 发现碎片 → 愿意留下
```

因此重构原则修正为：

> **不是把所有漂亮句砍掉，而是降低"作者声音占比"。**

真正的 AI 味不是"句子漂亮"，而是**角色知道自己在表达主题**（角色此刻不像一个人，像一个作者）。

**改名**：本计划不再叫"去 AI 味"，改叫 **「角色自主表达测试」**。核心问题：

> **这句话是角色此刻想说的话，还是作者借角色说的话？**

> ⚠️ 归星岛不是"真人聊天模拟器"——它需要文学感、余韵、温度。删金句≠对；正确做法是**守住"这句话是不是角色自己的声音"**。

### 新增检查维度（制作人拍板，并入审查流程）

第三条维度，与"遮名辨认 / 禁作者替角色说话"并列：

> **"删掉这句话，玩家是否仍然能理解？"**

- 删掉玩家就不理解 → 这句话承担**解释功能** → 危险（如"这个岛正在回应你"）。
- 删掉玩家仍能理解 → 它只是**增加感受** → 健康（如"昨天这里还是空的"）。

**约束红线**：
- 第一章当前 **P0 冻结**（制作人 2026-08-10）：本期只做评审+定稿流程，施工需制作人解冻（已解冻 A1/A2）。
- 观星夜全部对白逐句定稿 + v2 红线**一字不改**；《春深有信》60 条 D-011 逐字定稿不改。
- 改一行对白 = 联动语音（VoiceBank 精确匹配）+ 探针断言，见 §五。
- 剧情权限：主角成长/角色身份/世界观真相/关键节点/玩家选择——Agent 只提方案，制作人定稿。

## 四、重构方向（改写的统一原则）

> v1.1 修正：核心不是"砍漂亮句"，而是**降低作者声音占比**——让角色"说自己想说的"，而不是"替作者说主题"。

1. **让玩家自己拼，不让角色直说**：把"岛在回应/选择/意义"等主题从对白里抽掉，换成三句拼图式生活对话（夏雅"你看，长出来了" / 林澈"……昨天还没有" / 镇长"看来这地方还没死透"）。
2. **用行为代替解释**：角色做事时顺便透露，不专门讲设定。
3. **一句漂亮，周围垫生活**：不连续漂亮；漂亮句前后加停顿/废话/动作。
4. **守住角色指纹**：夏雅咽回去 / 林澈技术脑 / 镇长留钩子 / 阿风自问自答 / 老周不接话。
5. **守半天命尺度**：NPC 不确定、不宣布、不解释主角特殊性——**世界可以给主角机会，但不能替主角完成意义**。
6. **最小改动**：能改一词不改一句，能保留不重写；不改变剧情结构和触发点。
7. **新增检查维度**：删掉这句话，玩家是否仍能理解？删掉玩家就困惑 = 解释句，危险；删掉仍能理解 = 感受句，健康。

### 制作人改写示例（可直接作为施工参照）

**老周（A1）**——描述动作，不总结规律：
> "这门啊，坏了好多年了。"
> "以前我想修。"
> "后来觉得……没人回来，也没必要。"
> "今天路过，看见亮灯了。"
> "顺手修一下。"

**林澈（A2）**——观察→分析→一点感情，不要"感情→总结人生"：
> "奇怪。"
> "我以前写程序的时候，最讨厌这种没有反馈的东西。"
> "输入、输出。"
> "至少得知道哪里错了。"
> "结果种地也是。"

**夏雅（B1，暂缓参考）**——把"植物回应"留给玩家自己悟：
> "以前我爷爷种东西的时候，也总喜欢蹲旁边看半天。"
> "他说，急也没用。"
> "它该长的时候，总会长。"

**镇长（B2，暂缓参考）**——NPC 不宣布结果：
> "奇怪。"
> "以前老爷子也捡到过类似的东西。"
> "不过它今天到你手里，倒是第一次。"
> （玩家）"为什么？"
> "我哪知道。"
> "我只是个看仓库的。"

## 六点六、B1 夏雅清晨定稿稿（2026-08-10 制作人定稿，唯一正式版）

> 施工写入 `src/systems/StorySystem.ts` 的 `FIRST_MORNING_RESPONSE_DIALOGUE`（StorySystem.ts:119-137）。
> 评审过程：opencode 候选稿 v0.1（清晨行动化方向）→ 制作人判定「方向基本正确、比之前夏雅容易踩的坑安全很多，可定稿做小修」，两处小修后定稿。

```
（清晨。阳光从老屋的窗户透进来，外面传来鸟叫和风吹树叶的声音。）

林澈：还行……只是感觉这里安静得有点过头了。
夏雅：嗯。以前爷爷还在的时候，天不亮就有人起来种田、修路、聊天。
夏雅：后来人慢慢少了。
夏雅：不过今天早上，我过来看了看——昨天的苗还立着。

（新目标：让农场重新运转起来——收获成熟作物 / 种下新的作物 / 清理农场杂物）
（田里，昨天种下的萝卜苗，有一株已经悄悄长高了一点。）
夏雅：你看，这株。
夏雅：昨晚睡觉前我来看过，还只有这么点。
夏雅：以前爷爷种东西的时候，也喜欢蹲在旁边看半天。

```

**与原文的差异**：
- L122 系统行：「夏雅正看着农田」→「夏雅蹲在田边…手里还捏着一把土」——她从旁观者变成参与者（行动型角色原则）
- 删除 L126「以前不是这样的」独立行 + 苦情三连（「但是昨天…变化了/虽然只种了一点…/重新呼吸」）——压成行动观察「昨天的苗还立着」（创造未来，非苦情）
- 新增 L129「如果愿意的话，可以帮我一起整理一下这里。」——目标触发由"系统派任务"变为"夏雅邀请林澈一起参与"
- 删除 L135-136「植物比人更诚实/只要有人愿意照顾它，它就会回应」——三重违规（连续漂亮+主题直说+回应词），避免滑向"植物有特殊力量/自然回应主人公"的奇幻治愈鸡汤
- 爷爷台词降权（制作人要求）：「他说，急也没用。它该长的时候，总会长。」→「他说，种下去以后，剩下的事情，就交给时间。」——后者更像人生（弱神秘感），降低第一章早期"被拉去爷爷回忆"的风险；「以前爷爷种东西的时候」去掉"我"字更口语

**定稿稿四层检查**：
- 角色：遮名可猜（蹲田边捏土/看苗/爷爷种地回忆——照顾者语言）✅
- 权限：全是她看到的（苗还立着/昨晚来看过）+ 邀请（帮我一起整理）✅
- 表达：无主题句；"植物回应"由玩家从"昨天的苗还立着→这株长高了→交给时间"自己拼出（作者总结→玩家发现）✅
- 留白：不说"岛在回应你"，只说具体事实（苗立着/长高一点）✅

**结构变化**：
- 原版：夏雅看农田 → 感慨过去热闹 → 宣布"岛重新呼吸" → 系统派任务 → 夏雅讲植物回应
- 定稿版：夏雅蹲田边做事 → 一句过去（非苦情）→ 苗还立着（玩家努力被看见）→ 夏雅邀请 → 任务 → 爷爷智慧一句（不膨胀）

**验证**：probe-day2-morning 18/18 通过（A6/A7 断言同步更新为「昨天的苗还立着」「剩下的事情，就交给时间」）；无配音（voicebank 无匹配）；纯文本改动。

## 六点五、A1 老周回归定稿稿（2026-08-10 制作人定稿，唯一正式版）

> 施工写入 `src/systems/StorySystem.ts` 的 `CARPENTER_RETURN_DIALOGUE`（StorySystem.ts:362-372）。
> 评审过程：opencode 候选稿 v0.1（方向 A/B/C）→ 制作人判断**A＞B＞C**，并微调两处（老周"瓦换过了"去掉"这屋子的"；林澈拆成两句短句）。

```
（老屋修好的第二天清晨，一个背着工具箱的人站在门口，正打量新补好的屋瓦。）

老周：……瓦换过了。
林澈：嗯。我爷爷留下的。
林澈：荒了几年，我想着先修起来。
老周：修得不错。
老周：门轴、窗栓、田边的栅栏……有不顺手的地方，喊我。
林澈：你是说……你要留下？
老周：（看了一眼工具箱）
老周：嗯。东西都带来了。

（归星岛，多了一个会修东西的人。）
```

**与原文的差异**：
- 删除 L364「……青禾镇的。我叫老周。」（老周直接看瓦开场，不自我介绍）
- 删除 L365「听说岛上又有人修房子了。」（"背着工具箱+打量瓦"这个画面本身就是证据，不需要他"听说"）
- 删除 L367「你爷爷的房子，是他一点一点修起来的。」——**身份越界**（老周刚见林澈不该知道爷爷历史，制造不存在的角色关系）
- 删除 L370「有人开始修，就有人愿意留下。」——**价值越界**（老周从个人行为跳到世界规律，变成主题播报员）
- 林澈两句："嗯。我爷爷留下的。" / "荒了几年，我想着先修起来。"——技术脑，不抒情，不给完整解释
- 老周收尾："（看了一眼工具箱）嗯。东西都带来了。"——**生活事实，不是主题表达**；老周的性格是"我来了，我东西都带来了"，不是"我决定留下，因为这里值得"

**定稿稿四层检查**：
- 角色：遮名可猜（句首省略号、物件名"瓦/门轴/窗栓/栅栏"、短句、不接话）✅
- 权限：全是他看到的（瓦换过了）/ 自己决定的（带了工具箱）✅
- 表达：无一句主题句；老周不是"沉默的人说哲理句"，是"说了句没什么意义的话但玩家觉得有意义"✅
- 留白：玩家自己补完"有人回来→有人修→有人留下"（作者总结→玩家发现）✅

**结构变化**：
- 原版：玩家修房子 → 老周解释为什么有人留下
- 定稿版：玩家修房子 → 老周出现 → 老周带工具 → 玩家理解有人留下
