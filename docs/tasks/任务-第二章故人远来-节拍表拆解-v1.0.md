## 〇、一句话验收

玩家经历"镇上有人陆续回来，并且他第一次发现自己和这些人有了关系"的一条完整人线；
林澈从"我在这个镇住下"走到"这岛上有等我一起吃饭、聊天、修东西的人"。
**全章只有一个主悬念（夏雅为什么认识那盏灯）+ 一个远景钩子（海平线黑点），其余全部降级彩蛋。**

---

## 一、制作人三条硬护栏（拍板，不可违反）

1. **夏雅身世只揭"一层"**：玩家只知道她搬走过、又回来了。父亲、灯塔、童年经历**一律不往下解释**。
   章节结束时玩家状态必须是：**"我知道她为什么回来，但我还不知道她为什么认识那盏灯。"**
2. **夜谈是情绪高潮，不是剧情高潮**：信息量控制到最低，重点放在停顿、递东西、坐着、看海、问一句、答一句。
   保留三个动作骨架：「怎么又回来了？」「这儿有人认识我。」「这扳手是不锈钢的？」
3. **节拍表不膨胀**：已经闭环的七节拍（灯塔亮 → 夏雅 → 老船长 → 旅人 → 夜谈 → 夏雅秘密 → 黑点）只做**可制作事件化**，不增加第八、第九个剧情机关。

## 四、节拍 1 · 灯塔一直亮着（轻量递进）

> ⚠️ **衔接说明（关键）**：灯塔远景在第一章春日集时已实现并读档保持（`setupLighthouseDistant` + `markRestored('lighthouseLit')` + 首映台词「西边的灯塔……我还以为，它再也不会亮了」）。
> 第二章**不重新点亮灯塔**，只做"从亮一下 → 天天亮着 → 村民讨论"的递进。

| 字段 | 内容 |
|---|---|
| **触发条件** | 第一章完成（`ch1_spring_fair` 已触发 + `lighthouseLit` 已恢复）· 玩家白天经过农场西侧或进 town |
| **玩家看到什么** | （已有：远处塔灯持续亮 + 光束扫动，读档保持）新增：无新视觉，仅村民反应变化 |
| **玩家做什么** | 什么都不用做，路过即可（不触发任务、不给提示） |
| **NPC 说什么** | 闲聊池新增（一次性）：<br>阿风："西边那塔，这几天好像天天亮。"<br>老周：（抬头看一眼）"……嗯。有人回来了。"<br>（说完没人接话，各干各的） |
| **世界发生什么** | 无结构性变化（塔已经一直在亮） |
| **存档状态** | `triggerOnce('ch2_lighthouse_talked')` 记录闲聊触发（可重复听则不记） |
| **下一节拍条件** | 本节拍触发后，白天在 town 见到夏雅 → 进入节拍 2 |

**台词要点**：这句"有人回来了"是**全章主题的第一次出声**，但说的人不当回事——老周说完就不解释了。玩家要自己把它和后面的夏雅/老船长接起来。

## 五、节拍 2 · 夏雅的身世（只揭一层）

| 字段 | 内容 |
|---|---|
| **触发条件** | 节拍 1 后，白天在 town 遇到夏雅（修钟事件，对齐第一章夏雅支线范式） |
| **玩家看到什么** | 广场老钟摆停了很多年，钟前人站着夏雅，梯子/工具箱在旁 |
| **玩家做什么** | 靠近交互「帮忙扶一下梯子」或「递工具」（轻交互，复用现有交互模式） |
| **NPC 说什么** | 修着修着，夏雅说漏一句：<br>夏雅："我家以前……也走过船。"<br>玩家（选项或自动追问）："你家以前不在岛上？"<br>夏雅：（岔开）"先把钟修好吧。老人们听它报时，听惯了。"<br>……钟修好，报时。她站在钟下听了一阵：<br>夏雅："……走得真准。" |
| **世界发生什么** | 老钟恢复报时（此后 town 每整点响一次钟声，环境音，代码触发） |
| **存档状态** | `mapFlags.ch2_clock_fixed = true`（永久：老钟报时保持）+ `triggerOnce('ch2_xiya_clock')` |
| **下一节拍条件** | 本节拍完成后，某天码头出现旧船 → 进入节拍 3 |

**台词要点（硬护栏 1 执行）**：
- "我家以前也走过船"到此为止，**不解释**搬到哪、为什么走、什么时候回来。
- 她的身世藏在修钟行为里：她修的其实不是钟（"走得真准"是修自己）。
- 玩家此时该有的状态：「这人有故事，但我不急，她也不急」——呼应硬护栏"只揭一层"。

## 六、节拍 3 · 码头有人回来

| 字段 | 内容 |
|---|---|
| **触发条件** | 节拍 2（`ch2_clock_fixed`）后，某天（白天或傍晚均可）经过码头区 |
| **玩家看到什么** | 环境变化一次：木栈道补过一角（颜色/纹理略新）、船头挂起一盏旧船灯；靠着一艘旧船，老船长蹲在船边修船（补船板/抹桐油） |
| **玩家做什么** | 靠近交互「搭把手」（递木楔/扶一下） |
| **NPC 说什么** | 老船长："修好了，就能再出去一趟。"<br>林澈："您要出海？"<br>老船长："不一定。船不响了，心里才踏实。"<br>（之后码头开始有人走动——晾网、搬筐、蹲着抽烟，NPC 行为池轻量 +1 人） |
| **世界发生什么** | 码头从"废弃"变"有人收拾"：栈道补丁 + 船灯 + 走动的人影（环境叙事，零资源） |
| **存档状态** | `mapFlags.ch2_pier_repaired = true`（永久）+ `triggerOnce('ch2_captain_arrived')` |
| **下一节拍条件** | 本节拍后，任何一天傍晚可能刷出旅人 → 进入节拍 4 |

**台词要点**：
- 老船长语言指纹：短，硬，不解释。"船不响了心里才踏实"——玩家自己琢磨他为什么不真出海。
- 他修船不为出海。这整句话就是人物简介。

## 七、节拍 4 · 奇怪的旅人（降级气氛）

| 字段 | 内容 |
|---|---|
| **触发条件** | 节拍 1 后至夜谈前，**随缘触发**三次（随机某天傍晚，town/farm 边缘，错开日期） |
| **玩家看到什么** | 一个陌生身影，三次出现，三次即走（不做特殊光照/特效，就是个奇怪的路人） |
| **玩家做什么** | 路过即可（不可交互、不可对话、不可追问） |
| **NPC 说什么** | 第一次（码头边看海）：<br>旅人：（自言自语）"这海，夜里看着挺静的。"<br>第二次（集市角落逗猫）：<br>旅人：（对猫说）"今晚月亮落得早。"<br>第三次（遇到林澈，停下，看了他一会儿）：<br>旅人："……你身上，也有那个味道。"<br>说完就走，不回头 |
| **世界发生什么** | 三次出现期间 NPC 闲聊池可能提一句"最近有个生面孔"（可选，轻） |
| **存档状态** | `triggerOnce('ch2_stranger_1'/'ch2_stranger_2'/'ch2_stranger_3')` 分别记录三次 |
| **下一节拍条件** | 三次都出现过 + 节拍 2/3 完成 → 夜谈触发窗口开启 |

**台词要点（v0.2 减量执行）**：
- **前两次必须是"一个奇怪的路人"**——话可以理解成天气闲聊，玩家可能注意，但不会立刻判定"这就是神秘角色"。
- 只有第三次的"也"字是钩子：让玩家隐约想起神秘少女那句"你身上有那颗星的味道"，但**不确定、可遗忘**。第三章才解释。
- 旅人不交互、不解释、不回头——**她是来制造气味的，不是来提供信息的。**

## 八、节拍 5 · 故人远来（码头夜谈）— 全章真正高潮

> **定位（制作人拍板）**：情绪高潮，不是剧情高潮。人物结算，不是信息发布会。
> **信息量控制到最低**：全场只允许一个因果关系的事实交代（老船长"你爸那年船都订好了"→ 夏雅"嗯，搬出去过两年"），其余一律不解释。

| 字段 | 内容 |
|---|---|
| **触发条件** | 节拍 2 + 3 + 4（三次）完成后，**某天傍晚自动软触发**（进 town 或走过码头区时）：码头边点起一盏灯 |
| **玩家看到什么** | （克制演出，≤ 春日集规格）码头边一盏灯，老船长、夏雅、林澈围坐。远处海黑，只有灯下一点暖光。无篝火 |
| **玩家做什么** | 走近 → 坐下（自动进入演出）。全程无选项/无分支，玩家只是听、偶尔接一句 |
| **NPC 说什么**（演示骨架，逐句落地前过审） | 老船长："以前这码头，一天好几条船。卸货的、进货的、走亲戚的。"<br>"后来船少了。再后来，大家宁愿在城里，也不回来。"<br>"你爷爷当年想修这条道。没修成。"<br>（看向夏雅）"你爸那年也是，船都订好了。"<br>夏雅：（半天）"嗯。搬出去过两年。"<br>**林澈："……怎么又回来了？"**<br>**夏雅："这儿有人认识我。"**<br>（停顿。夏雅从包里掏那把旧扳手，递过去）<br>夏雅："搬走那天，我把我爸锁在工具箱里的这个带出来了。"<br>"总觉得，哪天还会用上。"<br>林澈接过，看了一会儿：<br>**林澈："这扳手是不锈钢的？"**<br>夏雅："嗯。"<br>林澈：（还给她，没再说话）<br>（沉默一阵，老船长：）<br>"你们还愿意回来，这岛就没白等。" |
| **世界发生什么** | 演出结束后无结构变化（夜谈本身即世界回应）；老船长自此在码头停留成为常驻环境剪影 |
| **存档状态** | `triggerOnce('ch2_night_talk')` + `markRestored('ch2_pier_lit')`（灯舷长期挂起，读档保持） |
| **下一节拍条件** | 本夜谈结束，人散 → 进入节拍 6（同夜，可连续演出） |

**不解释清单（硬性，全场零解答）**：
- 灯塔到底是什么 ✗
- 海流是什么 ✗
- 神秘旅人是谁 ✗
- 神秘少女是谁 ✗
- 星之碎片是什么 ✗
- 爷爷当年到底发现了什么 ✗

**制作要点（把信息量压到最低）**：
- 多用停顿：每个转折（递扳手前、问"怎么又回来了"前、还扳手时）都要有 1.5s+ 的静场。
- 动作 > 台词：坐、看海、递东西、还回去，这些动作是整场戏的骨架。
- **三个不可改的动作**：① 林澈问"怎么又回来了"（节奏点）② 夏雅答"这儿有人认识我"（全章核心台词）③ 林澈问"这扳手是不锈钢的"（林澈指纹，回答情感问题的方式是问扳手）。
- 人不总结、不拥抱、不说"感谢你回来"。关心是递东西、让座、留一句"你早点睡"。

## 九、节拍 6 · 夏雅的秘密（主悬念留白）

| 字段 | 内容 |
|---|---|
| **触发条件** | 节拍 5 结束后（同一夜，人散后），夏雅没走 |
| **玩家看到什么** | 夏雅站在码头边，朝灯塔方向看。夜，海上远处塔灯一个暖点 |
| **玩家做什么** | 走近（自动进入演出，无选项） |
| **NPC 说什么** | 夏雅："灯亮了。"<br>林澈："嗯。"<br>夏雅：（朝灯塔方向抬抬下巴）"那盏灯……我好像认识它。"<br>林澈："……什么意思？"<br>夏雅：（摇摇头）"没事。可能小时候见过。走了。"<br>（走两步，又停下）"你早点睡。" |
| **世界发生什么** | 无（纯对白留白） |
| **存档状态** | `triggerOnce('ch2_xiya_secret')` |
| **下一节拍条件** | 本节拍完成 → 返回庄园或任意地图 → 节拍 7 远景收尾 |

**台词要点**：
- 悬念挂在**一个人**身上（夏雅认识那盏灯），不是世界观。这是它区别于谜语的核心。
- "可能小时候见过"——她一秒钟内自己把话收回去。玩家记住的是她的停顿，不是"答案"。
- "你早点睡"是她的关心方式：从灯塔的事上岔开，只说这句。
