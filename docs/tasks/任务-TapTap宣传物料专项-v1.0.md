# 二、专项目标

## 核心目标

---

# 三、核心定位重新确认

## 错误定位（避免）

❌ 一个像素种田游戏

问题：市场同质化严重。玩家容易联想到 Stardew Valley / 普通模拟经营 / 休闲农场，无法体现差异。

## 正确定位

> 文案评审更新（2026-08-08，GPT 顾问意见后制作人拍板）：第一屏先卖"回到荒岛让一个地方活起来"的游戏幻想，再卖 AI 时代主题；去掉"慢节奏"标签。

### 核心一句话

> 一个被 AI 时代推着前进的年轻程序员，回到爷爷留下的荒废小岛，种田、修复、陪伴这里的人，让归星岛重新迎来星光。

### 核心卖点

| 卖点 | 关键词 |
|---|---|
| 卖点1：现代职业人的回归故事 | AI时代 / 城市压力 / 重新寻找生活 |
| 卖点2：让一个地方重新活起来 | 修复岛屿 / 改变环境 / NPC生活变化 |
| 卖点3：温暖的人际关系 | 夏雅 / 村民 / 旧日记忆 / 小岛故事 |
| 卖点4：轻松治愈的日常生活 | 种田 / 探索 / 观星 / 海风 / 日常（**不写"慢节奏"**） |

# 四、TapTap 页面整体结构规划

## 1. 首屏主视觉（最高优先级）

目标：玩家第一眼产生"这个地方我想进去看看"。

### 主图内容
主体：林澈 + 夏雅
场景优先级：① 海边观星 ② 黄昏归星岛 ③ 老屋与海风
画面表达：人 + 地方 + 情绪（❌ 单角色立绘 / 单纯风景 / 功能截图）

### 文案
《归星物语》 / Return to the Star Island
副标题：**当生活只剩下效率，你是否还记得自己为什么出发？**

## 2. 游戏简介优化

避免"种田模拟经营游戏"。

### 推荐简介（P0-01 定稿版，2026-08-08 制作人拍板）
> 一个被 AI 时代推着前进的年轻程序员，回到了爷爷留下的荒废小岛。
> 种下一片田，修复一座岛，也重新寻找自己想留下的理由。
> 当第一颗种子发芽、第一条路重新修通、第一次有人在小镇里笑着打招呼——归星岛，重新迎来了星光。

### 长介绍结构
第一段：故事钩子 → 第二段：玩法介绍 → 第三段：情绪价值

# 十、验收标准

陌生玩家浏览商店页后能回答：

- **Q1 这是什么？** → 一个关于回乡、种田、修复小岛的治愈冒险游戏。
- **Q2 怎么玩？** → 种植、探索、帮助居民，让岛屿恢复。
- **Q3 为什么特别？** → 它讲述现代人在 AI 时代重新寻找生活意义的故事。
