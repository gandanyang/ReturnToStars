# 《归星物语》昼夜·Action Time 实机试玩清单 v1.1

> 状态：📋 实机走查清单（2026-08-16 制作人拍板：先实际试玩时间成本，不改代码）
> 背景：Action Time 已从「采集+对话」扩展到种植——现涉及 采集/对话/锄地/播种/浇水/收获 六类动作。
>   时间成本（暂定非最终）：采集 10 / 对话 10 / 锄地 3 / 播种 3 / 浇水 2 / 收获 2（分钟）；
>   体力（仅成功扣）：锄地 2 / 播种 1 / 浇水 1 / 收获 1；现实 1 分 = 游戏 2 小时；21:00 轻提醒、22:00 强制结束。
> **实现原则（已确认）**：动作成功 → 才扣体力 → 才推进时间；失败不消耗任何东西。**必须保留。**
> 目的：验证「一个普通日子」的完整节奏是否顺——种田会不会变时间黑洞 / 体力+时间是否双重惩罚 / 种完田后还愿不愿意出门探索。

---

## 〇、四个体验维度（本次核心框架）

**自然**：下雨 → 想不想去后山 → 蘑菇 → 形成记忆
**时间**：行动推进是否让一天自然结束（而非催促玩家）
**种田**：一小块农田的完整操作是否占用合理时间
**生活**：种完田以后，玩家还有没有心情去镇子、河畔、森林转一圈

> **最后一个最重要**：目标不是"把农田管得最有效率"，而是「种完田以后，我还愿意出去看看今天青禾镇发生了什么」。

---

## 一、三大验证点（原有，保留）

① 一天能不能自然完成 3~5 件事？  ② 时间推进=生活感还是赶时间焦虑？  ③ 玩家会不会算账？
- [ ] 做不完 / 想做的事被"来不及"挡掉？
- [ ] "天色晚了该回去。" 而非 "又浪费十分钟。"？
- [ ] 出现"先别去森林、先对话"式计算？（→ 偏离轻生活）

---

## 二、核心场景 · ⭐ 一天节奏压力测试（新增，最重要）

> 单独作为压力测试，不顺便体验。**完整跑一次**：

```
起床 → 锄 3 格 → 种 3 格 → 浇 3 格 → 采集几次 → 和 2~3 个 NPC 对话 → 去森林探索 → 晚上回家
```

估算成本：锄 3×3=9 + 种 3×3=9 + 浇 2×3=6 = **24 游戏分钟**（光种这一小块）＋ 采集＋对话。

### 三个核心观察（对应三个风险）

- [ ] **种田有没有变成"时间黑洞"？** 玩家是否"我种几个格子就浪费半天了"？（若会→时间成本过高）
- [ ] **体力+时间有没有互相重复惩罚？** 两个系统叠太重→"我今天什么都干不了"？（我们要的是**机会成本**，不是双重处罚）
- [ ] **种田节奏有没有压过探索？** 若每天"种田→浇水→没时间出门"→ 与"青禾镇生活探索"方向冲突；若"种田只是一小段→自然出门"→ 正确。

## 三、原有三种试玩场景（保留）

**A 普通一天** `早上 → 农田 → 镇子 → 森林 → 回家`
**B 探索一天** `采集很多次 → 对话几个 NPC → 晚上回家`
**C 悠闲一天（最重要）** `不追任务，只散步、采集、聊天、看环境`
- [ ] 10 分钟/次 + 种植成本下，悠闲玩法仍成立？（C 是 10 分钟/次是否好的试金石）
