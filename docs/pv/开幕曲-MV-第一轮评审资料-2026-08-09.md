## 二、MV 感三大检查项（对应拍板问题 1）

### 1. 角色锚点（最高优先级——人别漂移）

- **男主**：深棕短发 + **细黑框眼镜**（标志性）+ 浅色挽袖衬衫。
  - A02（近景）/ A05 / B04 / B05 / C01 / E05：是否同一人？黑框眼镜在远景（A01 剪影、E05 背影）可不出现，但 B04/C01/E05 应能认出。
  - ⚠️ 重点核对：眼镜是否全程同款式；衬衫颜色是否随镜头跳变（浅色→其他色）。
- **夏雅**（D04 首现）：软橙金中长发 + 小发夹 + 浅色短外套。
  - ⚠️ 这是她整支 MV 唯一镜头，确认形象符合分镜定义，后续复兴版可复用同一锚点描述。
- **手部**（C05 播种、C07 幼苗）：生成易畸变点，重点看手指/指节。

### 2. 色温曲线（对应拍板问题 1）

预期走向，请按序号连看是否成立：

```
A01-A02（冷蓝灰，压抑）→ A05（第一盏暖灯）→ B01-B04-B05（黄昏暖金渐深）
→ C01（晨光金）→ C05-C07（绿意上升）→ D01（生命色爆发）→ D04（午后暖）
→ D07（暖色峰值）→ E05-E06-E07（蓝紫夜 + 暖金灯海，收束）
```

### 3. 镜头连续性（MV 感核心）

- **城市→旅程→岛**：A01/A02 现代城市 → A05/B01 车站列车 → B04/B05 登岛，地点过渡是否顺。
- **老屋同栋**：B05（远景）→ C01（推门）→ C05/C07（背景老屋虚化）应同一栋。
- **首尾呼应**：A01「冷灰城市独影」→ E07「星空下独影」，从「城市孤独」到「岛上仰望」是否形成闭环。
- **时间线**：深夜（A）→ 黄昏（B）→ 次日清晨（C）→ 白天/午后（D）→ 夜（E），昼夜是否合理。

## 四、拍板问题（对应 CURRENT_TASK 下一步）

1. **15 张连起来有没有 MV 感？**（角色锚点不漂移 + 色温曲线成立 + 镜头连续）
2. **哪些镜头重做？** 重做时保持同 seed 还是换 seed？（建议：只重做判定 ✗ 的镜头，其余不动）
3. **哪种画风保留？** anima_turbo + yourname LoRA 这一档是否满意；是否要试不同 LoRA/风格对照。
4. **林澈 / 夏雅表现是否需要调整？** 男主"疲惫返乡青年" vs 更清爽；夏雅镜头是否加戏。
5. **是否确认后进正式 MV？** 扩充到完整分镜（25-30 镜）并进入正式制作（需先过本批画风验收）。

## 五、重做建议参数（供制作人勾选）

- 单镜重做：复制对应 `tmp/mv_pNN.txt`，改提示词局部（角色/光照/构图），固定 seed 重跑。
- 批量重做：调统一前缀（如换 `anime key visual, clean lineart`）或换 LoRA，15 镜全部重跑。
- 画风对照：建议先出 2-3 张同镜头不同风格（同一 seed，只换风格词）做 A/B 对比再定。
- 加戏：若夏雅要两个镜头，建议 D04 花径 + 新增 D05 与男主同框（复用双人锚点句）。
