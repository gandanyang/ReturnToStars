## 三、资产表使用方式

1. **制作 PV 前**：按本表核对所需素材齐备与否 → 缺口走 `录制素材规划` 补录或 `音乐企划方向` 补创作
2. **每次新增宣传资产**：同步登记本表（新增一行 + 路径 + 用途）
3. **每完成一个 PV/Trailer**：在 §一.6 登记产物
