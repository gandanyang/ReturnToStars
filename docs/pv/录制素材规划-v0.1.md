# 《归星物语》录制素材规划 v0.1

> 状态：📋 预研阶段（2026-08-09 制作人开启《品牌化宣传资产预研》）
> 定位：回答"**我要录什么视频？**"——未来 PV / Trailer / 商店页视频的实机镜头清单
> 关联：`docs/pv/PV视觉叙事方向-v0.1.md`（镜头服务于三类 PV）、`docs/pv/宣传素材资产表-v0.1.md`（缺口追踪）
> 场景 key（实查）：`station` 车站 / `farm` 农场 / `town` 青禾镇 / `forest` 森林 / `house` 老屋 / `elder_house` / `mine` 矿洞 / `gate` 庄园大门

## 一、录制目标

为三类 PV（游戏主题 / 林澈角色 / 夏雅角色）与商店页视频提供**实机镜头素材库**。镜头按四类规划：

- **A 开场类**：讲"回来"——车站、海岛、老屋、第一次探索
- **B 生活类**：讲"活着"——种田四件套、农场日常
- **C 情感类**：讲"人"——夏雅剧情、NPC、老屋、观星夜
- **D 世界变化类**：讲"复活"——修复前后、青禾镇、农场回暖

> 录制原则：**实机优先**。像素风实机画面本身就是作品的质感；AI 画面仅用于无法实机的缺口（如城市段）。
> 每段录 10-20s raw，剪辑时再切。宁可多录，不要漏镜头。

## 二、A 开场类

### A1 火车到站
```
镜头名称：火车到站
场景：station（车站）
时间：白天（默认）
角色：林澈
动作：到站 → 下车 → 左右张望（站台起步）
推荐时长：8-12s
用途：游戏主题 PV 开场 / 林澈 PV 开场
备注：新档开局即触发；可反复录（reload 回 station）
```

### A2 海风与初见
```
镜头名称：海风与初见
场景：farm（农场海边/入岛段）
时间：黄昏（debug.setTime(17, 30)）
角色：林澈
动作：角色站立，镜头缓慢移动（camCenterOn 平移），海风粒子
推荐时长：10-15s
用途：游戏主题 PV "岛" 段落 / 林澈 PV
备注：需要"镜头慢移"能力——见 §五 开发者模式方案
```

### A3 老屋初见
```
镜头名称：老屋初见
场景：house（老屋）或 farm 老屋
时间：黄昏→夜晚过渡
角色：林澈
动作：推门 → 屋内环视 → 停在旧物前
推荐时长：10-12s
用途：林澈 PV "归属" 段落 / 主题 PV
备注：室内小地图 zoom2，画面信息密度高
```

### A4 第一次探索
```
镜头名称：第一次探索
场景：farm 全境
时间：白天
角色：林澈
动作：角色漫步穿过农田/屋后，镜头跟随
推荐时长：10s
```

## 六、录制技术检查（Task 4 方案，P1，**只提方案不开发**）

### 6.1 现状（实查 2026-08-09）

| 能力 | 现状 | 说明 |
|---|---|---|
| 分辨率 | ✅ 可配 | 探针 defaultViewport 1024×768；自适应逻辑分辨率（main.ts） |
| 时间控制 | ✅ 已具备 | `window.debug.setTime(h,m)` / `nextDay()`，自动重建 NPC 日程 |
| 场景跳转 | ✅ 可行 | localStorage 写 `scene:'farm'` + reload（探针既有模式） |
| 存档快进 | ✅ 可行 | 注入存档（farmWarm/剧情步骤/作物状态均可预置） |
| 摄像机控制 | 🟡 部分 | 有 `camCenterOn(wx,wy)` 中心对准 + 室内 zoom2 + 对话慢横移 tween；**无自由镜头/录制动效 API** |
| UI 隐藏 | ❌ 无 | DOM HUD（体力条/时间/任务）+ Phaser 文本，无 toggle 开关 |
| 天气/光照 | ❌ 无 | 游戏无天气系统；仅有昼夜明暗 + farmWarm 暖色 overlay |
| NPC 位置 | 🟡 部分 | setTime 按日程重建；无手动摆放 |

### 6.2 建议：录制开发者模式（若后续制作 PV，再评估是否开发）

| 项 | 方案 | 理由 |
|---|---|---|
| UI 隐藏开关 | `window.debug.toggleUI()`：隐藏 DOM HUD + Phaser 文本层 | 实机画面干净，剪片不用遮罩 |
| 自由/慢移镜头 | `window.debug.cam.slowPan(x,y,sec)`：tween 慢移 + `cam.freeze()` 固定机位 | A2/A6 等"镜头缓慢移动"镜头的前提 |
| 时间冻结 | `window.debug.timeFreeze(true/false)`：停 NPC/天气循环 | 情绪镜头不被打断 |
| 场景直达 | `window.debug.goto('town', x, y)` | 免 reload，连录效率高 |
| 天气/光照 | 与"镜头模式"同批评估（如晨雾/傍晚浓度） | D 类对比镜头需要统一光照 |

> 结论：**当前能力足以录制 B/C/D 类大部分镜头**（有 debug.setTime + 存档注入 + 探针驱动）；A2/A6 的"镜头缓慢移动"与"UI 干净画面"需要开发者模式支持——**先记入本档，等 PV 制作排期时再定开发与否**，本轮不开发。
